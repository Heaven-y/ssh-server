### 0.2 视觉方向

采用 UI UX Pro Max 中适合桌面工具的 Minimalism & Swiss Style 规则，结合实际产品截图，避免套用营销页结构：

- 风格：极简（Minimalism & Swiss）——高对比、网格对齐、少装饰；信息密度高（间距 8–32px）。
- 颜色（已实现为语义变量）。正文、辅助文字和状态色对 background/card/muted 的最小对比度分别为 12.45、5.89、7.50 以上；可交互边界 `border-strong` 最小 3.33:1，普通 `border` 仅用于装饰性分隔：

| 语义 | 值 | 用途 |
|---|---|---|
| background | `#101114` | 页面背景 |
| card | `#18191E` | 卡片、面板 |
| muted / muted-foreground | `#282A32` / `#A2A6B3` | 次要背景与文字 |
| foreground | `#EEEFF3` | 主要文字 |
| border | `#30323B` | 装饰性分隔线 |
| border-strong | `#747A89` | 输入框、按钮等可交互边界 |
| accent / accent-foreground | `#9CB5FF` / `#152044` | 主操作与焦点；按钮文字对比度 7.92:1 |
| success / warning | `#81CBA4` / `#F0C77F` | 成功 / 待确认，不与主要操作混用 |
| destructive | `#E66F7A` | 危险操作与错误边界 |
| destructive-foreground | `#FFB0B8` | 错误文字 |

- 字体：正文 IBM Plex Sans，中文明确回退到系统中文字体；代码 / 终端 / 路径 JetBrains Mono。字体通过 fontsource 本地打包，不从 Google Fonts 加载。对话正文 15px，行高 28px。
- 图标：Lucide（SVG），不用 emoji 当图标。
- 动效：只用细微过渡（150–250ms），遵守 `prefers-reduced-motion`。

│               │ 输入消息…                   [发送/停止] │                            │

- 三栏：左侧 240px，可折叠；中间对话区自适应；右侧面板 360–520px，可收起。分栏宽度可拖动并记住。
- 默认暗色主题，可切换亮色。视觉规范见第 0 节。
- 最小支持宽度960px；1280px以下右侧面板改为覆盖层。
- 右侧标签较多时可滚动，不压缩对话区；终端可展开为底部宽区域，编辑器可扩大显示空间。资源概览显示的数值仅为布局示例。

侧栏默认240px，200–320px用户调整；文件宽窗默认420px，360–520px，1280px以下使用同一dialog覆盖层。只保存用户交互产生的有界像素偏好，折叠为0时保留恢复宽度；存储不可用继续内存操作。宽窗文件保持最小宽度，关闭仍有未保存确认。顶栏亮暗切换、CodeMirror跟随主题；xterm保持自己的暗色画布。证据与取舍见[布局验收](../guides/workspace-navigation-acceptance.md)。

## 2. 顶栏

当前实现：顶部为侧栏/主题、工作区、命令面板、终端、文件、设置与本机服务状态；资源概览持续展示CPU、内存、最多两张GPU和额外数量、采集主机与更新时间。960/1280使用第二行，1920在同一顶栏排列；详情共用一个controller，隐藏/网页断线暂停。对话上方显示SSH、同步和版本摘要，点击打开详情。失败、断开、状态不可用和待确认保持可见；关闭详情不卸载同步调度。新建工作区使用五步向导，测试连接期间可以取消，提交创建期间禁止关闭。

| 元素 | 说明 |
|---|---|
| 工作区切换 | 下拉选择 |
| 连接状态 | 已连接 / 连接中 / 断开（图标 + 文字，不只靠颜色），点击可重连 |
| 同步状态 | 已同步（时间）/ 同步中 / 有待确认 / 失败；点击打开"同步"面板 |
| 待记录版本 | 相对上次 git 提交的改动文件数 + “保存版本”按钮；没有改动时按钮禁用，与编辑器保存文件区分 |
| 资源概览 | 当前 SSH 服务器的 GPU / 显存、CPU / 内存摘要与更新时间；点击打开“资源”面板，缺失或过期状态不能显示成零 |
| 设置 | 打开设置页 |

## 3. 左侧栏

工作区每行提供“移除工作区”，弹窗显示配置与保留内容，默认不勾选确认。有活动、待恢复文件任务或登记编辑器时显示阻断原因；失败保留目标，“重新核对”清除确认并重新读取。成功关闭所属文件面板与终端，清理所属缓存；仅当当前选择仍为目标时选择剩余第一项或空，侧栏常驻状态区播报结果。

当前会话列表独立读取Claude与Codex原生来源，合并按更新时间展示并标注Agent。一类失败时独立反馈，另一类历史仍可使用。“更多”打开原生dialog，提供重命名、删除和Codex归档；顶部“已归档”只查询Codex。网页cmdk命令面板已接入，仅打开时搜索工作区、当前工作区两Agent会话及常用入口。

删除须勾选确认原生记录及相关子会话的影响；操作等待期间禁用重复提交与关闭，失败保留条目并提供重新读取。归档记录只提供恢复/删除，恢复后才能继续对话或改名，不隐式恢复。删除/归档成功只清空仍匹配目标的当前对话，迟到结果不影响新选择；运行中的目标禁止管理，后端进一步校验后台轮次及同步收尾锁。实际界面、键盘与三种宽度验证见 [会话管理验收](../guides/session-management-acceptance.md)。

- 工作区列表，当前工作区高亮；"新建工作区"打开向导。
- 当前工作区的会话列表：标题、Agent 标记（C = Claude，X = Codex）、状态（空闲 / 运行中 / 等待确认 / 失败，图标 + 文字）、最近时间。
- `Ctrl+K` 打开网页命令面板：搜索并切换工作区、会话，执行常用操作（新会话、保存版本、立即同步、打开文件 / 终端 / 资源）。该入口不等同于 Agent 的 `/` 命令。

`Cmd+K`同样可用，IME组字、xterm内部和已有原生模态保留快捷键。宽窗非模态文件/终端不阻断聊天入口。保存版本只打开说明表单；立即同步只在ready且无忙/错误时委托原流程，其余状态打开详情；不包含自动确认、删除或覆盖命令。
- 会话“更多”按钮：重命名、删除；Codex 普通会话另有归档。删除须明确确认，原生调用成功后刷新对应列表。
- 可切换显示已归档会话。

## 4. 对话区

当前已实现新建时选择 Agent，发送中、读取历史及已有会话保持 Agent 固定；模型按 Agent 分别保留内存覆盖值，Codex 另有推理强度输入。聚焦输入框时按需读取原生候选，也可手动刷新和自由填写；留空沿用原生行为，候选默认项和历史实际模型不自动回填。新 Codex 会话采用新默认模型，历史续接保留原模型，显式填写才覆盖。

审批提交后显示等待后端确认并禁用重复操作，处理完成、超时或取消后关闭按钮。准备阶段已可点击停止；运行时收到停止后等待原生确认，无响应时 5 秒强停。未返回结果的工具显示“结果未返回 / 需核对实际执行状态”，不以轮次结束推断执行成功。网页断线后运行继续，但立即拒绝已有审批；重连不自动发起新轮次。切换历史时取消旧读取，加载期间禁止发送，迟到结果不覆盖新选择。

输入区“技能与命令”按钮打开可搜索 dialog，显示技能/命令、来源和限制原因；选择后显示可移除标签，技能可无附加文本发送，连接不接受时保留输入与选择。搜索框 Enter 不发送聊天，搜索在已读取目录内完成；目录失败不阻断普通消息。compact/context 要求已有会话，无参数命令会提示清空附加文本。切换工作区/Agent/会话清理选择，管理中仍禁止向同目标发送。

上下文卡可展开查看原生窗口、用量来源和模型；Claude 明示“原生估计”，Codex 明示“原生统计/估算”，不由 token/window 推算比例。压缩展示原生进行中、完成、失败、中断或结果未确认，历史保留原生边界，新普通轮次不复活旧的未确认压缩。

消息开头输入 `/` 自动展开当前 Agent 候选，浮层贴近输入框并保留焦点。上下方向键移动高亮，Enter 只确认选择，再次 Enter 才发送；Esc 收起并保留原文，Shift+Enter 换行。输入法组字时不触发选择或发送。只补全首个命令名，路径、正文和参数区保持普通编辑；光标移回命令名后可按方向键重新展开，选择保留已有参数。候选最多显示 20 项，继续输入缩小范围，名称、别名、来源和说明均可搜索。

既有真实网页与 GLM 两轮证据见 [Codex 对话验收](../guides/codex-conversation-acceptance.md)，能力控件和输入补全分别见 [原生能力验收](../guides/native-capabilities-acceptance.md) 与[补全验收](../guides/slash-completion-acceptance.md)。动态虚拟列表和明确读取工具分组已接入，受控长历史与流式证据见[时间线验收](../guides/conversation-timeline-acceptance.md)；不以显示负载代替原生自动压缩验收。

- 顶部：会话标题；新会话创建时选择 Claude / Codex，已有会话显示固定 Agent 标识，不能切换；模型选择（默认“跟随本地配置”，可下拉或手动输入）；Codex 另有推理强度。实际使用的模型名显示在标题旁。
- 消息类型：
  - 用户消息、助手文本（Markdown，代码高亮）、思考摘要（默认折叠）；
  - 工具调用卡片：工具名、关键参数、状态、结果（默认折叠，长输出可展开）。连续至少两项明确读取/搜索工具合并成“读取/搜索了N项”，始终显示完成、失败、运行或未返回计数，内部保留每项原结果；不根据shell猜测只读，`remote_exec`及审批始终独立；
  - 最近所属轮次改动聚合卡片：文件数和不可用/不完整状态，点击打开本轮 diff；不从工具报告猜测文件改动；
  - 权限请求卡片：说明 + 批准 / 拒绝；
  - 同步待确认卡片：待删除的服务器文件数 + 查看 / 确认 / 拒绝。
- 长对话使用动态高度虚拟列表；贴底时跟随流式增长，用户上翻时停止并显示“回到底部”。工具/思考/分组的展开状态在虚拟卸载后保留；切换或重开会话清空视图选择，首次原生会话id不重置列表。
- 输入框：Enter 发送，Shift+Enter 换行；回复进行中按钮变为"停止"。
- 输入框旁提供 skills / 命令入口，输入 `/` 时展示当前 Agent 可接入的命令与技能，支持搜索、选择和必要参数输入；使用对应运行时的真实能力列表。
- 列表区分可执行命令、技能调用和需要本机 CLI 的命令；不支持的命令显示原因，不伪装成已经执行。切换工作区或新建另一 Agent 会话后重新读取能力。
- 展示官方接口提供的上下文用量、正在压缩 / 已压缩等状态；没有数据时显示不可用。手动压缩走对应官方能力，网页不自建压缩逻辑。
- 用户通过普通消息手动要求查询训练进度或分析结果；需要统计、绘图时，Agent 通过远程执行卡片展示服务器已有 Python / 项目环境的命令与输出，必要的小结果在当前对话中展示或引用。等待期间不显示自动任务完成通知、不自动追加结果分析消息。资源面板刷新与对话状态独立。

## 5. 右侧面板

| 标签 | 内容 |
|---|---|
| 文件 | “本地代码 / 改动 / 服务器文件”视图切换；保持编辑器与远端通道，分别显示磁盘差异、远端路径和同步关系 |
| 改动 | 本轮及相对上次保存版本的改动文件列表，逐个文件查看 diff；可放弃单个文件的改动；可在 diff 行上写评论，作为下一条消息发给 Agent |
| 同步 | 最近同步时间与结果；待确认删除列表（逐个或全部确认 / 拒绝）；冲突列表；"立即同步"按钮；当前排除规则摘要 |
| 终端 | 多标签服务器终端（xterm.js），默认进入工作区服务器目录；可新建、关闭标签、调整区域大小，分屏交互参考 Pebrel |
| 资源 | 当前采集主机、GPU / CPU / 内存 / 磁盘和进程详情，持续刷新，不调用模型 |
| 历史 | 已保存的版本记录；点开查看该次的 diff；恢复整次或单个文件 |

### 5.1 文件区与本地编辑

- AI 是主要编辑者；文件面板用于偶尔修改脚本或配置，复用成熟组件，不提供完整 IDE。
- “本地代码”浏览同步范围内文件，条目可打开编辑或查看 diff；“服务器文件”按第 5.4 节管理远端实际目录，不受本地文件过滤规则隐藏大文件，也不自动下载。
- 编辑区显示路径、语言、未保存标记；复用 CodeMirror 提供语法高亮、搜索和“保存文件”。
- “保存文件”写入本地并同步；分别显示“本地已保存”“同步中”“服务器已同步”或失败 / 待确认，不生成 git 提交。
- 关闭未保存文件时提示保存或放弃；Agent / 同步修改了同一文件时显示冲突处理入口，不覆盖编辑缓冲。

当前顶栏文件入口提供本地代码、改动、服务器文件三视图：≥1280px 使用可调右侧面板，更窄时使用原生模态覆盖层；面板绑定打开时的工作区并显示名称，切换对话工作区保留编辑内容，关闭后重新打开可进入新工作区。分栏默认420px、可调360–520px，拖动与键盘交互保存偏好；收起使用关闭确认，重新展开恢复偏好。本地文件按目录逐级加载，支持手动输入相对路径；本地文件列表与编辑上限为同步阈值和 2 MiB 中较小值，不打开二进制。关闭、重新读取或切换文件前可取消操作并返回保存；文件保存与同步期间禁用关闭。编辑保护连接登记完成后才能编辑；失联或文件任务预留期间禁用编辑/保存，正文保留。断开登记显示处理入口，优先重连原页面，明确说明后才允许放弃登记。

版本摘要位于 SSH/同步状态旁，显示当前未记录文件数，点击按需打开版本详情。面板提供当前改动和排除项、1–200 字符保存说明、分页历史、按文件差异，以及单文件或整个版本的恢复预览。确认区明确标出将覆盖的未跟踪文件，勾选确认后执行；本地恢复与同步分别反馈，删除仍在同步详情中确认。版本操作期间禁用关闭与重复提交，保留已有文件编辑缓冲。

改动视图可选择最近20轮的本地净差异或相对上次保存版本。使用按需加载的成熟单列diff和高对比双主题；逐文件显示增删行与二进制，截断/解析失败明确提示并保留有界原文本。点击真实差异行或输入侧别/行号加入反馈，待发送区独立于正文，普通发送成功才消费；切换选择清理，首次原生id不清理。当前磁盘差异提供单文件放弃预览与勾选确认；独立暂存或陈旧指纹拒绝，不覆盖编辑缓冲，服务器删除另行确认。其他工作区的文件面板不能向当前对话加入反馈。见[改动验收](../guides/conversation-changes-acceptance.md)。

### 5.2 资源面板


- 始终标明采集主机与最近更新时间，默认是当前 SSH 服务器；不把该节点指标标成其他 Slurm 节点的训练指标。
- GPU 按卡列出型号、利用率、显存已用 / 总量、温度和功耗；CPU / 内存用简明数值或进度条展示，磁盘显示项目所在文件系统的可用空间。
- 进程表显示可获得的 PID、命令、CPU / 内存占用、GPU 关联和显存用量；共享账号下不将所有进程标为本人的任务。
- 数值更新不抢占焦点、不改变表格滚动位置。缺少工具或权限的字段显示“不可用”；失败时保留最近数据并标明“已过期”，提供手动刷新 / 重连入口。
- 资源区域可见时秒级刷新，隐藏 / 断线后暂停或降频，具体间隔在真实服务器验证。刷新不发送聊天消息，也不监视训练是否完成。
- 对话流式回复、终端命令或文件同步进行中，资源区域继续刷新；各活动分别显示状态，不用整页加载遮罩锁住其他入口。

### 5.3 终端交互

下述布局的[网页终端设计](../superpowers/specs/2026-10-04-web-terminal-design.md)已实施；稳定窗格与布局槽位的接线见[实施计划](../superpowers/plans/2026-10-04-web-terminal.md)。后端、网页顶栏及布局已接入，三种宽度、实例保留与复制粘贴的实际证据见[终端验收](../guides/web-terminal-acceptance.md)。

- 顶栏入口打开底部宽区，与文件面板并存；紧凑标签栏提供新建、左右/上下分屏、关闭、最大化及收起，窗格分隔线可拖动和键盘调整。首版每标签最多 4 个窗格，空间不足时仅显示活动窗格，其他连接保持。
- 标签绑定打开时的工作区，各窗格固定显示 Host 和“起始目录”，不把该路径当作用户 `cd` 后的当前目录；切换聊天不静默换目标。新增分屏使用原标签目标，另一工作区由明确入口新建终端。
- 收起和切换标签保留终端；关闭窗格确认将断开该 shell。断线立即停用输入，保留已显示内容，“新建连接”明确创建新 shell，不重发旧输入或承诺恢复原进程。
- 复制、粘贴、输入法及 PTY 尺寸同步以实际程序验证；多行粘贴先预览确认。用户手动 shell 不经过 Agent 黑名单或执行前同步，不调用模型；资源面板无需先打开 `nvitop`。

### 5.4 服务器文件视图（操作、下载与同步协调已接入）

沿用文件入口、主题和响应式面板，不另增一条顶层导航。“本地代码 / 服务器文件”位于面板顶部；切换视图保留各自路径、选择与本地编辑缓冲，服务器视图明确展示 Host、工作区和实际远端路径。宽屏可展开文件区，窄屏沿用覆盖层；长路径可换行或横向滚动路径栏，不撑宽整页。

当前已实现目录浏览、分页、隐藏项、文件信息及操作/下载入口；打开面板即登记目标，首次切换服务器视图才建立 SSH 文件通道。跨宽窄断点保留同一内容子树，旧 Host 绑定不能通过重连改指另一目标。操作窗口先预检，显示受影响工作区、源/目标同步文件数，再明确确认；未保存编辑、冲突、未知登记或不兼容名称阻止派发。远端完成与同步待恢复分别显示，恢复窗口说明实际远端优先、可能部分完成和不重放，勾选核对后才能开始；恢复可从任务区取消，关闭面板不取消。浏览、操作与协调分别见[浏览验收](../guides/remote-files-browser-acceptance.md)、[操作验收](../guides/remote-file-operations-acceptance.md)及[同步协调验收](../guides/remote-file-sync-acceptance.md)。

```text
文件 · demo-workspace                         [展开] [关闭]
[本地代码] [服务器文件]
my-server · ~/projects/demo                   [刷新]
项目 / outputs /                             [输入路径]
名称                 大小       修改时间       同步范围
run1/                按需计算   …              混合/待核对
weights.bin          100 GB     …              仅服务器
[新建目录] [移动到…] [复制到…] [更多]
操作：移动到 ~/projects/demo/archive/ · 在服务器执行
```

- 目录展开按需取下一层，分批显示；提供返回上级、返回工作区和路径输入，离开工作区目录时标注“工作区外”。固定显示工作区同步根和实际浏览路径，切换浏览目录不修改同步配置、不触发同步。隐藏项可切换显示，文件大小与目录体积区分，后者仅点击后计算。同步范围标记与最近同步结果分开，范围内不等于两端已一致。
- 文件/目录行提供选择、右键菜单和可见的更多按钮：重命名、移动到、复制到、删除、复制路径；文件另有按需下载。面包屑和目标选择器支持键盘。按 UI UX Pro Max 的拖动可访问性建议，拖动必须有菜单/按钮替代入口，不能成为唯一移动方式。
- 拖入目录表示同一服务器内移动，突出目标并在提交前展示源/目标路径；不把拖动解释为下载或跨视图本机传输。“移动到…”与“复制到…”复用目录选择器，默认定位当前目录，可输入同一 SSH 目标的其他路径。
- 单击选择、双击或 Enter 打开目录；F2 重命名、Delete 打开删除确认、Ctrl+Shift+N 新建目录，Alt 拖动选择复制。操作窗口优先聚焦路径输入，嵌套目录选择器关闭后恢复触发按钮焦点。任务折叠区独立显示状态、取消和结果核对，详情内部滚动，目录列表保留最小高度；关闭面板后已提交任务继续运行，重开可查询。隐藏时停止任务轮询。
- 删除、覆盖和影响同步范围的操作使用有明确动词的确认区，显示主机、路径、同名冲突及本地关联；同名目标默认拒绝，不自动合并目录。未保存编辑或同步冲突提供处理入口。
- 仅服务器文件可查看元数据并直接操作；同步范围内可通过“在本地代码中打开”跳转现有编辑器。打开未同步的大文件只显示信息及下载入口，不自动加载正文。下载明确提示不会自动纳入同步/版本管理。
- 面板底部按操作显示排队、执行中、完成、失败、部分完成或结果未确认；服务器操作和后续同步分开反馈，无可靠总量时使用不定进度。关闭面板后通过文件入口状态标记重新查看；取消只作用于所选任务，不关闭共享 SSH 连接。
- 目录递归操作的影响范围在用户发起操作后核对；普通浏览不预先遍历整个项目。断线后禁用新提交，保留待核对结果，重连不自动重试移动、复制或删除。

## 6. 新建工作区向导

1. 本地文件夹：逐级浏览或输入路径；显示是否为空、是否已是 git 仓库。
2. 服务器：选择 `~/.ssh/config` Host 或手动填写地址、端口、账号；选择“账号密码”或“已有私钥”。密码使用遮蔽输入，可选择“保存密码”，由本机 Windows 当前用户加密保存；点击“测试连接”。未知主机显示指纹确认，认证失败提供重新输入入口，不回显密码。
3. 服务器目录：逐级浏览（每层显示子目录，体积点击后计算）或输入路径。
4. 同步规则：扩展名列表、大小阈值；点击“预览”显示将同步的文件数与大小、被排除的大文件统计（前 N 个），不在打开向导时自动扫描大目录。
5. 确认：汇总双方目录、非空与.git状态；说明首次双端合并和冲突保留。验证当前快照成功、勾选核对后才可“创建并初始化同步”；创建期间禁止重复提交与正常关闭，完成后分别反馈配置已保存和首次同步结果。

向导已实现，见[验收](../guides/workspace-setup-acceptance.md)。手动服务器须明确“保存本机连接”，取消向导仍保留该连接；同步规则须点击“应用同步规则”。返回、改变目标或关闭撤销旧验证并清空密码输入；两端分页每页200项，预览上限20000项、排除例子最多20项，.git不计入统计。

明文密码不写入工作区配置或浏览器持久存储。主动断开 / 退出后清理内存，已保存的加密凭据仍可用于重连；取消“保存密码”勾选会删除保存项并关闭相关连接，提示自动连接已暂停；删除失败保持已保存状态，允许重试；不提供独立“忘记密码”入口。浏览目录、同步、命令和终端沿用同一连接参数，不让用户为每项操作重复配置服务器。

## 7. 设置页

- 默认值：新会话 Agent、模型（默认“跟随本地配置”）、同步大小阈值、扩展名列表、定时拉取间隔、资源刷新设置。Agent 默认值只影响新建会话，不能改变已有会话的 Agent。
- 命令黑名单：工作区侧栏“命令规则”按需打开固定目标dialog，默认勾选启用、可恢复全部默认；追加/编辑/移除程序名或字符串字面规则，最多20条。字段错误关联输入并聚焦摘要，保存单次、409保留、dirty关闭/重读先确认放弃。保存影响后续Agent远程执行，不影响网页终端及在途已检查命令，见[规则验收](../guides/workspace-policy-acceptance.md)。
- 显示本机检测结果：Claude Code、Codex、git、rclone 是否可用及版本。
- Agent 配置：顶栏“设置”先打开产品偏好，通过“编辑原生 Agent 配置”切换到CodeMirror编辑视图；同一时间只挂载一个dialog。分 Claude / Codex 选择固定配置文件，提供语法校验、重新读取和保存；外部修改时先提示重新读取，不静默覆盖。后续调用重读配置，无须重启项目，正在运行的轮次不改变；Codex 历史模型遵循第 4 节的续接规则。关闭或切换时若有未保存修改先确认放弃，保存期间禁用关闭；销毁编辑区时清理含密钥内容，不写浏览器持久存储。

产品偏好及手动环境检测已接入。新会话默认Agent/各Agent模型，空值跟随原生；新向导只复制一次同步大小/过滤快照。同步默认15秒（5–300）、资源检查默认5秒（2–60）、采样超时默认8秒（2–30），过期阈值取15秒和3倍间隔较大值。保存失败或409保留表单，跨独立窗口返回焦点时重读，迟到偏好不覆盖已操作草稿/历史。实际证据见[设置验收](../guides/product-settings-acceptance.md)；工作区黑名单使用侧栏独立入口。

## 8. 状态与反馈

- 空状态：没有工作区时显示引导；没有会话时显示"新会话"按钮。
- 加载：目录浏览、同步、测试连接显示进度，可取消。
- 错误：SSH 断开在顶栏和对话区显示横幅并提供重连；密码失效时请求重新输入；同步失败在“同步”面板显示原因，阻断远程执行时明确说明未执行；资源采样失败显示过期 / 不可用；操作结果用短暂提示（toast）。
- 危险操作（删除会话、确认删除服务器文件、恢复历史）一律二次确认，并写明影响范围。
- 文件保存、版本保存、远端文件操作和服务器同步分别反馈；远端完成但同步失败不显示整体完成。任务提交成功只显示启动信息或任务 ID，不将其标为训练完成，不启动后台完成检测。
- 对话、终端、资源刷新和同步分别反馈进行中 / 失败状态。同一会话正在回复时禁止重复发送；同一工作区同步请求排队执行，远程命令等待执行前同步时明确显示“等待同步”，失败或待确认时明确显示“未执行”。

## 9. 可访问性

- 所有操作可用键盘完成，焦点可见；弹窗打开时焦点限制在弹窗内，关闭后回到触发元素。
- 状态不只用颜色表示，同时有图标和文字。
- 流式回复区域使用 `aria-live="polite"`；图标按钮带可读的名称。
- 资源数值的频繁刷新不逐条触发屏幕阅读器播报；连接失败、采样失败和过期等状态变化提供可读提示。
- 文字与背景对比度满足 WCAG AA。完整的无障碍验证需要用辅助技术手动测试。

2026-10-05 终端入口实施状态：顶栏首次打开时加载终端模块；左侧栏外的主区上下分栏，底部默认40%，高度不足时显示覆盖层。同一标签保存固定目标，每标签最多4个窗格，空间不足可选择活动窗格。最大化、收起、切换聊天及嵌套分屏沿用同一窗格实例；标题显示起始目录，不能据此推断 shell 当前目录。类型、构建和实际交互检查通过，证据与尚未实测项见[终端验收](../guides/web-terminal-acceptance.md)。
