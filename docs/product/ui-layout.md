# 界面布局

更新日期：2026-10-02。本文描述目标界面；当前完成范围见 [路线图](../roadmap.md)，交互取舍见 [设计决策](../engineering/decisions.md)。

## 0. 参考与视觉规范

### 0.1 参考项目（2026-10 调研）

只借鉴交互和布局思路，不复制代码；AGPL 项目（CloudCLI、opcode）仅作对照。

| 项目 | 规模 / 许可 | 借鉴点 |
|---|---|---|
| pingdotgg/t3code | 约 2.4 万星 / MIT | 本机 Agent 的网页控制台；React + Base UI + Tailwind 4 + zustand 的前端组合 |
| BloopAI/vibe-kanban | 约 2.8 万星 / Apache-2.0 | 工作区 = 对话 + 终端 + diff；diff 行内评论回传给 Agent；可调分栏 |
| NanmiCoder/cc-haha | 约 1.5 万星 / MIT | 本轮改动逐文件 review；权限请求在界面内审批；会话全局搜索 |
| jakemor/kanna | 约 700 星 | 按项目分组的会话列表与运行状态；连续工具调用折叠成组 |
| siteboon/claudecodeui（CloudCLI） | 约 1.4 万星 / AGPL-3.0 | 三栏布局、会话列表、工具调用渲染（仅对照） |
| [Kuddev/pebrel](https://github.com/Kuddev/pebrel) | GPL-3.0 | 终端外观、多标签、分屏与可调整布局；仅参考设计，不复制实现 |

不采用：看板、多 Agent 编排、内置浏览器、分屏双会话、IM 集成、图片生成等与本项目目标无关的功能。

Pebrel 的 README 与许可已核对，截图的实际视觉核对尚未完成；其精确配色和终端分屏布局在 M5 实现时细化，不将已有主题变量当作已匹配 Pebrel。

### 0.2 视觉方向

由 ui-ux-pro-max 检索得出（查询 "developer tool dashboard dark"，密度 8、动效 2），只采用其中适合工具类应用的部分：

- 风格：极简（Minimalism & Swiss）——高对比、网格对齐、少装饰；信息密度高（间距 8–32px）。
- 颜色（暗色初始值，实现时用语义变量）。已校验：文字对背景、卡片的对比度均 ≥ 4.5:1；`border` 只有约 2.1–2.4:1，只能用于装饰性分隔，可交互组件的边框改用 `border-strong`（≥ 3:1）：

| 语义 | 值 | 用途 |
|---|---|---|
| background | `#0F172A` | 页面背景 |
| card | `#1B2336` | 卡片、面板 |
| muted / muted-foreground | `#272F42` / `#94A3B8` | 次要背景与文字 |
| foreground | `#F8FAFC` | 主要文字 |
| border | `#475569` | 装饰性分隔线（面板、卡片之间） |
| border-strong | `#6B7A90` | 输入框、按钮等可交互组件的边框（对背景 4.09:1、对卡片 3.59:1） |
| accent | `#22C55E` | 运行中、成功、主要操作 |
| destructive | `#EF4444` | 删除、失败（图标与边框；在卡片上作文字时对比度不足 4.5:1） |
| destructive-foreground | `#FCA5A5` | 卡片、背景上的错误文字（对卡片约 5.6:1） |

- 字体：正文 IBM Plex Sans，代码 / 终端 / 路径 JetBrains Mono；通过 fontsource 本地打包，不从 Google Fonts 加载。
- 图标：Lucide（SVG），不用 emoji 当图标。
- 动效：只用细微过渡（150–250ms），遵守 `prefers-reduced-motion`。

## 1. 主界面

```text
┌────────────────────────────────────────────────────────────────────────────────────┐
│ ssh-server │ 工作区: demo ▾ │ my-server 已连接 │ 已同步 12:03 │ 待记录版本 3 [保存版本] │
│ 资源概览：GPU 42% · 显存 18/80 GB │ CPU 12% │ 内存 20/128 GB │ 12:03:05 [详情]       │
├───────────────┬────────────────────────────────────────┬────────────────────────────┤
│ 工作区        │ 会话标题 · Claude（固定） · 模型 ▾       │ 文件 / 改动 / 同步 / 资源…  │
│ ▸ demo        │                                        │                            │
│ ▸ exp-2       │ 用户：把学习率改成 1e-4 然后跑一下       │ 当前面板                   │
│ + 新建工作区   │                                        │                            │
│               │ 助手：已修改 train.py ……                 │ 文件列表、编辑 / diff       │
│ 会话（demo）   │   ▸ 编辑 train.py（diff）                │ 或 GPU / 进程详情等         │
│ ● 调参 (C)    │   ▸ remote_exec: python train.py        │                            │
│ ○ 数据检查 (X) │     退出码 0 · 输出 120 行 ▾            │                            │
│ + 新会话       │                                        │                            │
│               │ 同步待确认：删除服务器文件 2 个          │                            │
│               │ [查看] [确认] [拒绝]                    │                            │
│               ├────────────────────────────────────────┤                            │
│               │ skills / 命令 · 原生上下文状态           │                            │
│               │ 输入消息…                   [发送/停止] │                            │
└───────────────┴────────────────────────────────────────┴────────────────────────────┘
```

- 三栏：左侧 240px，可折叠；中间对话区自适应；右侧面板 360–520px，可收起。分栏宽度可拖动并记住。
- 默认暗色主题，可切换亮色。视觉规范见第 0 节。
- 最小支持宽度 1280px；更窄时右侧面板改为覆盖层。
- 右侧标签较多时可滚动，不压缩对话区；终端可展开为底部宽区域，编辑器可扩大显示空间。资源概览显示的数值仅为布局示例。

## 2. 顶栏

| 元素 | 说明 |
|---|---|
| 工作区切换 | 下拉选择 |
| 连接状态 | 已连接 / 连接中 / 断开（图标 + 文字，不只靠颜色），点击可重连 |
| 同步状态 | 已同步（时间）/ 同步中 / 有待确认 / 失败；点击打开"同步"面板 |
| 待记录版本 | 相对上次 git 提交的改动文件数 + “保存版本”按钮；没有改动时按钮禁用，与编辑器保存文件区分 |
| 资源概览 | 当前 SSH 服务器的 GPU / 显存、CPU / 内存摘要与更新时间；点击打开“资源”面板，缺失或过期状态不能显示成零 |
| 设置 | 打开设置页 |

## 3. 左侧栏

- 工作区列表，当前工作区高亮；"新建工作区"打开向导。
- 当前工作区的会话列表：标题、Agent 标记（C = Claude，X = Codex）、状态（空闲 / 运行中 / 等待确认 / 失败，图标 + 文字）、最近时间。
- `Ctrl+K` 打开网页命令面板：搜索并切换工作区、会话，执行常用操作（新会话、保存版本、立即同步、打开文件 / 终端 / 资源）。该入口不等同于 Agent 的 `/` 命令。
- 会话右键或"…"菜单：重命名、删除；Codex 会话另有归档。删除弹出确认框。
- 可切换显示已归档会话。

## 4. 对话区

- 顶部：会话标题；新会话创建时选择 Claude / Codex，已有会话显示固定 Agent 标识，不能切换；模型选择（默认“跟随本地配置”，可下拉或手动输入）；Codex 另有推理强度。实际使用的模型名显示在标题旁。
- 消息类型：
  - 用户消息、助手文本（Markdown，代码高亮）、思考摘要（默认折叠）；
  - 工具调用卡片：工具名、关键参数、状态、结果（默认折叠，长输出可展开）。连续的读取、搜索类调用合并成一组（"读取了 5 个文件"），`remote_exec` 始终单独显示；
  - 文件编辑卡片：文件名、增删行数，点击在右侧面板显示 diff；
  - 权限请求卡片：说明 + 批准 / 拒绝；
  - 同步待确认卡片：待删除的服务器文件数 + 查看 / 确认 / 拒绝。
- 长对话使用虚拟列表；流式输出时自动滚动到底部，用户上翻时停止自动滚动并显示"回到底部"。
- 输入框：Enter 发送，Shift+Enter 换行；回复进行中按钮变为"停止"。
- 输入框旁提供 skills / 命令入口，输入 `/` 时展示当前 Agent 可接入的命令与技能，支持搜索、选择和必要参数输入；使用对应运行时的真实能力列表。
- 列表区分可执行命令、技能调用和需要本机 CLI 的命令；不支持的命令显示原因，不伪装成已经执行。切换工作区或新建另一 Agent 会话后重新读取能力。
- 展示官方接口提供的上下文用量、正在压缩 / 已压缩等状态；没有数据时显示不可用。手动压缩走对应官方能力，网页不自建压缩逻辑。
- 用户通过普通消息手动要求查询训练进度或分析结果；需要统计、绘图时，Agent 通过远程执行卡片展示服务器已有 Python / 项目环境的命令与输出，必要的小结果在当前对话中展示或引用。等待期间不显示自动任务完成通知、不自动追加结果分析消息。资源面板刷新与对话状态独立。

## 5. 右侧面板

| 标签 | 内容 |
|---|---|
| 文件 | 同步范围内的本地文件列表 / 文件树；打开轻量编辑区，显示未保存标记、保存文件与同步状态 |
| 改动 | 本轮及相对上次保存版本的改动文件列表，逐个文件查看 diff；可放弃单个文件的改动；可在 diff 行上写评论，作为下一条消息发给 Agent |
| 同步 | 最近同步时间与结果；待确认删除列表（逐个或全部确认 / 拒绝）；冲突列表；"立即同步"按钮；当前排除规则摘要 |
| 终端 | 多标签服务器终端（xterm.js），默认进入工作区服务器目录；可新建、关闭标签、调整区域大小，分屏交互参考 Pebrel |
| 资源 | 当前采集主机、GPU / CPU / 内存 / 磁盘和进程详情，持续刷新，不调用模型 |
| 历史 | 已保存的版本记录；点开查看该次的 diff；恢复整次或单个文件 |

### 5.1 文件与编辑

- AI 是主要编辑者；文件面板用于偶尔修改脚本或配置，复用成熟组件，不提供完整 IDE。
- 仅浏览本地同步范围内文件，不自动下载远程大型数据、权重或结果；文件条目可打开编辑或查看 diff。
- 编辑区显示路径、语言、未保存标记；提供语法高亮、搜索和“保存文件”，具体组件在实现时选定。
- “保存文件”写入本地并同步；分别显示“本地已保存”“同步中”“服务器已同步”或失败 / 待确认，不生成 git 提交。
- 关闭未保存文件时提示保存或放弃；Agent / 同步修改了同一文件时显示冲突处理入口，不覆盖编辑缓冲。

### 5.2 资源面板

- 始终标明采集主机与最近更新时间，默认是当前 SSH 服务器；不把该节点指标标成其他 Slurm 节点的训练指标。
- GPU 按卡列出型号、利用率、显存已用 / 总量、温度和功耗；CPU / 内存用简明数值或进度条展示，磁盘显示项目所在文件系统的可用空间。
- 进程表显示可获得的 PID、命令、CPU / 内存占用、GPU 关联和显存用量；共享账号下不将所有进程标为本人的任务。
- 数值更新不抢占焦点、不改变表格滚动位置。缺少工具或权限的字段显示“不可用”；失败时保留最近数据并标明“已过期”，提供手动刷新 / 重连入口。
- 资源区域可见时秒级刷新，隐藏 / 断线后暂停或降频，具体间隔在真实服务器验证。刷新不发送聊天消息，也不监视训练是否完成。
- 对话流式回复、终端命令或文件同步进行中，资源区域继续刷新；各活动分别显示状态，不用整页加载遮罩锁住其他入口。

### 5.3 终端交互

- 参考 Pebrel 的终端外观、多标签、分屏和可调整布局；项目整体主题遵循第 0 节，具体终端视觉与分屏布局在 M5 细化。
- 终端区域可扩大为底部宽区，支持复制 / 粘贴、键盘操作和 PTY 尺寸同步，以实际全屏程序显示验证可用性。
- 终端是通用 SSH shell，用户可以运行服务器已有的任何适用工具；资源面板无需先打开 `nvitop`。

## 6. 新建工作区向导

1. 本地文件夹：逐级浏览或输入路径；显示是否为空、是否已是 git 仓库。
2. 服务器：选择 `~/.ssh/config` Host 或手动填写地址、端口、账号；选择“账号密码”或“已有私钥”。密码使用遮蔽输入，只用于当前连接周期；点击“测试连接”。未知主机显示指纹确认，认证失败提供重新输入入口，不回显密码。
3. 服务器目录：逐级浏览（每层显示子目录，体积点击后计算）或输入路径。
4. 同步规则：扩展名列表、大小阈值；点击“预览”显示将同步的文件数与大小、被排除的大文件统计（前 N 个），不在打开向导时自动扫描大目录。
5. 确认：汇总信息；本地文件夹非空时提示首次同步的处理方式；点击"创建"开始首次同步并显示进度。

密码不写入工作区配置或浏览器持久存储。主动断开 / 退出后清除，后端重启后在网页重新输入；浏览目录、同步、命令和终端沿用同一连接参数，不让用户为每项操作重复配置服务器。

## 7. 设置页

- 默认值：新会话 Agent、模型（默认“跟随本地配置”）、同步大小阈值、扩展名列表、定时拉取间隔、资源刷新设置。Agent 默认值只影响新建会话，不能改变已有会话的 Agent。
- 命令黑名单：默认规则列表（可停用）、自定义规则；可按工作区覆盖。
- 显示本机检测结果：Claude Code、Codex、git、rclone 是否可用及版本。

## 8. 状态与反馈

- 空状态：没有工作区时显示引导；没有会话时显示"新会话"按钮。
- 加载：目录浏览、同步、测试连接显示进度，可取消。
- 错误：SSH 断开在顶栏和对话区显示横幅并提供重连；密码失效时请求重新输入；同步失败在“同步”面板显示原因，阻断远程执行时明确说明未执行；资源采样失败显示过期 / 不可用；操作结果用短暂提示（toast）。
- 危险操作（删除会话、确认删除服务器文件、恢复历史）一律二次确认，并写明影响范围。
- 文件保存、版本保存和服务器同步分别反馈；任务提交成功只显示启动信息或任务 ID，不将其标为训练完成，不启动后台完成检测。
- 对话、终端、资源刷新和同步分别反馈进行中 / 失败状态。同一会话正在回复时禁止重复发送；同一工作区同步请求排队执行，远程命令等待执行前同步时明确显示“等待同步”，失败或待确认时明确显示“未执行”。

## 9. 可访问性

- 所有操作可用键盘完成，焦点可见；弹窗打开时焦点限制在弹窗内，关闭后回到触发元素。
- 状态不只用颜色表示，同时有图标和文字。
- 流式回复区域使用 `aria-live="polite"`；图标按钮带可读的名称。
- 资源数值的频繁刷新不逐条触发屏幕阅读器播报；连接失败、采样失败和过期等状态变化提供可读提示。
- 文字与背景对比度满足 WCAG AA。完整的无障碍验证需要用辅助技术手动测试。
