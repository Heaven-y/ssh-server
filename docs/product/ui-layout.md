# 界面与交互

更新于 2026-11-04。行为范围见[需求](requirements.md)，交付进度见[路线图](../roadmap.md)。旧三栏界面与验收可通过提交 `c686ef2` 查阅；本文说明原生会话、设置与已接入插件的界面关系。

## 1. 桌面外壳

整体参考 DSH 的清晰导航与克制视觉。会话和插件通过侧栏切换主区，旧工具面板按需展开。插件页面拥有完整主区空间，不能把所有业务挤入固定右栏。

| 区域 | 职责 |
|---|---|
| 顶栏 | 当前项目、命令面板、产品设置、主题、插件管理与服务器档案 |
| 左栏 | 工作台插件导航、项目树、按 CLI 分组的会话、刷新及管理入口 |
| 会话主区 | 会话身份、原生历史、实时工具事件和输入操作 |
| 右侧停靠区 | 保留旧终端、资源、Slurm 和服务器文件业务，作为兼容工具入口 |

当前外壳沿用已有布局预算，后续改变需同步验证受影响区域：最小网页宽度 960px，1280px 为宽窄断点；左栏默认 240px、范围 200–320px，右侧默认 420px、范围 360–720px；主区常规最小 480px，窄窗主动展开左栏时允许到 320px。隐藏的分隔线不可聚焦，恢复尺寸不得超出当前约束。

小于断点时可自动收起左栏，但不覆盖用户的持久偏好。停靠区收起或切页不会结束已有 shell；独立控制台的终端保留方式见第 6 节。资源视图隐藏后停止本视图采样。

## 2. 视觉和可访问性

- 默认浅色，保留深色选择及持久偏好。灰阶背景、细边框和少量高亮构成层次；路径与代码使用等宽字体。
- 主题变量集中定义在样式表，不在多篇文档复制色值。CLI 用字母徽标和文字区分，状态不能只靠颜色。
- 图标按钮有可访问名称，键盘焦点清晰；菜单、对话框和分栏复用成熟组件。
- 弹窗关闭后恢复触发点焦点；只有模态对话框限制焦点，普通面板不形成焦点陷阱。
- 兼容输入法组字和 `prefers-reduced-motion`。流式信息避免逐 token 播报，资源数值刷新不打断读屏。
- 新页面检查实际渲染、长标题、错误文案、缩放与键盘操作；现有单元测试不等于已通过完整辅助技术验收。

## 3. 项目与会话导航

项目行显示名称、目录、会话数量与当前选择，更多菜单提供重命名、更换目录和移除。服务器绑定入口只处理默认 SSH 目标。新增和更换目录需要本地绝对路径，失败保留输入；离线目录仍可改名或移除。移除通过独立确认框执行，明确保留磁盘目录与原生历史。

更换当前项目目录后关闭其旧会话并清空参数覆盖，之后按新目录显示会话。运行或准备发送时管理菜单及已打开的确认框均禁用。处理其他项目的操作完成后不改变当前选择；未保存修改在离开时确认。

会话按 Claude/Codex/Antigravity 分组，组内按最近活动时间排序；无会话的组不画空壳。读取中、读取失败与空列表分别显示。未归属记录通过「显示其他目录的会话」集中查看；可信目录在条目下显示，并可点击“加为项目”预填表单，没有目录的摘要不提供猜测入口。

侧栏刷新按钮检查原生列表；可见窗口同时轮询目录版本，有变化才更新摘要。不能用列表刷新替换主区已收到的正文，也不由此触发能力探测。监听不完整或接口失败时显示手动刷新提示。

新建会话先确定项目与 CLI，实际发送才创建原生会话。三种 CLI 均可进入输入区，Antigravity 的历史限制单独说明。适配失效或能力探测失败时展示原因，不能把未知状态包装为可用。

会话头显示 CLI、标题、项目目录和本应用运行状态。版本与模型必须标明来源：探测版本不等于历史回合的驱动版本，原生未报告模型时不能根据列表猜测。当前会话的 CLI 不提供切换按钮。

## 4. 对话主区

### 4.1 历史与流式事件

历史与新回合使用一致的消息和工具卡片。文本、代码、工具参数与结果均来自原生事件；读取类工具可合组，审批、执行和失败保持独立，便于找到需要处理的动作。

实时回合需要支持跟随底部和回到底部；用户向上浏览时不强制跳回。展开工具详情、长代码块和布局变化后保持合理滚动位置。长列表的实现预算见[架构](../engineering/architecture.md)。

加载中、空历史、失败和不可回放是互斥状态。切换会话先取消旧读取并隔离迟到结果；失败在原位置解释并允许重试。Antigravity 的说明区须按实际适配状态表达继续对话是否可用，不能把历史不可读当作实时对话不可用。

不展示独立的「本轮改动」汇总、并排 diff 或行内评论；工具自身报告的路径和动作正常展示。

### 4.2 输入与原生参数

输入区由文本、发送/停止、以及当前 CLI 支持的参数组成。发送需要明确操作；输入法组字时不提交，忙碌时避免重复发起同一会话回合。

模型和推理强度默认沿用原生值；菜单的候选来自实际能力，不用固定档位凑齐所有 CLI。未刷新能力时仍可清楚表达「原生默认」或显式输入，不自动联网获取列表。

「刷新能力」旁说明会启动 CLI 检查账号和能力。加载新会话、切项目或恢复页面不触发这一动作。命令补全保留原生命名与限制，失败不悄悄降成普通文本。

### 4.3 运行、审批与结束

运行中明确展示本应用正在驱动的会话，停止可覆盖准备和生成阶段。Claude/Codex 工具审批只展示 CLI 实际提出的请求，批准、拒绝与取消的结果绑定正确回合。Antigravity 显示原生权限模式与软拒提示，不使用无效的批准按钮。

本轮运行或准备期间阻止切项目、切会话和新建，提示先结束当前回合，让停止和审批始终可达；这是当前工作台的实施范围，不是原生 CLI 的并发能力限制。

正常结束、报错、断开和中断分别呈现。停止后保留已产生的内容，不编造成功结果；网络恢复不自动再次发送。能否跨连接接回在途回合须由实现与验证证明，不能仅凭「已重连」宣称恢复。

分叉与删除等操作只有在对应原生能力已接入且会话空闲时出现；删除明确二次确认，分叉使用原生结束点，不承诺回滚文件。

项目侧栏的会话“更多”菜单按 CLI 显示动作，键盘到达该行时管理入口可见；无支持的来源不显示假按钮。Codex 已归档会话在所属项目下按需展开，加载、空列表和读取失败各自显示；归档条目只允许恢复或确认删除。操作对话框显示原生来源和目标标题，处理期间禁用重复提交。成功刷新对应项目的列表，失败保留原处说明；操作其他项目不能把主区切走。

## 5. 设置

设置分清产品偏好和 CLI 原生配置。默认 CLI、主题等属于工作台；模型、权限、Skills、MCP 和原生插件属于对应 CLI。

工作台页面入口位于侧栏上方，插件管理也可从顶栏打开。SSH Console 使用主区完整宽度，切回对话保留服务器标签和终端；停用插件才回收控制台通道。旧服务器面板入口继续承载兼容工具。外部页面插件关闭即卸载显示，自己的持久设置保留。

配置按「这个 CLI 支持哪些项」呈现，再显示其真实作用域。没有项目级配置的项不画项目级空表单；目录级规则、运行时参数也不能强行合并成用户/项目两层。原生配置读取失败、文件不存在和空白文件分别说明。

原生资源目录按 CLI 和真实作用域列出文件，Claude 的个人项目配置与共享项目配置分开。目录页面不读取文件正文；点击“显示并编辑文件”后才展示完整内容，包括其中的敏感值。离开清空正文，保存冲突保留草稿并提供重读；只读资源和不可读取原因清楚标注。

规则和 Skill 仅在提供的原生根目录中创建；Skill 名称和用途字段生成必要元信息。启动环境单独位于运行环境分类，旧值只显示来源；切换继承、单独设置和停用时解释作用，填写新值后才替换。保存后提示新启动生效，已有会话需空闲回收或显式“重新启动 CLI”，该按钮不发送消息。

## 6. SSH Console 与工作台插件

SSH Console 从侧栏打开主页面，返回对话保留原会话。页面采用「服务器标签 → 概览/进程/文件/终端」两层导航，多服务器状态分开。项目只给首次默认服务器与目录，之后切项目不抢走已选服务器。

- 概览中的 GPU 利用率与显存占用分别显示，进程页保留完整命令信息。
- 文件页只读进入目录和预览文本，清楚标识截断；目标范围见需求 F6。
- 终端支持独立 PTY、多标签和分屏；切页与关闭页面不等于关闭 shell，断开与关闭终端才明确结束对应会话。
- 终端中的 `Ctrl+F`（或 `Meta+F`）打开本机查找，支持前后跳转；关闭后清除选中并把焦点交回终端。查找不发送 SSH 指令。
- 插件停用有独立的资源清理语义；不得把页面隐藏当成插件已卸载。

插件管理显示包身份、版本、权限和启用状态；从本地目录安装后先停用，明确启用才可使用。外部 v1 插件显示受控静态页面，可贡献命令并访问获准的设置与项目摘要；它不包含通用后端执行入口。CLI 的原生插件继续在各自配置入口管理。

## 7. 命令与反馈

`Ctrl+K` 包含项目、会话、终端、设置、主题、布局与已启用插件声明的命令。执行插件命令打开对应页面并交付命令 id；未实现的同步或版本功能不重新出现在菜单中。

快捷命令支持上下选择、Enter 执行和 Esc 退出，输入法组字期间不触发。成功的本机读取保持安静；失败在操作位置给出原因，连接断开时提供明确恢复入口。涉及不可逆原生操作的确认应写明对象和范围。
