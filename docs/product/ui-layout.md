# 界面与交互

更新于 2026-11-05。行为范围见[需求](requirements.md)，交付进度见[路线图](../roadmap.md)。旧三栏界面与验收可通过提交 `c686ef2` 查阅；本文说明本轮对齐 DSH 后的页面结构。交互约定不代表相关浏览器或真实 CLI 验收已经完成。

## 1. 桌面外壳

整体采用 DSH 式「左侧工作区、中间对话、按需打开右侧栏」。Claude、Codex 和 Antigravity 使用同一套界面，通过来源图标与名称区分。会话和插件通过左栏切换中央主区，插件页面使用完整主区空间。

| 区域 | 职责 |
|---|---|
| 左栏上方 | 品牌与收起按钮、新建会话、插件管理、已启用插件及更多操作 |
| 左栏工作区 | 项目树、按最近活动排列的会话、搜索及项目和会话管理 |
| 左栏底部 | 设置与外观菜单，集中提供产品设置和主题切换 |
| 中央标题栏 | 当前会话标题、项目名称、本应用运行/连接状态和右栏开关 |
| 对话主区 | 原生历史、实时文本与工具事件、消息输入和 CLI 参数 |
| 右侧栏 | 当前会话信息：项目目录、CLI、原生 id、参数覆盖和运行状态 |

中央标题栏高 48px，只占中央列，不跨左栏堆放全局操作。右栏每次启动默认关闭，打开后显示会话信息；当前不提供 IDE、文件树、diff 或服务器工具。切到插件时隐藏右栏，回到对话后恢复本次打开状态。

Windows 桌面另有一行 40px 应用顶栏，AgentDeck 与 File、Edit、View、Window 同排，右侧使用系统窗口按钮，保留拖动、缩放和原生菜单快捷键。浏览器调试隐藏桌面栏；弹出菜单不改变左栏布局，“更多”打开前后工作区位置保持不变。

### 1.1 宽度与收起

最小网页宽度 800px，1024px 为宽窄断点。左栏默认 280px，可调 264–420px，收起后保留 56px 图标导航；右栏默认 420px，可调 300–720px。对话区常规最小 400px，窄窗主动展开左栏时可降至 320px，并收起右栏；窄窗主动打开右栏时收起左栏，避免同时挤压中央区域。

窄窗自动收起左栏不覆盖用户持久偏好。宽度只保存有界值，旧服务器栏的展开偏好不再控制新右栏。隐藏的分隔线不可聚焦；普通面板关闭后恢复到可见入口，不能把焦点留在隐藏内容中。

对话输入与历史保留在同一组件树内，打开右栏或切到插件后返回不会清空草稿。服务器与终端的生命周期见第 6 节，不由对话右栏控制。

## 2. 视觉和可访问性

- 默认浅色，保留深色选择及持久偏好。灰阶背景、细边框和少量高亮构成层次；路径与代码使用等宽字体。
- 主题变量集中定义在样式表，不在多篇文档复制色值。采用系统字体，正文默认 14px，辅助控件约 13px；CLI 使用来源图标和文字，状态不能只靠颜色。
- 图标按钮有可访问名称，键盘焦点清晰；菜单、对话框和分栏复用成熟组件。
- 弹窗关闭后恢复触发点焦点；只有模态对话框限制焦点，普通面板不形成焦点陷阱。
- 兼容输入法组字和 `prefers-reduced-motion`。流式信息避免逐 token 播报，资源数值刷新不打断读屏。
- 新页面检查实际渲染、长标题、错误文案、缩放与键盘操作；现有单元测试不等于已通过完整辅助技术验收。

## 3. 项目与会话导航

项目行显示名称、会话数量与当前选择，完整目录通过提示与项目管理查看。更多菜单提供重命名、更换目录和移除，服务器绑定只处理默认 SSH 目标。桌面版新增和更换目录可点击“选择文件夹”打开系统窗口，也保留绝对路径输入；取消选择不清空原值。浏览器调试环境仅保留手输路径。离线目录仍可改名或移除；移除通过独立确认框执行，明确保留磁盘目录与原生历史。

更换当前项目目录后关闭其旧会话并清空参数覆盖，之后按新目录显示会话。运行或准备发送时管理菜单及已打开的确认框均禁用。处理其他项目的操作完成后不改变当前选择；未保存修改在离开时确认。

每个项目下混合显示三种 CLI 的会话，按最近活动时间排序，不再为每种 CLI 画一层空分组。来源图标和文字保留身份差异，搜索同时匹配项目名称、目录、会话标题和来源。读取中、读取失败与空列表应分别呈现，不能用「暂无会话」代替读取失败。

未归属记录通过更多菜单中的「其他目录」按需发现，零项目也能使用。可信目录在条目下显示，可点击“加为项目”预填表单；没有可信目录的摘要不提供猜测入口。项目映射变化后同步更新归属，避免同一条目继续留在其他目录。

会话列表随应用加载和应用内操作自动更新，普通列表及归档页均不提供常驻刷新按钮。只有读取失败时在错误处提供重试；列表变化不替换当前对话内容，也不重新获取模型目录。

新建会话先确定项目与 CLI，实际发送才创建原生会话。三种 CLI 均可进入输入区，Antigravity 的历史限制单独说明。适配失效或能力探测失败时展示原因，不能把未知状态包装为可用。

中央标题栏只显示一份会话标题与项目名称。输入区模型按钮显示当前 CLI 和模型；本机探测版本与模型来源放在提示中，完整目录与原生 id 可在右栏查看。探测版本不等于历史回合的驱动版本，原生未报告模型时不能根据列表猜测。已有会话的 CLI 不提供切换操作。

## 4. 对话主区

### 4.1 历史与流式事件

历史与新回合使用一致的消息与工具行。用户消息使用靠右的圆角气泡，助手正文直接排版；工具默认显示紧凑摘要，展开后查看参数和结果。文本、代码、工具参数与结果均来自原生事件；读取类工具可合组，审批、执行和失败保持独立。

正文宽度根据中央列计算，目标宽度为 `clamp(680px, 64cqw, 920px)`，实际不超过可用区域；输入框外沿比正文宽 32px。打开右栏后仍保持消息与输入的共同轴线，长路径和代码不能撑破布局。

实时回合需要支持跟随底部和回到底部；用户向上浏览时不强制跳回。展开工具详情、长代码块和布局变化后保持合理滚动位置。长列表的实现预算见[架构](../engineering/architecture.md)。

加载中、空历史、失败和不可回放是互斥状态。切换会话先取消旧读取并隔离迟到结果；失败在原位置解释并允许重试。Antigravity 通过可展开的「原生会话说明」解释权限与历史限制，不能把历史不可读当作实时对话不可用。

不展示独立的「本轮改动」汇总、并排 diff 或行内评论；工具自身报告的路径和动作正常展示。

### 4.2 输入与原生参数

输入区采用统一圆角容器，包含文本、技能与命令、模型、推理强度、按原生报告显示的上下文状态，以及圆形发送/停止按钮。发送需要明确操作；输入法组字时不提交，忙碌时避免重复发起同一会话回合。

模型和推理强度默认沿用原生值；菜单的候选来自实际能力，不用固定档位凑齐所有 CLI。首次打开模型菜单会读取尚未发现的原生模型列表，之后使用缓存。未选择具体型号时继续继承原生默认。

模型菜单保留“默认模型”选项，选择后清除会话覆盖，不发送 default 占位型号。候选来自 CLI，空结果直接保留默认和手填操作；错误只显示对应模型原因，技能警告留在技能入口。目录失效时提供“更换工作区目录”，不伪装成模型或安装故障。图标与名称同排，加载中显示进度，失败可重试。应用启动、切项目和斜杠补全不自动检查账号。

### 4.3 运行、审批与结束

运行中明确展示本应用正在驱动的会话，停止可覆盖准备和生成阶段。Claude/Codex 工具审批只展示 CLI 实际提出的请求，批准、拒绝与取消的结果绑定正确回合。Antigravity 显示原生权限模式与软拒提示，不使用无效的批准按钮。

本轮运行或准备期间阻止切项目、切会话、新建及打开插件主页面，插件命令采用相同门禁，提示先结束当前回合，让停止和审批始终可达；这是当前工作台的实施范围，不是原生 CLI 的并发能力限制。

正常结束、报错、断开和中断分别呈现。停止后保留已产生的内容，不编造成功结果；网络恢复不自动再次发送。能否跨连接接回在途回合须由实现与验证证明，不能仅凭「已重连」宣称恢复。

分叉与删除等操作只有在对应原生能力已接入且会话空闲时出现；删除明确二次确认，分叉使用原生结束点，不承诺回滚文件。

每个会话的“更多”菜单依据服务端能力显示重命名、创建分支、归档和删除，键盘到达该行时入口可见。统一归档页合并 Codex 原生归档与 Claude/Antigravity 工作台归档；后两者保留 CLI 记录，仅从工作台活动列表移出。归档后先恢复再续聊；删除确认说明实际影响的会话及子记录。操作完成刷新同来源列表，迟到结果不抢占当前选择，其他项目的首次加载不能因查询取消而停住。未归属条目沿用添加项目后管理的流程。

## 5. 设置

设置分清产品偏好和 CLI 原生配置。默认 CLI、主题等属于工作台；模型、权限、Skills、MCP 和原生插件属于对应 CLI。

设置使用左侧分类、右侧表单。模型配置分为三个 CLI，图标与名称同行；另提供通用设置和运行环境。常用模型、地址与认证优先展示，模型别名映射折叠；原始配置与启动环境从对应 CLI 进入，返回保留所在分类。服务器资源采样沿用 SSH Console 默认值。设置与主题仍从主界面左栏底部打开，服务器档案留在 SSH Console 内。

配置按「这个 CLI 支持哪些项」呈现，再显示其真实作用域。没有项目级配置的项不画项目级空表单；目录级规则、运行时参数也不能强行合并成用户/项目两层。原生配置读取失败、文件不存在和空白文件分别说明。

原生资源目录按 CLI 和真实作用域列出文件，Claude 的个人项目配置与共享项目配置分开。目录页面不读取文件正文；点击“显示并编辑文件”后才展示完整内容，包括其中的敏感值。离开清空正文，保存冲突保留草稿并提供重读；只读资源和不可读取原因清楚标注。

模型表单只修改对应用户原生配置，秘密只显示“已设置”状态，空输入不擦除已有 Key；清除有独立操作。切换分类、重新读取或退出时保护未保存修改，保存期间不重复提交。模型能力缓存随保存失效，旧请求的成功、失败和忙碌状态不能影响新配置。

常态页面不堆叠实现细节或防御性说明。字段补充信息放帮助提示，复杂配置解释折叠；只有实际失败、未保存修改和删除范围需要直接提醒。

规则和 Skill 仅在提供的原生根目录中创建；Skill 名称和用途字段生成必要元信息。启动环境显示继承、工作台设置或停用状态，填写新值才替换。保存后说明新启动生效，已有会话可在空闲时“重新启动 CLI”，该按钮不发送消息。Antigravity 的 API 地址与 Key 明确属于子进程环境，区别于写入原生文件的模型选择。

## 6. SSH Console 与工作台插件

SSH Console 从侧栏打开主页面，返回对话保留原会话。页面采用「服务器标签 → 概览/进程/文件/终端」两层导航，多服务器状态分开。项目只给首次默认服务器与目录，之后切项目不抢走已选服务器。

页面只有一份 SSH Console 标题，其下为服务器操作工具栏。Slurm、文件写操作与旧终端集中在控制台内显式打开的「项目服务器工具」，不占用对话右栏；它仍是旧项目绑定业务，不能描述成独立服务器能力。打开工具后焦点进入可操作入口，返回或按 Esc 关闭后回到触发按钮。

- 概览中的 GPU 利用率与显存占用分别显示，进程页保留完整命令信息。
- 文件页只读进入目录和预览文本，清楚标识截断；目标范围见需求 F6。
- 终端支持独立 PTY、多标签和分屏；切页与关闭页面不等于关闭 shell，断开与关闭终端才明确结束对应会话。
- 终端中的 `Ctrl+F`（或 `Meta+F`）打开本机查找，支持前后跳转；关闭后清除选中并把焦点交回终端。查找不发送 SSH 指令。
- 停用 SSH Console 会结束控制台及「项目服务器工具」中的终端，确认提示须说明这一范围；清除已结束的旧标签并取消待绑定操作，重新启用后由用户新建终端。服务器档案、保存的凭据、项目与旧任务记录保留。页面隐藏不等于插件停用。

插件管理显示包身份、版本、权限和启用状态；从本地目录安装后先停用，明确启用才可使用。外部 v1 插件显示受控静态页面，可贡献命令并访问获准的设置与项目摘要；它不包含通用后端执行入口。CLI 的原生插件继续在各自配置入口管理。

## 7. 命令与反馈

`Ctrl+K` 包含项目、会话、设置、主题、侧栏收起与已启用插件声明的命令。插件命令打开对应页面并交付命令 id；旧服务器面板不再作为对话区快捷入口，未实现的同步或版本功能不出现在菜单中。

快捷命令支持上下选择、Enter 执行和 Esc 退出，输入法组字期间不触发。成功的本机读取保持安静；失败在操作位置给出原因，连接断开时提供明确恢复入口。涉及不可逆原生操作的确认应写明对象和范围。
