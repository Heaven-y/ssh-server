# 界面与交互

更新于 2026-11-09。行为范围见[需求](requirements.md)，交付进度见[路线图](../roadmap.md)。旧三栏界面与验收可通过提交 `c686ef2` 查阅；本文说明本轮对齐 DSH 后的页面结构。交互约定不代表相关浏览器或真实 CLI 验收已经完成。

## 1. 桌面外壳

整体采用 DSH 式「左侧工作区、中间对话、按需打开右侧栏」。Claude、Codex 和 Antigravity 使用同一套界面，通过来源图标与名称区分。会话和插件通过左栏切换中央主区，插件页面使用完整主区空间。

| 区域 | 职责 |
|---|---|
| 左栏上方 | 品牌与收起按钮、新建会话、插件管理、已启用插件及更多操作 |
| 左栏工作区 | 项目树、按最近活动排列的会话、搜索及项目和会话管理 |
| 左栏底部 | 直接打开设置，主题在通用设置中切换 |
| 中央标题栏 | 当前会话标题、项目名称、对话/轨迹切换、子代理入口、运行/连接状态和右栏开关 |
| 对话主区 | 原生历史、实时事件、统计和消息输入 |
| 右侧栏 | 当前会话信息与选中执行步骤的输入、输出、状态和耗时 |

中央标题栏最小高 58px，窄窗允许换行；视图切换与标题同排，消息区不再单独保留工具栏空行。它只占中央列，不跨左栏堆放全局操作。右栏每次启动默认关闭；顶栏开关显示会话信息，点击轨迹步骤打开详情，可返回会话信息。当前不提供 IDE、文件树、独立 diff 或服务器工具。切到插件时隐藏右栏，回到对话后恢复本次打开状态。

Windows 桌面另有一行 40px 应用顶栏，AgentDeck 与 File、Edit、View、Window 同排，右侧使用系统窗口按钮，保留拖动、缩放和原生菜单快捷键。浏览器调试隐藏桌面栏；弹出菜单不改变左栏布局，“更多”打开前后工作区位置保持不变。

### 1.1 宽度与收起

最小网页宽度 800px，1024px 为宽窄断点。左栏默认 280px，可调 264–420px，收起后保留 56px 图标导航；右栏默认 420px，可调 300–720px。对话区常规最小 400px，窄窗主动展开左栏时可降至 320px，并收起右栏；窄窗主动打开右栏时收起左栏，避免同时挤压中央区域。

窄窗自动收起左栏不覆盖用户持久偏好。宽度只保存有界值，旧服务器栏的展开偏好不再控制新右栏。隐藏的分隔线不可聚焦；普通面板关闭后恢复到可见入口，不能把焦点留在隐藏内容中。

对话输入与历史保留在同一组件树内，打开右栏或切到插件后返回不会清空草稿。服务器与终端的生命周期见第 6 节，不由对话右栏控制。

## 2. 视觉和可访问性

- 默认浅色，保留深色选择及持久偏好。灰阶背景、细边框和少量高亮构成层次；路径与代码使用等宽字体。
- 主题变量集中定义在样式表，不在多篇文档复制色值。采用系统字体，正文默认 14px，辅助控件约 13px；CLI 使用来源图标和文字，状态不能只靠颜色。
- 图标按钮有可访问名称，键盘焦点清晰；菜单、对话框和分栏复用成熟组件。
- 弹窗关闭后恢复触发点焦点；只有模态对话框限制焦点，普通面板不形成焦点陷阱。
- 兼容输入法组字和 `prefers-reduced-motion`。流式信息避免逐 token 播报，资源数值刷新不打断读屏。
- 标签、菜单、折叠内容与右栏采用短过渡，输入容器只显示轻微悬停光照；装饰层不接收点击。正式顶栏不提供预览用的动效开关，减弱动态跟随系统偏好；不替换已有 AgentDeck 标识。
- 新页面检查实际渲染、长标题、错误文案、缩放与键盘操作；现有单元测试不等于已通过完整辅助技术验收。

## 3. 项目与会话导航

项目行使用展开/关闭的文件夹图标，点击只展开目录并选择下一次新建的工作区，不恢复或切换已有会话。当前对话保持不变，只有点击会话或标签才打开目标。完整目录通过提示与项目管理查看。更多菜单提供重命名、更换目录和移除，服务器绑定只处理默认 SSH 目标。桌面版新增和更换目录可点击“选择文件夹”打开系统窗口，也保留绝对路径输入；取消选择不清空原值。浏览器调试环境仅保留手输路径。离线目录仍可改名或移除；移除通过独立确认框执行，明确保留磁盘目录与原生历史。

工作区行右侧提供“＋”，可直接选择 CLI 新建会话；当前工作区已有任务运行时也可新建。项目管理菜单仍可打开查看目录，修改动作及已打开的确认框在运行或准备发送期间禁用。更换当前项目目录后关闭其旧会话并清空参数覆盖，之后按新目录显示会话。处理其他项目的操作完成后不改变当前选择；未保存修改在离开时确认。

每个项目下混排三种 CLI 会话，默认按最近活动排序；工作区标题旁可切换名称或手动顺序。任何模式都支持同项目拖动和 Alt+↑/↓，操作后保存为手动顺序，无需提前切换。首次移动以当前显示顺序为准，搜索只调整已知相关身份，分页外条目保留原有位置；只持久化排序身份。当前会话整行使用浅色底和描边高亮。来源图标和文字保留身份差异，搜索同时匹配项目名称、目录、会话标题和来源。读取中、读取失败与空列表应分别呈现，不能用「暂无会话」代替读取失败。

会话先展示近期一页，点击“加载更多会话”继续读取；搜索在服务端覆盖旧摘要，不只过滤当前屏幕。大量非匹配记录会分段扫描，仍可继续加载时不显示最终“无结果”。归档页、其他目录和命令面板遵守相同浏览方式。项目名称变更后搜索结果随之更新。

未归属记录通过更多菜单中的「其他目录」按需发现，零项目也能使用。可信目录在条目下显示，可点击“加为项目”预填表单；没有可信目录的摘要不提供猜测入口。项目映射变化后同步更新归属，避免同一条目继续留在其他目录。

会话列表随应用加载和应用内操作自动更新，普通列表及归档页均不提供常驻刷新按钮。只有读取失败时在错误处提供重试；列表变化不替换当前对话内容，也不重新获取模型目录。

新建会话先确定项目与 CLI，实际发送才创建原生会话。消息成功发送后，本页会话立即出现在所属工作区；原生 id 和摘要到来后按工作区与 CLI 身份合并，不生成重复条目。运行失败也能从该行返回本页内容；原生摘要尚未出现的条目不提供管理或手动排序，其临时身份不写入持久排序。此补充导航仅存在于本次页面，不代替原生持久化。三种 CLI 均可进入输入区；历史由对应适配器读取，失败在读取位置说明。

中央标题上方提供已打开会话的标签条，包含 CLI 图标、标题、状态和关闭按钮，可拖动重排、键盘切换，过多时横向滚动。关闭标签不删除原生会话、不停止任务，草稿和后台结果仍可找回；关闭或归档当前会话后选择相邻标签。插件或归档页上方仍可点击标签返回对话。标签只保留在本次应用运行期间。输入区只显示来源图标和具体型号，完整目录与原生 id 可在右栏查看。

## 4. 对话主区

### 4.1 历史与流式事件

历史与新回合使用一致的消息与工具行。用户消息使用靠右的圆角气泡，助手正文直接排版；工具收起时以单行展示动作、截断参数、状态和耗时，公开说明、完整参数和结果放在展开内容中。读取/搜索组同样保持单行，窄窗优先保留失败与未完成状态。文本、代码、工具参数与结果均来自原生事件；读取类工具可合组，审批、执行和失败保持独立。

正文宽度根据中央列计算，目标宽度为 `clamp(680px, 64cqw, 920px)`，实际不超过可用区域；输入框外沿比正文宽 32px。打开右栏后仍保持消息与输入的共同轴线，长路径和代码不能撑破布局。

实时回合需要支持跟随底部和回到底部；用户向上浏览时不强制跳回。展开工具详情、长代码块和布局变化后保持合理滚动位置。长列表的实现预算见[架构](../engineering/architecture.md)。

对话右侧提供用户消息刻度，悬停预览提问，点击定位对应用户消息；方向键与 Home/End 可切换刻度后按 Enter 跳转。刻度按实际视口高亮，长会话只挂载可见窗口，滚动或键盘能访问其余提问。主动跳转暂停贴底跟随；“回到底部”在对话与轨迹中都使用实体主题背景，避免正文透出。

加载中、空历史、读取失败与旧版本返回的不可回放状态分别处理。切换会话先取消旧读取并隔离迟到结果；失败在原位置解释并允许重试。Antigravity 已接入原生服务历史读取，不能继续固定显示“历史暂不能回放”。

不展示独立的「本轮改动」汇总、并排 diff 或行内评论；工具自身报告的路径和动作正常展示。

Claude 已有会话在对话视图切换旁提供“子代理”入口。打开后按需列出原生子代理，可切换查看其对话或轨迹并继续加载；步骤详情在独立弹窗内显示。子代理记录不插入主对话，不改变主会话统计、草稿、分叉点或右栏选择。

### 4.2 执行轨迹与用量

“对话 / 轨迹”共用同一会话内容。轨迹按用户轮次排列步骤，显示类型、执行内容、状态和已有耗时；命令、文件、读取、搜索、MCP、审批等保持原生顺序，未知步骤显示为活动，不伪装成工具。长回合逐步骤虚拟化，选中行在右栏查看详细输入、输出或错误；未处理审批仍可在轨迹中直接答复，底部保留输入和停止按钮。

输入框外下方将统计作为一组居中排列，左侧为最新一轮已有的平均 tok/s 和耗时，右侧为上下文用量；两侧位置固定，缺失的数据用“—”表示。点击可展开 token 分项，轨迹中保留历史各轮完整统计。新轮运行期间不沿用上一轮速度。输出量与计时属于同一范围、且没有失败时才显示速度；悬停及详情解释回合或步骤平均口径，缺少计时不补零，旧会话缺少统计时不恢复虚构速度。累计费用不混入单轮统计。

上下文按钮位于输入框外下方，显示最近报告的已用量、窗口和占比圆环，并保留百分比；达到 90% 时使用警示色，超过窗口时圆环封顶但百分比保留实际值。有效窗口可用于计算比例，详情说明原生来源。用量或窗口未报告时对应项显示横线，无报告时保留“上下文 —”入口。压缩是一次整理上下文的操作，只有正在压缩时在底部显示进度；完成、失败和未确认结果留在轨迹与详情，不代替用量和窗口。Antigravity 历史可读取最近生成元数据中的上下文估计；实时 headless 尚无等价报告，不用累计输入 token 推算当前占用。

轨迹提供「全部 / 上下文 / 用户 / 工具 / 助手」筛选，每条以单行排列图标、角色、动作摘要、状态和耗时，长文本截断并可打开全文详情；默认行高约 36px，统计也以单行摘要呈现。筛选保留原生顺序和轮次；上下文只有最近用量报告和已有压缩事件，不伪装成 CLI 未提供的完整提示词。思考、回复、活动和统计归于助手，工具与审批归于工具，实际失败状态继续保留。

### 4.3 输入与原生参数

输入区采用统一圆角容器，底栏左侧放技能与命令、权限，右侧放模型、推理强度及圆形发送/停止按钮；原生上下文与用量摘要位于容器下方。发送需要明确操作；输入法组字时不提交，忙碌时避免重复发起同一会话回合。

模型和推理强度默认沿用原生值；菜单优先采用原生报告，未报告时仅按精确型号补充有依据的档位。选中会话即读取缓存，首次打开模型或强度菜单且无缓存时才调用原生发现；打开已有缓存不显示整块加载提示。Claude 模型菜单单独提供“默认窗口 / 1M”，后缀由用户选择或继承原生配置；打开菜单不自动开启，切换保留已选强度。`[1m]` 原样发送，按钮另显示 1M 标记，实际占用仍采用原生报告。

模型菜单先列少量可见候选并保留当前选择，超过首批数量时通过“搜索可见模型”查找名称或真实型号；长结果按需展开。可见范围在设置中按 CLI 选择，当前型号即使未勾选也保留，避免隐式切换模型。检索只使用已有缓存，不重新发现账号或发送请求；键盘可选中结果，关闭后返回模型按钮焦点。

模型入口只显示 CLI 图标和具体型号，不重复拼接 CLI 名称或目录标签；能解析别名时显示配置对应的型号，发送仍保留 CLI 原始选择值。菜单中的 CLI 用图标切换，名称保留在悬停提示和可访问标签中。当前原生配置直接勾选对应型号；没有型号证据时只显示图标，不生成“默认模型”等占位选项。“重置模型”放在“更多模型操作”，空目录仍可手填。推理强度优先显示显式选择或适用于当前型号的配置档位，未知时只保留强度图标；明确不支持时隐藏入口。菜单直接显示档位和已知选中值，只有手动选择后才显示“重置强度”。菜单只列原生报告或精确适配的档位，原生 `auto` 与不传覆盖参数分别处理。错误只显示对应模型原因，技能警告留在技能入口；目录失效时提供“更换工作区目录”。应用启动、切项目和斜杠补全不自动检查账号。

### 4.4 运行、审批与结束

运行中在输入框上方持续展示本轮阶段与已用时间，对话和轨迹共用。准备、等待模型响应、思考、生成回复、工具执行、等待批准和停止按本轮事件推导，结束后清除；旧回合工具与审批不影响新回合。工具卡片显示中文动作，并在原生提供时显示公开说明或进度文字；未提供的思考正文或工具说明不补造。停止可覆盖准备和生成阶段。Claude/Codex 工具审批只展示 CLI 实际提出的请求，批准、拒绝与取消的结果绑定正确回合。Antigravity 显示原生权限模式与软拒提示，不使用无效的批准按钮。

运行与页面选择分开：任务进行中仍可查看另一会话、切项目、新建并发送其他任务，或进入插件与归档页面。左侧后台入口显示运行、等待批准和未读结果，原生 id 尚未返回时也可点击找回或单独停止；窄窗以图标入口保留访问。草稿和对话/轨迹选择随会话恢复，同一会话不能重复发送。项目目录修改和移除只锁定正在使用该项目的任务，不阻止普通导航。

正常结束、报错、断开和中断分别呈现。停止后保留已产生的内容，不编造成功结果；网络恢复不自动再次发送。能否跨连接接回在途回合须由实现与验证证明，不能仅凭「已重连」宣称恢复。

分叉与删除等操作只有在对应原生能力已接入且会话空闲时出现；删除明确二次确认，分叉使用原生结束点，不承诺回滚文件。

每个会话的“更多”菜单依据服务端能力显示重命名、创建分支、归档和删除，键盘到达该行时入口可见。统一归档页合并 Codex 原生归档与 Claude/Antigravity 工作台归档；后两者保留 CLI 记录，仅从工作台活动列表移出。归档后先恢复再续聊；删除确认说明实际影响的会话及子记录。操作完成刷新同来源列表，迟到结果不抢占当前选择，其他项目的首次加载不能因查询取消而停住。未归属条目沿用添加项目后管理的流程。

## 5. 设置

Codex 模型设置将“上下文窗口”和“自动压缩阈值”分别显示为数字输入，单位均为 tokens；清空恢复原生默认，不把 Claude 的 1M 选择复用到其他 CLI。

设置分清产品偏好和 CLI 原生配置。默认 CLI、主题等属于工作台；模型、权限、Skills、MCP 和原生插件属于对应 CLI。

模型页的“对话菜单中的模型”属于本机工作台偏好，按 CLI 勾选并自动保存，支持搜索、全部隐藏与恢复全部。未设置范围时展示全部已获取候选；设置范围后，新获取型号不会自动加入。当前型号继续可见，筛选不修改原生默认、模型目录或已有会话参数。显示范围保存后立即应用，重启可读回；保存冲突需重新读取，迟到响应不覆盖较新的设置。

设置左侧按通用设置、模型与连接、运行环境分类；模型页顶部横向选择三个 CLI，图标与名称同行。通用设置提供深浅主题卡片。常用模型、地址与认证优先展示，模型别名映射折叠；高级入口改称“CLI 配置文件”和“CLI 环境变量”，分别编辑原生文件与工作台启动进程的附加变量，返回保留所在分类。服务器资源采样沿用 SSH Console 默认值。左栏底部直接打开设置，不再弹出额外主题菜单；服务器档案留在 SSH Console 内。

配置按「这个 CLI 支持哪些项」呈现，再显示其真实作用域。没有项目级配置的项不画项目级空表单；目录级规则、运行时参数也不能强行合并成用户/项目两层。原生配置读取失败、文件不存在和空白文件分别说明。

原生资源目录按 CLI 和真实作用域列出文件，Claude 的个人项目配置与共享项目配置分开。目录页面不读取文件正文；点击“显示并编辑文件”后才展示完整内容，包括其中的敏感值。离开清空正文，保存冲突保留草稿并提供重读；只读资源和不可读取原因清楚标注。

模型表单只修改对应用户原生配置，秘密只显示“已设置”状态，空输入不擦除已有 Key；清除有独立操作。切换分类、重新读取或退出时保护未保存修改，保存期间不重复提交。模型能力缓存随保存失效，旧请求的成功、失败和忙碌状态不能影响新配置。

Codex 高级设置将认证选项称为“凭据获取方式”：直接填写 API Key、从环境变量读取 API Key、沿用 Codex 登录，选择一种即可。环境变量输入只填写变量名；原生认证可来自 ChatGPT 或 API Key 登录。来源及变量名的帮助直接展示，保留已有高级认证的原生编辑入口；不要求重复填写密钥。

常态页面不堆叠实现细节或防御性说明。字段补充信息放帮助提示，复杂配置解释折叠；只有实际失败、未保存修改和删除范围需要直接提醒。

模型页统一提供连接、模型候选和对应的运行参数，API Key 用圆点占位并提供更换、清除；Antigravity 的 Gemini 地址与密钥直接在同页填写。模型目录复用缓存，获取前若有改动，按钮明确写“保存并获取模型”。名称、推理强度和窗口按各 CLI 支持的字段展示，不做无效通用字段。仅内容区滚动，页脚保存按钮固定，焦点环位于输入框内。模型建议及固定选项使用统一浮层，允许保留自定义型号；浮层挂在所属原生对话框内，自动翻转和限高，不参与表单布局。第一次 Esc 关闭列表，下一次退出设置，方向键浏览不提前写回配置。

原始配置、模型别名及启动环境收进高级设置；规则和 Skill 仍在原生根目录中创建。高级启动变量保持原有语义，已有会话可在空闲时重新启动 CLI。常用页面不罗列变量来源与继承状态。

## 6. SSH Console 与工作台插件

SSH Console 从侧栏打开主页面，返回对话保留原会话。页面采用「服务器标签 → 概览/进程/文件/终端」两层导航，多服务器状态分开。项目只给首次默认服务器与目录，之后切项目不抢走已选服务器。

页面只有一份 SSH Console 标题，其下为服务器操作工具栏。Slurm、文件写操作与旧终端集中在控制台内显式打开的「项目服务器工具」，不占用对话右栏；它仍是旧项目绑定业务，不能描述成独立服务器能力。打开工具后焦点进入可操作入口，返回或按 Esc 关闭后回到触发按钮。

- 概览中的 GPU 利用率与显存占用分别显示，进程页保留完整命令信息。
- 文件页只读进入目录和预览文本，清楚标识截断；目标范围见需求 F6。
- 终端支持独立 PTY、多标签和分屏；切页与关闭页面不等于关闭 shell，断开与关闭终端才明确结束对应会话。
- 终端中的 `Ctrl+F`（或 `Meta+F`）打开本机查找，支持前后跳转；关闭后清除选中并把焦点交回终端。查找不发送 SSH 指令。
- 停用 SSH Console 会结束控制台及「项目服务器工具」中的终端，确认提示须说明这一范围；清除已结束的旧标签并取消待绑定操作，重新启用后由用户新建终端。服务器档案、保存的凭据、项目与旧任务记录保留。页面隐藏不等于插件停用。

插件管理显示包身份、版本、权限和启用状态；从本地目录安装后先停用，明确启用才可使用。外部 v1 插件显示受控静态页面，可贡献命令并访问获准的设置与项目摘要；它不包含通用后端执行入口。CLI 的原生插件继续在各自配置入口管理。

## 7. 命令与反馈

`Ctrl+K` 包含项目、会话、设置、侧栏收起与已启用插件声明的命令。插件命令打开对应页面并交付命令 id；旧服务器面板不再作为对话区快捷入口，未实现的同步或版本功能不出现在菜单中。

快捷命令支持上下选择、Enter 执行和 Esc 退出，输入法组字期间不触发。成功的本机读取保持安静；失败在操作位置给出原因，连接断开时提供明确恢复入口。涉及不可逆原生操作的确认应写明对象和范围。

## 会话权限入口

权限模式放在输入区底栏左侧，模型与推理强度位于右侧；菜单按当前 CLI 展示原生模式，已选模式显示其名称，未确认有效值时仅显示权限图标，不写“原生权限”或“沿用原生配置”。选项说明移到悬停提示，手动选择后提供“重置权限”，不改动原生默认执行语义。选择按 CLI 与具体原生会话保存，刷新或重启后重新打开仍可恢复；新会话不继承其他会话的选择。修改保存后直接用于下一次发送，不出现成功或刷新/重启提示。运行、读取或保存权限期间禁改；读写失败提供重试并暂缓发送，切换页面不会把迟到结果写入另一会话。Codex 用户显式点“重置权限”时读取并恢复当前配置；它与不作选择的原生续接分开。
