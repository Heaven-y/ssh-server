## 0. 参考与视觉规范

### 0.1 参考项目

参考T3 Code的对话中心、CloudCLI的项目/会话组织、Vibe Kanban的对话/diff/终端分区和[Pebrel](https://github.com/Kuddev/pebrel)的紧凑终端标签与分屏。只借鉴交互和布局，配色自定，不逐像素对齐参考截图。

### 0.2 视觉方向

采用 UI UX Pro Max 中适合桌面工具的 Minimalism & Swiss Style 规则，结合实际产品截图：

- 风格：极简（Minimalism & Swiss）——高对比、网格对齐、少装饰；信息密度高（间距 8–32px）。
- 颜色使用双主题语义变量，首次默认为浅色；下方为深色主题配色与对比度测量（浅色主题的验收数值另行记录）。深色正文、辅助文字和状态色对background/card/muted的最小对比度分别为12.45、5.89、7.50以上，可交互边界border-strong最小3.33:1：

| 语义 | 值 | 用途 |
|---|---|---|
| background | `#101114` | 页面背景 |
| card | `#18191E` | 卡片、面板 |
| muted / muted-foreground | `#282A32` / `#A2A6B3` | 次要背景与文字 |
| foreground | `#EEEFF3` | 主要文字 |
| border | `#30323B` | 装饰性分隔线 |
| border-strong | `#747A89` | 输入框、按钮等可交互边界 |
| accent / accent-foreground | `#9CB5FF` / `#152044` | 主操作与焦点；按钮文字对比度 7.92:1 |
| success / warning | `#81CBA4` / `#F0C77F` | 成功 / 待确认，不与主要操作混用 |
| destructive | `#E66F7A` | 危险操作与错误边界 |
| destructive-foreground | `#FFB0B8` | 错误文字 |

- 字体：正文 IBM Plex Sans，中文明确回退到系统中文字体；代码 / 终端 / 路径 JetBrains Mono。字体通过 fontsource 本地打包，不从 Google Fonts 加载。对话正文 15px，行高 28px。
- 图标：Lucide（SVG），不用 emoji 当图标。
- 动效：只用细微过渡（150–250ms），遵守 `prefers-reduced-motion`。

- ≥1600px右侧资源/文件横排形成四列；1280–1599px右侧上下停靠，960–1279px默认自动收起左栏、右侧仍上下。左栏默认240px、200–320px可调；紧凑窗口允许主动展开，不改写用户持久折叠偏好。通常对话最小480px，窄屏主动展开左栏时允许320px。
- 资源与文件各自开关，不互斥、不叠盖、不自由拖动；标题保留“复位”和“收起”，真正关闭文件另有入口。分隔线支持鼠标与键盘调节，隐藏的分隔线不可聚焦。
- 单资源宽默认320px（280–640）、单文件420px（360–960）、窄右区420px（360–720）、宽双工具总宽760px（646–1400）；横向资源比例默认43%、纵向40%，均限定20–80%。这些模式分别记忆，实际尺寸受可用空间与最小值约束；只记录用户调整，复位只恢复工具尺寸，不改主题与左栏宽度。
- 默认浅色，主题按钮记住选择；最小支持960px。≥1280px有工作区时初始打开资源，960–1279px首屏不强开，文件按需打开；主动打开不变成modal。
- 收起、调尺寸、切方向和切聊天工作区不改变内容父子树，不释放已打开文件、固定文件目标或PTY。“关闭文件面板”只收起面板，不涉及写入确认。
- 终端继续使用对话主区的独立底部宿主，隐藏不释放PTY；同步、版本及危险确认仍按需打开，渲染结果见[最新验收](../guides/ui-usability-optimization-acceptance.md)。

## 2. 顶栏

顶栏保留深浅主题、当前工作区及其SSH状态、同步与版本摘要状态、“搜索与操作”、终端、资源、文件、服务器和设置，没有资源横条。同步与版本以紧凑状态项显示工作区摘要：正常态低饱和、需要注意才着色，点击打开原详情，立即同步与保存版本等快捷操作入口不变。空间不足时按内容自然换行，工作区名称允许省略，SSH状态与操作按钮保持分离。正常本机WebSocket连接不占常驻位置，连接中/断开时保留提示和“重连网页”。资源/文件独立切换，可同时开启。“搜索与操作”和Ctrl+K/Cmd+K共用命令面板，不与聊天“+”或`/`能力混用。服务器入口统一档案与认证，选择只看详情；编辑、保存、连接、断开分别触发，不新增列表轮询。向导只选档案和目录。

| 元素 | 说明 |
|---|---|
| 工作区 | 显示当前工作区；通过左栏或“搜索与操作”切换 |
| 服务器 | 全局档案管理、显式SSH config导入、认证/断开、共享工作区影响；没有工作区也可使用 |
| 深浅主题 | 带文字及可访问名称的切换按钮，保留已存选择 |
| SSH状态 | 显示当前工作区服务器的真实连接状态，复用原连接详情与查询，不新增第二套状态轮询 |
| 网页WebSocket | 正常连接静默；连接中/断开提示与“重连网页”保留 |
| 工作区同步状态 | 位于对话状态栏，显示就绪/同步中/待确认/失败，按需打开原同步详情 |
| 工作区版本摘要 | 位于对话状态栏，打开版本与“保存版本”；本地文件只读，网页不提供保存 |
| 资源 / 文件 | 独立开关与状态，可同时停靠；不在顶部显示指标 |
| 设置 | 打开设置页 |

## 3. 左侧栏

工作区每行提供“移除工作区”，弹窗显示配置与保留内容，默认不勾选确认。有活动、待恢复文件任务或同步仍在运行时显示阻断原因；失败保留目标，“重新核对”清除确认并重新读取。成功关闭所属文件面板与终端，清理所属缓存；仅当当前选择仍为目标时选择剩余第一项或空，侧栏常驻状态区播报结果。

Codex与Claude独立读取、分别成组。每组置顶优先，再按更新时间排列；行内只显示单行标题、置顶图标和简洁运行状态。完整标题、Agent和时间保留在可访问名称/提示中，模型证据在输入区与单动作详情按需查看。“更多”菜单包含重命名、置顶/取消置顶、复制会话链接、分叉会话和删除，Codex另有归档。归档只查询Codex，成功空状态为“暂无归档会话”。

删除勾选确认原生记录及相关子会话的影响；等待期间禁用重复提交与关闭，失败保留条目并提供重新读取。归档只提供恢复/删除，恢复后才能继续或改名，不隐式恢复。删除/归档成功只清空仍匹配目标的对话，迟到结果不影响当前选择；运行中的目标不允许管理。

置顶只保存当前浏览器按工作区/Agent/原生ID隔离的排序信息。复制链接包含本网页路径和`#session?workspace=…&agent=…&id=…`，不含正文或凭据；剪贴板拒绝时显示可选中的手动复制框。首次和hash导航校验目标，当前运行/管理中不跳转，迟到历史不覆盖当前选择。

“分叉会话”从原生末尾创建独立会话；时间线可信已结束位置另有“从此处分叉”。确认框说明保留范围与源会话不变，忙碌期间禁用重复提交与正常关闭。成功刷新对应列表，只有用户未切换选择且当前空闲时打开新会话；请求未确认时提示先读列表核对，不自动重试。

- 工作区列表，当前工作区高亮；"新建工作区"打开向导。
- 会话行不显示模型名或“模型未报告”占位；行尾显示相对更新时间，完整时间保留在提示中，组标题使用对应 Agent 品牌图标。内部Agent、原生ID及模型证据保留。选中和运行状态简洁，标题单行省略但可查看全文。
- 顶栏“搜索与操作”和`Ctrl+K`/`Cmd+K`打开同一网页命令面板，按需搜索工作区、会话及常用动作；不同于Agent的`/`命令。

`Cmd+K`同样可用，IME组字、xterm内部和已有原生模态保留快捷键。资源/文件非模态面板不锁住聊天焦点。保存版本只打开说明表单；立即同步只在ready且无忙/错误时委托原流程，其余状态打开详情；不包含自动确认、删除或覆盖命令。
- 会话“更多”按钮只选动作；改名、分叉与危险操作各用独立确认视图，原生成功后刷新对应来源。
- 可切换显示已归档会话。

## 4. 对话区

新建会话才允许选Agent，发送、读取历史和已有会话保持固定。模型与effort按Agent独立保留；无显式覆盖时沿用原生，不猜目录首项。初始/新会话强度为`high`，两Agent均可直接选五档，Codex保留目录扩展值；“自动”省略强度。主菜单只列真实模型候选，“更多模型操作”提供清除覆盖、手填与刷新。目录失败不锁强度，Claude合法枚举直接进入SDK。

审批提交后显示等待后端确认并禁用重复操作，处理完成、超时或取消后关闭按钮。准备阶段已可点击停止；运行时收到停止后等待原生确认，无响应时 5 秒强停。未返回结果的工具显示“结果未返回 / 需核对实际执行状态”，轮次结束不推断执行成功。网页断线后运行继续，但立即拒绝已有审批；重连不自动发起新轮次。切换历史时取消旧读取，加载期间禁止发送，迟到结果不覆盖当前选择。

输入底栏左侧“+”打开“技能与命令”dialog，与`/`补全共用可执行过滤；需要会话的命令仍显示前置条件，不可用能力通过按需入口查看原因。区分未接入、原生接口限制、等价网页操作与临时读取失败。选择后显示可移除标签；搜索框Enter不发送聊天，失败不伪装为空清单。连接不接受时保留输入和选择，切工作区/Agent/会话清理选择；管理中仍禁止向同目标发送。

上下文按钮与模型、强度位于同一输入控制行，仅在存在原生报告时显示；按需展开Popover查看原生窗口、用量来源、模型和压缩详情，无报告时整颗胶囊隐藏。Claude标“原生估计”，Codex标“原生统计/估算”，比例取自原生报告。压缩状态独立于用量显示：进行中、完成、失败、中断或未确认照常展示，历史不复活旧压缩。

消息开头输入 `/` 自动展开当前 Agent 候选，浮层贴近输入框并保留焦点。上下方向键移动高亮，Enter 只确认选择，再次 Enter 才发送；Esc 收起并保留原文，Shift+Enter 换行。输入法组字时不触发选择或发送。只补全首个命令名，路径、正文和参数区保持普通编辑；光标移回命令名后可按方向键重新展开，选择保留已有参数。候选最多显示 20 项，继续输入缩小范围，名称、别名、来源和说明均可搜索。

- 对话顶部只保留标题、Agent与工作区；输入区模型触发器按已选覆盖、最近报告、会话配置回退，均无数据时显示“默认模型”，不以“未报告”占位。宽圆角输入上部16px正文/28px行高，下部左“+”、右模型/强度/上下文及圆形发送或停止，窄空间允许控制行换行。选项Enter不发送，正文、Shift+Enter、补全和组字保护保持，不增加附件入口。
- 模型证据：Claude列表未提供模型时不逐条加载正文；打开历史复用主会话助手的模型报告，排除子代理和合成消息。Codex列表模型标为“原生会话模型”，不是逐轮执行遥测。实际报告与原生配置分开，刷新列表的新原生模型优先于旧历史缓存，缺失时可回退已观察值；不回填用户覆盖输入。
- 消息类型：
  - 用户消息、助手文本（Markdown，代码高亮）、思考摘要（默认折叠）；
  - 工具调用卡片：工具名、关键参数、状态、结果（默认折叠，长输出可展开）。连续至少两项明确读取/搜索工具合并成“读取/搜索了N项”，始终显示完成、失败、运行或未返回计数，内部保留每项原结果；不根据shell猜测只读，`remote_exec`及审批始终独立；
  - 最近所属轮次改动聚合卡片：文件数和不可用/不完整状态，点击打开本轮 diff；不从工具报告推断文件改动；
  - 权限请求卡片：说明 + 批准 / 拒绝；
  - 同步待确认卡片：待删除的服务器文件数 + 查看 / 确认 / 拒绝。
  - 原生已结束分叉边界：只由服务端可信`forkPoint`产生，提供“从此处分叉”，未报告位置不补造按钮。
- 长对话使用动态高度虚拟列表；贴底时跟随流式增长，用户上翻时停止并显示“回到底部”。工具/思考/分组的展开状态在虚拟卸载后保留；切换或重开会话清空视图选择，首次原生会话id不重置列表。
- 正文Enter发送，Shift+Enter换行，运行时发送切换为“停止”；空输入、加载或不可用时保留对应禁用状态。
- 技能选择和`/`候选只使用当前Agent实际目录，限制按需查看；参数区、路径和普通正文不触发命令补全。
- 模型与强度菜单支持Enter选择、Escape收起和焦点恢复；手填模型Enter不发送正文，空白或“默认”等占位词不可当模型ID，恢复原生使用明确的清除覆盖操作。
- 展示官方接口提供的上下文用量、正在压缩 / 已压缩等状态；用量无数据时整体隐藏，压缩状态照常显示。手动压缩走对应官方能力，网页不自建压缩逻辑。
- 用户通过普通消息手动要求查询训练进度或分析结果；需要统计、绘图时，Agent 通过远程执行卡片展示服务器已有 Python / 项目环境的命令与输出，必要的小结果在当前对话中展示或引用。等待期间不显示自动任务完成通知、不自动追加结果分析消息。资源面板刷新与对话状态独立。

## 5. 停靠工具面板

| 区域 / 入口 | 内容 |
|---|---|
| 停靠：资源 | 友好目标、逐卡GPU、CPU/内存/磁盘及Slurm；资源采样与作业刷新独立 |
| 停靠：文件 | 本地代码/改动/服务器文件子视图；固定文件工作区、只读预览和远端通道 |
| 文件内：改动 | 本轮或相对上次版本的差异、单文件放弃与行反馈 |
| 同步详情 | 从状态栏按需打开，沿用立即同步、删除确认、冲突与工作区规则 |
| 对话底部：终端 | 多标签/分屏xterm与固定PTY，不随停靠尺寸、方向或收起重建 |
| 版本详情 | 当前改动、保存版本、分页历史、差异与恢复预览 |

### 5.1 文件区与本地只读查看

- AI 是主要编辑者；文件面板用于偶尔修改脚本或配置，复用成熟组件，不提供完整 IDE。
- “本地代码”浏览同步范围内文件，条目可只读查看内容或切到 diff；“服务器文件”按第 5.4 节管理远端实际目录，不受本地文件过滤规则隐藏大文件，也不自动下载。
- 两端文件列表以单击选择、双击/Enter打开、方向键/Home/End导航和右键为主。本地明确提供“返回工作区根目录”，仅打开目录/文件，不增加本地CRUD。选择色与焦点使用已有`accent`语义变量。
- 查看区显示路径、语言与“只读”标记；复用 CodeMirror 提供语法高亮、搜索和“重新读取文件”，没有保存按钮。
- 本地正文只来自最近一次读取：外部程序或同步改动后由用户显式重新读取，不自动覆盖正在显示的内容。
- 读取期间文件被替换时丢弃该次快照并给出提示；同一文件再次读取沿用同一只读子树。

文件面板跨断点保留同一内容子树，打开时固定工作区，切聊天不迁移已打开文件。独立收起只隐藏，真正关闭后重开才可使用新工作区；打开资源不影响文件可见性。隐藏时停止目录GET并取消在途请求，恢复后按用户操作重新读取。查看范围为同步阈值与2 MiB中较小值，仅普通UTF-8文本；目录条目截断时提示可进入子目录或在服务器文件视图核对，面板内没有按路径打开的常驻表单。本地改写由 Agent、外部编辑器或同步流程完成，网页不登记编辑状态、不挂起同步，也不出现“未保存”提示。

版本详情显示当前改动、排除项、1–200字符保存说明、分页历史、差异及单文件/整版本恢复预览。确认绑定将覆盖的未跟踪文件；本地恢复与同步分别反馈，删除仍在同步详情确认。版本操作期间禁用关闭与重复提交，保留编辑缓冲。

改动视图可选择最近20轮的本地净差异或相对上次保存版本，使用按需加载的成熟diff（默认并排、可切换单列对照）和高对比双主题；截断/解析失败保留有界原文本并提示。点击行号即在行下展开评论框加入独立待发送反馈，侧别/行号手动表单删除，锚点自动捕获；普通发送成功才消费；切选择清理，首次原生id不清理。单文件放弃需预览与勾选，独立暂存或陈旧指纹拒绝，不覆盖编辑缓冲，服务器删除另行确认。其他工作区文件不能加入反馈。

### 5.2 资源与Slurm作业

- 资源面板按友好服务器/工作区摘要、逐卡GPU、CPU/内存/项目磁盘、Slurm排序。“目标与采样详情”保留实际别名、路径和样本，不展示节点进程表。
- GPU显示利用率、显存已用/总量及可用的温度/功耗；CPU取两次样本，缺失时留空。资源区域独立蓝/青/少量紫色，橙红仅用于警告/错误，高利用率不自动告警。
- 默认5秒资源检查；仅资源面板自身隐藏、页面隐藏或网页断线时暂停并取消网页请求，恢复仍只有一个控制器。打开、收起或调整文件面板不影响资源/Slurm的active；失败保留最近资源并标过期，更新时间、不可用与暂停状态附文字说明。
- Slurm只在首次激活和点击“刷新作业”时读取，重新展开已有快照不会自动再查；与资源时间和错误独立。已知档案/认证变化清除旧作业并要求手动刷新，迟到结果不串到其他目标。
- 唯一查询为当前SSH账号的固定格式`squeue`文本，8秒、stdout/stderr合计512 KiB，最多200行作业输出。非空输出补匹配列宽的英文表头，等宽纯文本区域最大高480px、内部双向滚动；超字节拒绝整份，超行准确标“仅显示前200行”。无警告空输出为“暂无作业”；成功警告保留，警告空输出为“本次查询没有返回内容”。不可用与失败仍可操作。
- 共享账号列出的是该账号可见作业，含他人任务；不增加自动作业轮询、全用户查询、节点遍历、提交、取消、安装或训练完成通知。
- 对话、终端、同步与资源分别反馈，不用整页遮罩阻止无关活动。常态仅简述当前SSH节点与CPU需两次采样，详细目标按需查看。

### 5.3 终端交互

终端固定目标、独立通道与稳定窗格取舍见[设计决策第5节](../engineering/decisions.md#5-终端参考的使用方式)。顶栏首次打开才加载模块；主区和底部各至少240px，底部默认40%，高度不足480px时终端沿用自己的覆盖层，不改变资源/文件的非模态性质。

- 顶栏入口打开底部宽区，与文件面板并存；紧凑标签栏提供新建、左右/上下分屏、关闭、最大化及收起，窗格分隔线可拖动和键盘调整。首版每标签最多 4 个窗格，空间不足时仅显示活动窗格，其他连接保持。
- 标签绑定打开时的工作区，各窗格固定显示 Host 和“起始目录”，该路径是标签的起始位置、不随 shell 内 `cd` 变化；切换聊天保持原目标。新增分屏使用原标签目标，另一工作区由明确入口新建终端。
- 收起和切换标签保留终端；关闭窗格确认将断开该 shell。断线立即停用输入，保留已显示内容，“新建连接”明确创建新 shell，不重发旧输入或承诺恢复原进程。
- 复制、粘贴、输入法及 PTY 尺寸同步以实际程序验证；多行粘贴先预览确认。用户手动 shell 不经过 Agent 黑名单或执行前同步，不调用模型；资源面板无需先打开 `nvitop`。

### 5.4 服务器文件视图（操作、下载与同步协调已接入）

沿用独立文件停靠区，不新增顶层导航。内部保留“本地代码 / 服务器文件 / 改动”，切换保留各自路径、选择与编辑缓冲。服务器视图明确显示Host、工作区与实际远端路径，长路径在区内换行或滚动，不撑宽整页；宽窄窗口使用同一个内容子树。

打开文件面板即登记目标，首次切服务器视图才建立SSH文件通道。跨断点保留同一内容子树，旧Host绑定在重连后仍指向原目标。操作先预检，再明确确认；冲突或不兼容名称阻止派发。远端完成与同步待恢复分别显示，核对与恢复保留部分结果，并提供重放与取消说明。

下载只使用保存API：选择本地位置后流式写入，展示实际字节进度，文件关闭成功后才显示完成；取消或写入失败标为失败。无保存API时说明当前浏览器不支持，不提供备用链接。选择器卸载后忽略迟到结果，不再创建文件。

```text
文件 · demo-workspace                   [复位] [收起] [关闭文件面板]
[本地代码] [服务器文件] [改动]
my-server · ~/projects/demo                   [刷新]
项目 / outputs /                             [输入路径]
名称（文件夹优先）                    [新建文件夹] [?]
run1/                                           …
weights.bin                         100 GB       …
右键/Shift+F10：重命名、移动、复制、删除、属性、下载
拖动到目录后打开原有预检与明确确认，不直接执行
```

- 目录展开按需取下一层，分批显示；提供返回上级、返回工作区和路径输入，离开工作区目录时标注“工作区外”。固定显示同步根和实际浏览路径，切目录不修改同步配置、不触发同步。点文件和点目录始终按服务返回的当前页展示；文件大小与目录体积区分，后者仅点击后计算。同步范围标记与最近同步结果分开，范围内不表示两端已一致。
- 文件/目录行只紧凑显示名称与大小；选择不自动展开属性。“更多”在hover/focus时显现，右键、Shift+F10/菜单键均可打开。重命名、移动、复制、删除、复制路径、下载和属性集中在菜单，顶部仅保留导航、刷新、新建和帮助，不常驻一排操作按钮。
- 拖入目录表示同一服务器内移动，突出目标并在提交前展示源/目标路径；不把拖动解释为下载或跨视图本机传输。“移动到…”与“复制到…”复用目录选择器，默认定位当前目录，可输入同一 SSH 目标的其他路径。
- 单击选择、双击或 Enter 打开目录；F2 重命名、Delete 打开删除确认、Ctrl+Shift+N 新建目录，Alt 拖动选择复制。操作窗口优先聚焦路径输入，嵌套目录选择器关闭后恢复触发按钮焦点。任务折叠区独立显示状态、取消和结果核对，详情内部滚动，目录列表保留最小高度；关闭面板后已提交任务继续运行，重开可查询。隐藏时停止任务轮询。
- 删除、覆盖和影响同步范围的操作使用有明确动词的确认区，显示主机、路径、同名冲突及本地关联；同名目标默认拒绝，不自动合并目录。未保存编辑或同步冲突提供处理入口。
- 仅服务器文件可查看元数据并直接操作；同步范围内可通过“在本地代码中查看”跳转只读预览。打开未同步的大文件只显示信息及下载入口，不自动加载正文。下载明确提示不会自动纳入同步/版本管理。
- 面板底部按操作显示排队、执行中、完成、失败、部分完成或结果未确认；服务器操作和后续同步分开反馈，无可靠总量时使用不定进度。关闭面板后通过文件入口状态标记重新查看；取消只作用于所选任务，不关闭共享 SSH 连接。
- 目录递归操作的影响范围在用户发起操作后核对；普通浏览不预先遍历整个项目。断线后禁用新提交，保留待核对结果，重连不自动重试移动、复制或删除。
- 当前层按文件夹优先、名称自然排序，分页前收集有界完整快照，不递归。向导与服务器文件每页200项，超过10000项或4 MiB元数据拒绝不完整列表并提示进入具体子目录。SFTP读取完成即释放句柄；本地代码仍最多扫描5000项、展示500项，排序后截取并标明截断。

## 6. 新建工作区向导

1. 本地文件夹：优先草稿路径、无值从home开始，逐级浏览或输入路径；成功浏览的路径显示“待使用目录”，下一步直接采用，不再点“使用此目录”。加载或失败时不沿用旧结果。
2. 服务器：只选择已保存档案；没有档案或需要重新认证时打开统一“服务器”界面，返回保留向导草稿。
3. 服务器目录：优先草稿路径或home，逐级浏览（每层显示子目录，体积点击后计算）或输入路径；“进入”仅导航，下一步直接采用当前成功浏览路径。
4. 同步规则：扩展名列表、大小阈值；点击“预览”显示将同步的文件数与大小、被排除的大文件统计（前 N 个），不在打开向导时自动扫描大目录。
5. 确认：汇总双方目录、非空与.git状态；说明首次双端合并和冲突保留。验证当前快照成功、勾选核对后才可“创建并初始化同步”；创建期间禁止重复提交与正常关闭，完成后分别反馈配置已保存和首次同步结果。

确认页显示“验证通过：目录与连接可用”，不显示截止时刻。5分钟一次性票由后端控制，过期就地重验、保留草稿、清除勾选，需重新确认；服务端不透明绑定核对连接身份、凭据代次及目录/输入快照，变更时要求手动核对。

服务器管理中的新增/导入显式保存，取消向导不删除已保存档案；同步规则由“应用同步规则”提交。返回、改变目标或关闭撤销旧验证；两端分页每页200项，预览上限20000项、排除例子最多20项，.git不计入统计。

明文密码不写工作区配置、日志、URL或浏览器持久存储。普通认证流程仍可留空复用已保存密码；主动断开保留加密凭据，取消保存才移除保存项并断开，失败保留状态并可重试。目录、同步、命令和终端共用连接参数，不要求重复配置。

统一服务器界面以列表展示友好名称、目标、认证方式、公开连接/凭据状态和引用数量；选中只查看详情。点击“编辑服务器”才按需读取已保存密码并填回表单，默认掩码，眼睛按钮可查看/隐藏和修改。取消、关闭、换目标清理表单，迟到结果不回填；换目标后重新读取密码。保存核验档案快照、凭据版本与活动锁，不强行断开。

新增密码档案可同时保存密码，已有密码可在编辑表单明确确认后修改。保存与SSH连接分离，不自动认证；保存后选中档案并引导下一步核对指纹和连接。普通列表与长期查询缓存不含密码正文。

## 7. 设置页

- 分类：对话与模型、文件同步、服务器资源、运行环境。复用Ariakit Tabs，只挂载当前分类内容，但外层共用草稿、revision和保存状态；切类不丢值，隐藏错误自动切类聚焦。保存/409、离开/Esc/重读/原生视图切换的未保存保护不变。
- 对话默认只保留默认Agent，模型默认由原生配置管理，当前显式选择在输入区；磁盘定点退休`defaultModels`而不重置其他偏好。全局同步过滤/大小只作为新工作区模板，已有工作区从同步摘要“规则”独立保存；自动拉取间隔仍为全局偏好。
- 命令规则：默认保护保持可见，自定义折叠为“高级：自定义拦截（可选 · N条）”，通常无需填写。教程说明程序基本名、字符串字面匹配、大小写与误拦，不执行示例或自动增加规则。最多20条，保存校验错误自动展开并定位字段，修正后不收起；恢复默认、禁用警告、409和未保存保护继续。仅约束Agent远程入口。
- 本机运行环境：工具全部可用时主界面不显示成功条或占位；缺失/失败显示简短状态和“查看设置”。设置内保留Node.js、Claude Code、Codex、Git和rclone的可执行状态、版本、检测时间、重新检测与缺失工具官方指引。检测只判断工具是否可执行，不自动安装。
- 原生配置：入口只放在“对话与模型”分类内，分别提供“修改 Claude 配置”和“修改 Codex 配置”，切到独立CodeMirror视图且同时只挂一个dialog；仅编辑约定Claude `settings.json`和Codex `config.toml`。模板只改空白草稿，取消不创建，显式保存才写入；不放假密钥、未核实端点或强制模型。填写说明按需展开，读取失败、外部创建409、语法/目录身份与原子写入保护保留。保存不代表认证或模型验证。

自动文件同步默认60秒（5–300），显式保存值不迁移；原3秒同步状态查询、手动/执行前后/保存后同步不变。资源检查默认5秒（2–60）、超时8秒（2–30），过期阈值取15秒和3倍间隔较大值。产品分类共用草稿/revision，失败和409保留输入；新工作区只复制一次过滤/大小快照，不覆盖已有规则。

## 8. 状态与反馈

- 正常状态安静，空状态短句，详细帮助按需展开。删除、覆盖、冲突、未保存、认证/目标变化和真实错误仍在需要决策的位置说明。
- 空状态：没有工作区时显示引导；没有会话时显示"新会话"按钮。
- 加载：目录浏览、同步、测试连接显示进度，可取消。
- 错误：SSH状态与连接详情在顶栏，网页WebSocket异常另行提示和重连；密码失效请求重新输入。同步失败在原详情显示，阻断执行时明确未执行；资源失败标过期/不可用，分叉及保存的未确认结果提供核对入口。
- 危险操作（删除会话、确认删除服务器文件、恢复历史）一律二次确认，并写明影响范围。
- 文件保存、版本保存、远端文件操作和服务器同步分别反馈；远端完成但同步失败不显示整体完成。任务提交成功只显示启动信息或任务 ID，不标注训练完成。
- 对话、终端、资源刷新和同步分别反馈进行中 / 失败状态。同一会话正在回复时禁止重复发送；同一工作区同步请求排队执行，远程命令等待执行前同步时明确显示“等待同步”，失败或待确认时明确显示“未执行”。

## 9. 可访问性

- 所有操作可用键盘完成，焦点可见。资源/文件停靠区不设焦点陷阱或整页遮罩；分隔线具名并支持方向键，收起后不可聚焦，复位入口可达。真正确认/设置模态才限制焦点，关闭回到触发元素；子dialog取消不误收起外层。
- 状态不只用颜色表示，同时有图标和文字。
- 流式回复区域使用 `aria-live="polite"`；图标按钮带可读的名称。
- 资源数值的频繁刷新不逐条触发屏幕阅读器播报；连接失败、采样失败和过期等状态变化提供可读提示。
- 文字与背景对比度满足 WCAG AA。完整的无障碍验证需要用辅助技术手动测试。
