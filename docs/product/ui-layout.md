# 界面布局

## 0. 参考与视觉规范

### 0.1 参考项目（2026-10 调研）

只借鉴交互和布局思路，不复制代码；AGPL 项目（CloudCLI、opcode）仅作对照。

| 项目 | 规模 / 许可 | 借鉴点 |
|---|---|---|
| pingdotgg/t3code | 约 2.4 万星 / MIT | 本机 Agent 的网页控制台；React + Base UI + Tailwind 4 + zustand 的前端组合 |
| BloopAI/vibe-kanban | 约 2.8 万星 / Apache-2.0 | 工作区 = 对话 + 终端 + diff；diff 行内评论回传给 Agent；可调分栏 |
| NanmiCoder/cc-haha | 约 1.5 万星 / MIT | 本轮改动逐文件 review；权限请求在界面内审批；会话全局搜索 |
| jakemor/kanna | 约 700 星 | 按项目分组的会话列表与运行状态；连续工具调用折叠成组 |
| siteboon/claudecodeui（CloudCLI） | 约 1.4 万星 / AGPL-3.0 | 三栏布局、会话列表、工具调用渲染（仅对照） |

不采用：看板、多 Agent 编排、内置浏览器、分屏双会话、IM 集成、图片生成等与本项目目标无关的功能。

### 0.2 视觉方向

由 ui-ux-pro-max 检索得出（查询 "developer tool dashboard dark"，密度 8、动效 2），只采用其中适合工具类应用的部分：

- 风格：极简（Minimalism & Swiss）——高对比、网格对齐、少装饰；信息密度高（间距 8–32px）。
- 颜色（暗色初始值，实现时用语义变量）。已校验：文字对背景、卡片的对比度均 ≥ 4.5:1；`border` 只有约 2.1–2.4:1，只能用于装饰性分隔，可交互组件的边框改用 `border-strong`（≥ 3:1）：

| 语义 | 值 | 用途 |
|---|---|---|
| background | `#0F172A` | 页面背景 |
| card | `#1B2336` | 卡片、面板 |
| muted / muted-foreground | `#272F42` / `#94A3B8` | 次要背景与文字 |
| foreground | `#F8FAFC` | 主要文字 |
| border | `#475569` | 装饰性分隔线（面板、卡片之间） |
| border-strong | `#6B7A90` | 输入框、按钮等可交互组件的边框（对背景 4.09:1、对卡片 3.59:1） |
| accent | `#22C55E` | 运行中、成功、主要操作 |
| destructive | `#EF4444` | 删除、失败（图标与边框；在卡片上作文字时对比度不足 4.5:1） |
| destructive-foreground | `#FCA5A5` | 卡片、背景上的错误文字（对卡片约 5.6:1） |

- 字体：正文 IBM Plex Sans，代码 / 终端 / 路径 JetBrains Mono；通过 fontsource 本地打包，不从 Google Fonts 加载。
- 图标：Lucide（SVG），不用 emoji 当图标。
- 动效：只用细微过渡（150–250ms），遵守 `prefers-reduced-motion`。

## 1. 主界面

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ ssh-server │ 工作区: demo ▾ │ ● my-server 已连接 │ ⟳ 已同步 12:03 │ 未保存 3 [保存] │ ⚙ │
├───────────────┬──────────────────────────────────────┬───────────────────┤
│ 工作区        │ 会话标题                 Claude ▾ 模型 ▾│ [改动][同步][终端][历史] │
│ ▸ demo        │                                      │                   │
│ ▸ exp-2       │  用户：把学习率改成 1e-4 然后跑一下    │  改动               │
│ + 新建工作区   │                                      │  M train.py  +2 -1 │
│               │  助手：已修改 train.py ……             │  M cfg.yaml  +1 -1 │
│ 会话（demo）   │   ▸ 编辑 train.py（diff）              │                   │
│ ● 调参 (C)    │   ▸ remote_exec: python train.py     │  [diff 预览区域]    │
│ ○ 数据检查 (X) │     退出码 0 · 输出 120 行 ▾          │                   │
│ + 新会话       │                                      │                   │
│               │  ┌ 需要确认：删除服务器文件 2 个 ┐      │                   │
│               │  └ [查看] [确认] [拒绝] ───────┘      │                   │
│               ├──────────────────────────────────────┤                   │
│               │ 输入消息…                    [发送/停止]│                   │
└───────────────┴──────────────────────────────────────┴───────────────────┘
```

- 三栏：左侧 240px，可折叠；中间对话区自适应；右侧面板 360–520px，可收起。分栏宽度可拖动并记住。
- 默认暗色主题，可切换亮色。视觉规范见第 0 节。
- 最小支持宽度 1280px；更窄时右侧面板改为覆盖层。

## 2. 顶栏

| 元素 | 说明 |
|---|---|
| 工作区切换 | 下拉选择 |
| 连接状态 | 已连接 / 连接中 / 断开（图标 + 文字，不只靠颜色），点击可重连 |
| 同步状态 | 已同步（时间）/ 同步中 / 有待确认 / 失败；点击打开"同步"面板 |
| 未保存 | 改动文件数 + "保存"按钮；没有改动时按钮禁用 |
| 设置 | 打开设置页 |

## 3. 左侧栏

- 工作区列表，当前工作区高亮；"新建工作区"打开向导。
- 当前工作区的会话列表：标题、Agent 标记（C = Claude，X = Codex）、状态（空闲 / 运行中 / 等待确认 / 失败，图标 + 文字）、最近时间。
- `Ctrl+K` 打开命令面板：搜索并切换工作区、会话，执行常用操作（新会话、保存、立即同步、打开终端）。
- 会话右键或"…"菜单：重命名、删除；Codex 会话另有归档。删除弹出确认框。
- 可切换显示已归档会话。

## 4. 对话区

- 顶部：会话标题；Agent 选择（新会话可选，已有会话锁定）；模型选择（默认"跟随本地配置"，可下拉或手动输入）；Codex 另有推理强度。实际使用的模型名显示在标题旁。
- 消息类型：
  - 用户消息、助手文本（Markdown，代码高亮）、思考摘要（默认折叠）；
  - 工具调用卡片：工具名、关键参数、状态、结果（默认折叠，长输出可展开）。连续的读取、搜索类调用合并成一组（"读取了 5 个文件"），`remote_exec` 始终单独显示；
  - 文件编辑卡片：文件名、增删行数，点击在右侧面板显示 diff；
  - 权限请求卡片：说明 + 批准 / 拒绝；
  - 同步待确认卡片：待删除的服务器文件数 + 查看 / 确认 / 拒绝。
- 长对话使用虚拟列表；流式输出时自动滚动到底部，用户上翻时停止自动滚动并显示"回到底部"。
- 输入框：Enter 发送，Shift+Enter 换行；回复进行中按钮变为"停止"。

## 5. 右侧面板

| 标签 | 内容 |
|---|---|
| 改动 | 本轮及相对上次保存的改动文件列表，逐个文件查看 diff；可放弃单个文件的改动；可在 diff 行上写评论，作为下一条消息发给 Agent |
| 同步 | 最近同步时间与结果；待确认删除列表（逐个或全部确认 / 拒绝）；冲突列表；"立即同步"按钮；当前排除规则摘要 |
| 终端 | 多标签服务器终端（xterm.js），默认进入工作区服务器目录；可新建、关闭标签 |
| 历史 | 保存记录列表；点开查看该次的 diff；恢复整次或单个文件 |

## 6. 新建工作区向导

1. 本地文件夹：逐级浏览或输入路径；显示是否为空、是否已是 git 仓库。
2. 服务器：从 `~/.ssh/config` 的 Host 中选择，点击"测试连接"。
3. 服务器目录：逐级浏览（每层显示子目录，体积点击后计算）或输入路径。
4. 同步规则：扩展名列表、大小阈值；点击"预览"显示将同步的文件数与大小、被排除的大文件统计（前 N 个）。
5. 确认：汇总信息；本地文件夹非空时提示首次同步的处理方式；点击"创建"开始首次同步并显示进度。

## 7. 设置页

- 默认值：Agent、模型（默认"跟随本地配置"）、同步大小阈值、扩展名列表、定时拉取间隔。
- 命令黑名单：默认规则列表（可停用）、自定义规则；可按工作区覆盖。
- 显示本机检测结果：Claude Code、Codex、git、rclone 是否可用及版本。

## 8. 状态与反馈

- 空状态：没有工作区时显示引导；没有会话时显示"新会话"按钮。
- 加载：目录浏览、同步、测试连接显示进度，可取消。
- 错误：SSH 断开在顶栏和对话区显示横幅并提供重连；同步失败在"同步"面板显示原因；操作结果用短暂提示（toast）。
- 危险操作（删除会话、确认删除服务器文件、恢复历史）一律二次确认，并写明影响范围。

## 9. 可访问性

- 所有操作可用键盘完成，焦点可见；弹窗打开时焦点限制在弹窗内，关闭后回到触发元素。
- 状态不只用颜色表示，同时有图标和文字。
- 流式回复区域使用 `aria-live="polite"`；图标按钮带可读的名称。
- 文字与背景对比度满足 WCAG AA。完整的无障碍验证需要用辅助技术手动测试。
