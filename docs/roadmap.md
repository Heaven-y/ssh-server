## 当前交付：独立浮动面板与资料精简

- 资源与文件为两个独立非模态浮动面板，各有顶栏开关和收起入口，可同时存在；标题拖动、右下角缩放，方向键及Shift辅助移动/调整大小，视口约束与复位入口保持可达。
- 文件沿用`fileWidth`偏好（360–960px），资源默认420px；其他位置和大小只在当前页面分别记忆。保留960px最小支持、明暗主题和240px侧栏（200–320px），≥1280px有工作区时默认资源打开，较窄首屏不强开。
- 隐藏不卸载CodeMirror、dirty缓冲、固定文件工作区、编辑登记/WS或PTY；真正关闭文件才确认释放。资源与Slurm只根据资源面板自身可见性及页面/连接状态激活，打开文件不隐藏资源或停止采样。
- D40的默认high、五档直选、自动省略强度、单一文本Slurm、点文件默认显示和简洁提示保持。页面自动文件同步默认/回退60秒，原3秒状态查询与手动、执行前后同步不变。
- 经批准移除已由现行说明覆盖的旧spec/plan、重复验收和旧图；关键取舍与操作注意事项并入当前决策和开发指南，不新增一套过程材料。

规则见[D41](engineering/decisions.md#d41-资源与文件独立浮动面板及资料精简2026-10-09)。**独立面板的最终实现与验证结论统一以[最新验收](guides/ui-usability-optimization-acceptance.md)为准**；D40拆分前的测试、交互与截图不作为新面板通过证明，本页不提前填写最终数字。

## 运行与证据边界

- 旧/坏状态保留原文件并明确拒绝，不自动迁移、清空或重放远端任务；当前格式的恢复与核对继续提供。
- Windows rclone不支持含反斜杠的远端根，产品提前拒绝，不自动替换字符或升级工具。
- 下载要求当前桌面Edge/Chrome的File System Access API，不提供下载管理器备用路径。
- Slurm仅当前账号首次/手动文本查询，不遍历集群、不自动安装或管理作业；共享账号不等于个人任务，SSH节点不等于计算节点。
- 本轮没有新增真实付费模型、真实集群文本Slurm成功、OS输入法或CI证据。旧实例未重启，隔离验收构建不覆盖其dist；实际检查范围由最新验收记录。
- 不包含完整IDE、多用户、服务器软件安装、独立安装器、自动检测训练完成或自动分析。

后续只围绕可复现的具体问题修复并做影响范围验证；新增功能须有明确需求。提交、合并与推送另须授权，遵循[两级no-ff分支规则](guides/dev-environment.md#16-本仓库的-git-分支与提交)。
