## DSH 界面对齐与逻辑审查

左侧工作区导航贯穿窗口，上方集中新建会话、插件、SSH Console 和更多入口。中央显示对话，右栏默认关闭，打开后展示会话信息；三个 CLI 按时间混排，用来源图标与输入区选项区分。灰阶、字号、消息密度、输入区和图标轨道对照本机 DSH 安装版调整。

SSH Console 从左上打开中央独立页面。旧 Slurm、绑定式终端和文件写任务收进“项目服务器工具”；原数据与接口继续保留。切页面暂停观察并保留终端，停用插件则结束其终端、取消待打开操作并清旧标签，防止再次启用时自动重开 shell。

整体验证中发现并修复：

- 会话发现过早按项目根筛选，遗漏其他目录与项目子目录；现在全局枚举摘要后统一裁决归属，零项目也能发现其他目录。
- 子目录会话读取、续接、管理及能力刷新使用错误工作目录；现在复核原生 cwd，能力缓存区分当前会话。
- 添加、换目录或移除项目后旧摘要归属残留；现在取消在途列表并刷新归属，成功来源的会话在其他来源失败时仍保留。
- 启动环境并发解析可能越过运行实例预算；解析完成后再次核对上限。
- 原生文件保存或创建与项目换目录竞争；写入全程持项目租约。
- SSH 页面重复标题、旧工具返回时焦点丢失，以及窄窗开右栏后左栏实际未收缩。
- 插件导航和命令能在回合中隐藏停止及审批；现与会话导航共用运行门禁，结束后再打开。

本轮完整覆盖率检查 1,229 项通过、5 项跳过，语句 89%、分支 81.96%、函数 89.57%、行 92.39%，全局、shared 与安全模块门槛均通过。类型、ESLint、格式、文档、重复率以及前端和桌面构建已核对；最终覆盖率以两个 worker 运行，避免与成包压缩争用资源。此前暴露的旧返回值断言、异步等待和失败后清理问题均已修正，没有放宽超时或覆盖率。

隔离浏览器验证三 CLI 合成发送、Codex/Antigravity 原生 id 续接、停止、运行保护、页面切换草稿、零项目会话发现与添加后的即时刷新。800/960/1280/1600 宽度无横向溢出，窄窗折叠与拖动恢复符合约束；浅深主题、代码块与 1,600 条消息虚拟滚动已检查。旧右栏展开偏好不会触发 SSH 请求。

## 启动日志与会话自动更新

针对验收目录报出的主进程 EPIPE，隔离 Electron 重现了父进程关闭输出管道后日志写入失败。桌面启动和后端日志统一经过专用输出，处理管道的异步 EPIPE；真实桌面关闭两条输出管道后仍能渲染窗口并正常退出。未拦截业务异常，也未改动真实会话。

按用户明确的单端使用方式，移除普通列表和归档页的刷新入口，以及文件监听、版本轮询和对应接口。应用首次读取原生摘要，新会话取得 id、回合结束和管理操作后自动更新。原生正文保持单份；旧监听实现和上一轮证据可从 `9fda867` 查询，不把此前隐藏按钮描述成已经删除机制。

关联回归分范围运行，共 123 项通过；覆盖三 CLI 新会话及回合结束时取消旧摘要、管理后更新、项目变更、启动退出与日志异常。类型、范围 ESLint、格式、文档及网页/桌面构建通过。隔离页面完成发送→归档→恢复→分支→删除分支，保留源会话；普通列表和归档页均无刷新入口，空闲超过原轮询周期没有会话请求。桌面验收确认两条管道实际返回 EPIPE 后仍正常退出。没有真实模型请求、真实会话修改、版本递增或成包。

## 模型缓存、原生差异与设置简化

模型目录持久缓存，菜单与设置共用，重启后继续复用；用户可手动获取，存在草稿时先明确保存再获取。模型与技能的就绪状态分开，防止模型缓存恢复后技能列表一直为空。设置统一为连接、模型及运行参数；认证变量与原始文件收进高级，修复嵌套滚动和焦点边框裁切。

Claude 提供原生模型名称与默认强度，Codex 提供服务名称、默认强度和数字窗口；Antigravity 在同页配置 Gemini URL/Key、自定义模型名称和窗口，原生 customModels 使用对象映射。没有制造通用上下文或认证字段。原生对照与限制见[模型与连接](engineering/native-configuration.md#模型与服务连接)。

Antigravity 终端闪现查明为 models 加载真实 MCP，以及后台更新器另开控制台。改为临时 profile/cwd、只复制模型设置并跳过临时更新检查，隔离本机返回 14 个内置加 1 个自定义模型；可见控制台监测为零，模型端点禁用，源配置不变。Claude/Codex 的显示名、窗口和强度也用合成原生配置核对，没有发送真实模型请求。

关联缓存、配置事务、字段、路由与组件回归通过；审查修复已有 Antigravity 自定义模型改名时误写真实 ID、空白 Key 擦除、保存冲突后的连接回滚及过时模型显示测试。类型、范围 ESLint、格式、文档、重复率和网页/桌面构建通过。隔离页面验证三 CLI 保存与密钥遮蔽、菜单和设置共用模型目录，800/960/1280 宽度无横向溢出且保存按钮可见。Claude 验收的一个合成临时目录清理被自动审批策略拒绝，未重试删除；不影响实现或验证结论。

## 执行轨迹与用量

Claude 接入主循环本轮 usage、工具进度与公开 thinking；计时在原生 result 到达时截止。Codex 使用累计快照的可靠差分，恢复首轮、重置、压缩、失败、中断和迟到报告不补造用量；扩展搜索、计划、动态工具及协作活动。Antigravity 采用明确步骤数据，历史读取经原生服务校验目录与身份并受分页预算限制；真实隔离回复历史已读取到用量和上下文估计。

审查修复跨轮复用工具 ID 覆盖旧记录、重复统计、取消被标成功、Claude 子代理结果提前结束父轮，以及中断后的迟到结果进入下一轮等问题。Antigravity 成功结果之后的退出清理独立处理，实际 close 前保持占用，未成功发出清理信号后的异常退出仍失败。

用量与轨迹的实现及来源区别见[接入说明](engineering/cli-observability.md)，实施前评估保留在 `3c8d0ac`。原生公开字段不足时仍不承诺精确实时生成速度、旧会话速度或完整子代理历史。

- 输入法已覆盖组字事件回归，实际 Windows 输入法交互仍需现场确认。
- 前端构建仍有大 chunk 提示；终端和编辑器按需加载，未提高阈值隐藏。外部插件尚无任意后端执行或通用系统权限。
