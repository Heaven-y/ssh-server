## 当前基线

M1 已有 Electron 开窗与退出编排，开发入口为 `npm run dev:desktop`。项目添加、移除、服务器绑定和解绑可从界面使用，项目改名只有接口。旧目录和字段经过迁移保留有效记录，离线目录仍可管理。

三个 CLI 可探测并枚举会话，统一归属到本地项目；Claude 与 Codex 历史可读，Antigravity 显示不可回放说明。当前主区已接通输入与实时事件，模型/强度默认不覆盖原生配置；跨会话切换清除旧参数，同会话重读失败保留已收到内容。

项目侧栏已接入 Claude/Codex 的重命名、分叉与确认删除，Codex 另有按项目展开的归档列表与恢复。管理目标取自来源行，迟到结果不抢占新选择；删除或归档当前记录后清除模型和强度覆盖。Antigravity 仍不显示未接入的管理动作。

现有 SSH 仍是项目绑定式服务：终端、资源、Slurm 与服务器文件读写暂时保留。它尚不是自有插件系统，也不等同于目标 SSH Console 的独立主页面。M2 不提前迁移这一部分。

## M2 验证重点

2026-11-04 对话阶段记录：完整覆盖率运行 1096 通过、5 跳过，行覆盖率 93.39%；随后补齐 Codex 在 Electron 下的脚本解释器回归，相关启动测试 23 项通过。全项目类型、ESLint、格式、文档、重复率检查，以及前端和桌面构建通过。独立审查发现的四项问题均修复并定向复查。

浏览器使用隔离 Fastify 和合成运行器：三 CLI 新建入口、Claude 审批、Codex 续接、Antigravity 新建与不可回放续接、停止、运行中导航保护、仅显式刷新能力通过；960/1280/1600 宽度无页面横向溢出，浅深主题已检查。这里未调用真实模型或连接真实 SSH；Antigravity 本机帮助与官方 headless 协议已核对，实际账号/端点的回合仍未验证。

随后完成会话管理：后端路由 59 项通过；前端 11 个相关测试文件共 113 项，最后一轮 112 项通过、1 项缓存异步通知断言修正后，侧栏 16 项定向复验通过。关联类型、ESLint、格式、文档与重复率检查，以及前端和桌面构建通过；后端及前后端交叉审查未发现待修复缺陷。沿用上一阶段完整基线，不重复运行未受影响的全量测试。

管理页面使用临时项目与合成 provider 验收：重命名、分叉选中、确认删除、归档与恢复、跨项目操作、归档加载/失败重试和键盘焦点均通过。960/1280/1600 宽度无页面横向溢出，浅深主题已检查；控制台仅出现人为注入的归档 503。没有修改真实原生记录，模拟结果不代替原生 SDK/RPC 的真实写入验收。

当前限制：同窗口运行时暂不切会话；断线请求中断并由用户重读历史，不提供事件续传。Antigravity 每轮启动进程并用原生 id 续接，结构化模型/命令目录暂未接入，用户可用原生默认或手填模型；不提供其历史正文、交互审批、分叉或删除。后续按原生能力逐项完善，不把未支持功能列为已交付。

- 每个 CLI 的新建与续接都使用正确的原生会话身份；切换会话时旧结果不串到新页面。
- 文本和工具事件实时显示，准备阶段与运行阶段可中断，结束或失败解除占用。
- Claude/Codex 的审批按原生请求路由；Antigravity 按实际权限机制展示模式和软拒原因，不伪造批准按钮。
- 未显式选择参数时使用原生默认，显式选择正确传到对应 CLI；界面版本和实际驱动来源一致。
- 进入应用、打开新会话、切项目、重新连接不自动发 prompt 或联网刷新能力。
- 受控事件与假 CLI 可以验证协议和界面；原生真实发送需明确授权，结果另记，不从模拟通过推导真实可用。

## 后续边界

M3 不强制用户级/项目级两层模板，按各 CLI 真实配置面逐项实现。启动环境只补足原生配置不能表达的需要；不引入新的模型默认覆盖层。

M4 采用 AgentDeck 自有接口，**没有 DSH 包兼容计划**。首个 SSH Console 对照现有插件的服务器标签、概览/进程/只读文件/终端体验。现有 Slurm、文件写操作、服务器档案和加密密码如何迁移，在该阶段明确，不凭文档整理直接删除用户数据。

每个阶段完成时更新实际交付与证据范围。历史失败和未验证状态保留在对应提交中，不用新版文档追认；新增代码按关联范围检查，阶段整合满足完整质量门禁。
