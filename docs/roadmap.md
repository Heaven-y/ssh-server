## 当前待办与暂缓项

| 项目 | 状态 | 继续条件 |
|---|---|---|
| 当前 URL/Key 的完整模型任务 | 外部条件阻塞 | Claude 本次请求预扣额度不足；Codex 用户并发上限；AGY 辅助模型无可用渠道。条件变化后再做有界复验，不自动替换模型或改写服务响应 |
| 账号登录模式 | 用户明确暂缓 | 当前使用 URL/Key；不以此模式成功推定账号登录通过 |
| AGY 实时上下文与逐 token 速度 | 未接入可靠数据源 | headless 未提供足够数据；内部流订阅的运行实例归属、计量范围仍需证明，不能用历史估计或字符数补造 |
| Windows 外部会话链接 | 源码已接入，系统验收待做 | 新安装包获准制作后验证协议注册、冷启动、运行中唤起和卸载清理；现存旧包不能用于证明新功能 |
| 新安装包、签名、发布及更新 | 暂缓 | 发布范围和版本须另行确认；本地合并授权不包含推送或打包 |
| CLI 与环境兼容扩展 | 按需补验 | 新版本、其他输入法和服务器环境单独留证；Claude Windows 8.3 别名目录仍有原生存储键差异 |
| 未连接成功的 SSH 目标 | 一台连接失败 | 网络或认证条件恢复后再查；不跳过主机信任，不据另一台成功推定全部目标通过 |
