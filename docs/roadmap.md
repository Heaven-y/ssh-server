## DSH 界面对齐与逻辑审查

左侧工作区导航贯穿窗口，上方集中新建会话、插件、SSH Console 和更多入口。中央显示对话，右栏默认关闭，打开后展示会话信息；三个 CLI 按时间混排，用来源图标与输入区选项区分。灰阶、字号、消息密度、输入区和图标轨道对照本机 DSH 安装版调整。

SSH Console 从左上打开中央独立页面。旧 Slurm、绑定式终端和文件写任务收进“项目服务器工具”；原数据与接口继续保留。切页面暂停观察并保留终端，停用插件则结束其终端、取消待打开操作并清旧标签，防止再次启用时自动重开 shell。

整体验证中发现并修复：

- 会话发现过早按项目根筛选，遗漏其他目录与项目子目录；现在全局枚举摘要后统一裁决归属，零项目也能发现其他目录。
- 子目录会话读取、续接、管理及能力刷新使用错误工作目录；现在复核原生 cwd，能力缓存区分当前会话。
- 添加、换目录或移除项目后旧摘要归属残留；现在取消在途列表并刷新归属，成功来源的会话在其他来源失败时仍保留。
- 启动环境并发解析可能越过运行实例预算；解析完成后再次核对上限。
- 原生文件保存或创建与项目换目录竞争；写入全程持项目租约。
- SSH 页面重复标题、旧工具返回时焦点丢失，以及窄窗开右栏后左栏实际未收缩。
- 插件导航和命令能在回合中隐藏停止及审批；现与会话导航共用运行门禁，结束后再打开。

本轮完整覆盖率检查 1,229 项通过、5 项跳过，语句 89%、分支 81.96%、函数 89.57%、行 92.39%，全局、shared 与安全模块门槛均通过。类型、ESLint、格式、文档、重复率以及前端和桌面构建已核对；最终覆盖率以两个 worker 运行，避免与成包压缩争用资源。此前暴露的旧返回值断言、异步等待和失败后清理问题均已修正，没有放宽超时或覆盖率。

隔离浏览器验证三 CLI 合成发送、Codex/Antigravity 原生 id 续接、停止、运行保护、页面切换草稿、零项目会话发现与添加后的即时刷新。800/960/1280/1600 宽度无横向溢出，窄窗折叠与拖动恢复符合约束；浅深主题、代码块与 1,600 条消息虚拟滚动已检查。旧右栏展开偏好不会触发 SSH 请求。

0.1.1 的最终解压应用和便携版均通过隔离启动、单实例、退出与端口释放验收，成品已在本地生成。NSIS 安装与卸载机制的候选包范围见[安装记录说明](guides/local-installation.md)；本轮没有签名或发布。真实模型和真实服务器仍按下方边界保留未验证状态。

## 仍需真实环境确认的边界

- 三 CLI 的真实账号、模型、原生写入、MCP 和原生插件安装未作为本轮验收输入，不能由合成成功推定全部兼容。
- Antigravity 历史正文不可回放，结构化模型/命令目录尚未接入；可以按原生 id 续聊，使用原生默认或显式模型。没有伪造审批、分叉、删除接口。
- 当前窗口运行期间保留当前会话；断线请求中断，不自动重发，也不提供跨连接事件续传或后台多会话界面。
- SSH 资源采样依赖 Linux/procps/NVIDIA，文件浏览依赖 SFTP；缺工具如实提示，不自动安装。真实 SSH/Slurm 成功不在本轮证据中。
- 输入法已覆盖组字事件回归，实际 Windows 输入法交互仍需现场确认。
- 前端构建仍有大 chunk 提示；终端和编辑器按需加载，未提高阈值隐藏。外部插件尚无任意后端执行或通用系统权限。

## 交付方式

本轮按用户授权合入 `main`，同步 `main` 与 `feat/native-cli-workbench`；不创建线上版本或发布安装包。小功能分支按 `--no-ff` 整合后清理，大功能分支保留。正式签名、公开发布、自动更新均暂缓。

源码使用 `npm.cmd run dev:desktop` 查看最新界面；已生成 exe 不会随源码自动更新。本地安装与手动升级方式见[安装指南](guides/local-installation.md)。
