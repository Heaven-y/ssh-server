# 路线图

更新日期：2026-11-03。功能与验收条件以[需求](product/requirements.md)为准，设计与取舍见[设计文档](superpowers/specs/2026-11-03-native-cli-workbench-design.md)，文档入口见[导航](README.md)。

## 产品转向

原主线「本地改代码 → rclone 双向同步 → 服务器上跑」整体移除。同步、版本、本地文件镜像三个域连同改动视图与行内反馈一并删除，不保留开关与兼容路径。新主线是**本机桌面应用，统一管理 Claude Code / Codex / Antigravity 的原生会话**；SSH 能力作为附带工具保留，范围与既有 ssh console 一致，仅移除文件下载。

产品名由 `ssh-server` 改为 **AgentDeck**（包作用域 `@agentdeck/*`，数据目录 `%LOCALAPPDATA%\AgentDeck`），旧数据一次性迁移。

## 运行边界

- 三个 CLI 都在自升级，接口随时会变。本应用跟着本机装的那一版走，按能力探测而非版本号判断；探测失败时该 CLI 标记不可用，其余照常工作。
- **不自动发请求**：能力目录只在点「刷新能力」时读取，模型请求只在点发送时发生。
- Antigravity 的历史轨迹是 protobuf 存储、没有公开 schema，因此只保证列出会话并能继续对话，不保证历史可回放；界面如实说明，不存副本、不伪造。
- 同一会话在外部进程（终端里的 CLI、桌面端）是否也被驱动无法可靠探测，这是能力边界，界面只呈现本应用自己的运行状态。
- 待移除：`remote-tools/`、`policy/` 与 shared 中对应的协议文件。
