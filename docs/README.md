## 适用规则

- 资源与文件按[D41](engineering/decisions.md#d41-资源与文件独立浮动面板及资料精简2026-10-09)呈现为两个独立非模态浮动面板，不再使用互斥右栏或窄屏模态。D40默认high、强度直选、单一文本Slurm和提示精简继续保留。
- 当前只维护一种正式业务路径和数据格式；不恢复旧API、迁移或下载备用分支。当前格式的重启恢复、取消、冲突与数据保护不是旧版本兼容。
- 经用户批准，已完成的设计/计划、重复验收、阶段路线图和旧图从仓库移除。仍有效的操作说明和关键取舍集中到上述文档；需复盘时查对应Git历史或本次已核验的清理前基线，不在仓库复制另一套历史材料。
- 历史事实不改写：D39、D40和独立面板的证据分别成立；拆分前通过不等于新面板最终通过。测试数字、截图与真实/受控范围只在最新验收中按实际运行记录，不能借历史CI宣称当前树通过。
- VS Code、CLI、系统选择器和OS输入法是可选检查手段。未观察的事实不写成通过，也不自行扩大为额外产品任务；实际问题按影响范围修复验证。
