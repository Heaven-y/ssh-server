## 适用规则

- 资源与文件按[D42](engineering/decisions.md#d42-停靠工作台会话操作与设置收敛2026-10-09)自适应停靠：宽屏四列、较窄右侧上下、更窄默认收起左栏。保留独立活动与编辑/PTY生命周期，替代D41自由浮窗而不删除其历史。
- 当前只维护一种正式业务路径和数据格式；不恢复旧API、迁移或下载备用分支。当前格式的重启恢复、取消、冲突与数据保护不是旧版本兼容。
- 经用户批准，重复设计/计划、验收流水和旧图可以精简；决策记录长期保留，不属于清理对象。独有理由和有效操作限制先并入现行说明，已提交旧资料通过Git历史查询，不以会话临时目录作为唯一追溯依据。
- 历史事实不改写：D39、D40、D41与D42分别使用各自证据；旧树通过不等于新功能通过。测试数字、截图与真实/受控范围只在最新验收中按实际运行记录，不能借历史CI宣称当前树通过。
- VS Code、CLI、系统选择器和OS输入法是可选检查手段。未观察的事实不写成通过，也不自行扩大为额外产品任务；实际问题按影响范围修复验证。
