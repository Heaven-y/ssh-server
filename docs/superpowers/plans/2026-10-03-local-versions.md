# 本地版本记录实施计划

设计见 [版本设计](../specs/2026-10-03-local-versions-design.md)。用户已授权合理决定并继续；当前功能分支实施，不推送。

1. 固定共享类型与 API 契约。
2. 后端独立实现 vcs Git 调用、状态/范围过滤、提交、历史/diff、恢复预览与执行，路由接入现有同步事务。
3. 前端实现状态摘要与按需版本面板：保存说明、历史分页、文件差异、恢复预览和同步反馈，保留已有编辑缓冲。
4. 审核核心目标后补真实临时 Git 仓库核心测试，核对已有暂存区、父仓库作用域、过滤和恢复安全。
5. 主线程完成 main/API 集成、受控浏览器和可用真实 SSH 复验，更新路线图与验收边界。
6. 修复实际问题，按完整阶段提交代码与文档。

所有权：后端子任务仅修改 apps/server/src/vcs、http/versions.routes.ts 和对应 tests；前端子任务仅修改 apps/web/src/features/versions；主线程负责 shared、web lib/api、App、server main、文档及集成。后端与前端同时按本契约实施；有接口变化先协商，不各自猜测。
