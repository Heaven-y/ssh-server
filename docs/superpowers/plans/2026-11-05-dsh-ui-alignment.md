# DSH 工作台界面对齐与整体验收

用户已明确要求按 DSH 布局和视觉直接实施，完成后整体审查并修复；已授权合入 main，推送 main 与 feat/native-cli-workbench。本轮不发布 Releases。

目标：左侧工作区导航从顶到底，顶部新会话/插件/SSH Console，中央对话，右侧按需打开；三 CLI 仅作为原生来源和能力差异。SSH Console 在中央独立面板，不能由默认服务器右栏代替。

依据：本机 DSH 0.2.2-rc.1 的可访问导航与安装包 UI 样式，以及用户的 dsh-plugin-ssh-console README。只复现布局、色值、控件密度与交互，沿用 AgentDeck 的数据及成熟组件，不引入 DSH 包兼容。

## 文件分工

- 主控：App、TopBar、WorkspaceLayout/Columns、右侧会话信息、旧工具移入 SSH Console 明确入口、偏好迁移、整合与浏览器验证。
- 导航：Sidebar、PluginNavigation、项目行及相应行为测试；统一按时间列会话，用 CLI 徽标区分来源。
- 视觉：主题、共享控件、聊天内容与输入区，对齐 DSH 灰阶和密度，保留参数及审批语义。
- 审查：后端会话/配置/插件/SSH 并发身份及生命周期，必要修复只覆盖可复现问题；最终交叉审查导航与全局组合。

## 约束与验证

- 首次以及旧偏好下均不自动打开服务器工具；浏览项目不得因此连接 SSH 或请求模型。
- 会话运行/准备/管理期间导航保护继续有效；插件切换不销毁会话和既有 PTY，回到会话恢复选中。
- DSH 左栏尺寸参考 264–420px，折叠图标轨道 56px，1024px 以下可自动收起；右栏默认关闭，隐藏不可聚焦且不占宽度。
- 旧 Slurm/文件写操作保留数据与显式入口，不能在默认对话页显示服务器提示。
- 使用临时项目与合成 CLI/SSH，核对三 CLI、面板开关、插件启停、焦点、迟到结果、960/1280/1600 和浅深主题；不动真实会话与服务器。
- 按影响范围测试；因全局样式/布局变化，最后扩大工程门禁并独立审查。修复后按实际影响复验，不无故重复全量。
