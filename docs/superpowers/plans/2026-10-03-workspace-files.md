# 工作区文件编辑实施计划

设计见 [文件编辑设计](../specs/2026-10-03-workspace-files-design.md)。用户已授权自主继续；在 feat/ssh-workflow 直接实施，按完整阶段提交，不推送。

状态：功能实现与受控验收已完成。13 项服务/路由核心测试、35 项关联测试、真实文件接口浏览器流程通过；实际 SSH 的 A13 复验与版本历史继续保留后续任务。详见 [验收记录](../../guides/workspace-files-acceptance.md)。

1. 固定共享类型；后端实现限定工作区的逐级列表、读取、revision 与原子保存路由；保存接入已有同步事务。
2. 前端复用 CodeMirror，增加脚本语言；文件面板按需加载并绑定工作区，保留草稿，处理冲突、关闭与页面离开。
3. 本地保存后调用已有同步接口，区分本地成功和同步结果，复核 revision 后展示服务器成功。
4. 审核核心目标后添加必要服务/路由测试，浏览器受控后端验证；按影响范围运行类型、lint、构建及关联测试。
5. 修复实际问题，更新路线图和验收记录，提交文件编辑阶段；版本历史保留后续独立阶段。

实现分工：后端服务/路由由同任务子代理负责；主线程负责共享类型、前端、main 接线、文档与集成验收。文件所有权不重叠。已有设置、同步与凭据内容不做无关改造。
