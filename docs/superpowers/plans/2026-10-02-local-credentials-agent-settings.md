# 本机凭据与原生 Agent 配置实施计划

> 用户已授权继续开发、验证及阶段提交；在当前分支内联实施，不推送。设计见 [本机凭据与配置](../specs/2026-10-02-local-credentials-agent-settings-design.md)。

## 阶段一：Windows 加密保存密码（已完成）

认证、保存、网页入口及取消生命周期已接入；最终 345 项测试和浏览器核心流程通过，边界见 [验收记录](../../guides/m2-acceptance.md#本轮保存凭据与目录收尾)。

1. 复用现有核心测试，按审查发现补充必要回归：真实 DPAPI 往返、磁盘无明文、目标绑定、密码认证后保存；断开保留、重新连接复用、后端重启、取消保存与认证失败失效。
2. 独立凭据存储仅接受实际目标摘要，用当前用户 DPAPI 加密，stdin 传递、无密码 argv；加密输出原子写入配置目录，不回退明文。
3. 连接解析器按代次读取保存项，避免断开、取消保存、目标变更和退出后迟到认证复活；主动断开暂停所有自动 SSH/rclone 重连，显式连接才恢复。
4. REST 返回保存可用性/是否保存/是否主动断开，不返回密码；成功认证和目录检查后才持久化。网络与目录错误保留已保存项，认证错误清除。
5. 网页增加可选保存勾选、已保存状态、复用连接；取消保存勾选清除保存项并断开，不设独立入口。密码不进入 React Query variables/cache；提交、失败、模式/目标变化、关闭和销毁清理临时字段。
6. 受控本机 SSH 与真实 DPAPI 验证，网页检查断开、取消保存、重连和输入清理；完成相关工程检查后单独提交。

## 阶段二：原生配置编辑（后续实施）

本次后续 Codex 验收临时使用用户提供的 `config_bq.toml`，实际路径仅通过运行时参数传入并复制到隔离测试 home；原文件不改写。正式实现始终按原生规则读取 `config.toml`，不把测试文件名作为产品默认。

1. 核对官方路径、目录环境变量及下一轮配置读取机制；正式 Codex 固定原生 `config.toml`，测试替代仅通过隔离的运行时参数使用。
2. 失败测试覆盖限定文件、大小、UTF-8、JSON/TOML 校验、外部修改摘要、符号链接、原子替换和匿名错误。
3. GET/PUT 受既有本机访问控制保护，响应 no-store；原文件内容保留未知字段和格式，保存前检查摘要，避免覆盖外部修改。
4. 设置入口只在显式打开时读取原生文件，编辑内容不进入 React Query、Agent、日志、持久浏览器存储；切换/关闭/销毁清理。展示后续调用生效及当前轮次保持设置。
5. Claude fresh query 重读原生配置；Codex 按核实的官方机制重载，必要时空闲子进程重启并通过原生会话 ID resume，不重启网页后端。
6. 文件修改用隔离 fixture；真实 Codex 测试复制用户指定替代配置到隔离 home，检查两个原始配置文件前后摘要一致，不记录真实模型/服务商/密钥。
7. 验证真实下一次调用和相关网页行为，完成相关工程检查，更新实际进度并提交配置阶段。

## 验证与边界

- 只在指定空根目录内创建和清理本工具所有的随机子树；不在服务器安装工具或存放模型/凭据。
- 不扩大为 cc-switch 的配置集、账户或用量管理；不以替代配置改变正式默认路径。
- 本轮先完成保存凭据与目录整理，阶段二保持待办；不把后续 Codex 适配或设置能力记为完成。
- 阶段完成时更新路线图和匿名验收记录。已有可靠基准按影响范围增量验证，出现实际缺陷才定向修复复测。
