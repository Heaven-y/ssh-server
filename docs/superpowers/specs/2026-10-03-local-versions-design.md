# 本地版本记录与恢复

落实 F6、A5，沿用用户已授权的持续开发与阶段提交。本地 Git 管理已保存的小文件，保存文件和同步不创建提交。服务器不需要 Git。

## 范围与语义

- 打开工作区时，以幂等 POST 初始化本地版本能力；未处于 Git 仓库时在工作区执行 git init，无初始提交。已有仓库/链接工作树直接复用；位于父仓库的子目录时，操作范围限定到当前工作区，不提交或恢复其他目录。
- 状态只列出当前工作区的改动，区分可记录与已排除，显示未记录文件数。遵守 Git 忽略与现有同步过滤、大小阈值，.git 永不进入记录；小型二进制允许记录，超过阈值文件明确排除。
- 用户点击保存版本后提交已保存到本地的可记录改动；无改动不产生空提交。支持自填 1–200 字符说明，默认说明由网页提供，不调用模型；历史时间统一使用 Unix 毫秒。
- 保存版本纳入当前可记录文件的工作树内容，消费这些文件对应的暂存内容；不把工作区外或被排除的已暂存内容带入提交，也不丢弃这些暂存内容。HEAD/暂存区或文件在确认后变化时拒绝旧请求。
- 历史分页，原生 Git diff 可查看工作树或选定提交，支持按文件缩小差异；二进制和超限差异有明确反馈。
- 恢复某个提交表示将当前工作区的跟踪文件恢复到该提交快照，HEAD 与历史保持不变，产生待记录改动。整次恢复保留不冲突的未跟踪文件；同名未跟踪文件若将被覆盖，必须列入预览。单文件可恢复或删除该历史路径。
- 恢复先生成预览，列出新增/修改/删除/排除项，再确认执行；重新核对 revision，禁止陈旧确认覆盖新编辑。合并/rebase等未完成状态应明确拒绝写操作，不能擅自解决。
- 本地恢复成功后网页调用已有同步接口，分别展示本地结果与同步结果；删除仍须通过既有同步确认，不绕过执行门禁。未保存编辑器内容保持在原缓冲，由已有外部修改检测提示。

## 实现边界

- 后端 vcs 模块使用原生 Git CLI（成熟 Git 实现），Node 异步参数数组与 stdin 调用，不通过 shell，不接收任意 Git 参数；固定超时和输出限制，错误不回显底层命令或配置。
- 路径仅为工作区相对路径，使用 NUL 分隔处理文件名，校验路径、链接、对象类型、文件大小和根目录身份。提交 SHA 只接受实际提交对象，不能把任意用户字符串拼到命令中。
- 保存采用隔离暂存索引或同等原生机制，构造仅包含当前范围改动的提交；保持其他已暂存内容。通过 Git 锁和 HEAD 条件更新避免并发提交冲突，失败不得宣称成功，清理自身临时文件。
- 恢复在修改前准备内容并校验当前文件身份，不跟随链接，不覆盖 .git 或排除路径。只更改工作树，不移动分支或修改实际暂存区；中途系统失败若无法全部回滚，明确返回部分失败与已处理范围，不伪装成完成。
- 同工作区写操作复用 SyncManager.transaction；服务同时按实际仓库序列化，避免不同工作区指向同仓库时互相覆盖。事务内不嵌套调用 sync。
- 使用 Git 现有作者配置；缺少身份时返回可操作提示，不改写用户全局 Git 配置，不推送。

## 接口

固定前缀 /api/workspaces/:id/versions，类型见 packages/shared/src/versions.ts。

- POST /initialize → VersionStatus；GET / → VersionStatus。
- GET /history?skip=0 → VersionHistory，每页 30 条。
- GET /diff?commit=<可选提交>&path=<可选相对路径> → VersionDiff；无 commit 查看当前工作树相对 HEAD。
- POST /save，{ message, revision } → VersionSaveResult。
- POST /restore/preview，{ commit, path? } → VersionRestorePreview。
- POST /restore，{ commit, path?, revision, confirmed:true } → VersionRestoreResult。

恢复预览中的同名未跟踪覆盖项带 untrackedOverwrite:true，界面明确标注覆盖。无法安全回滚的恢复错误使用 code:partial_restore，并通过 affectedPaths:string[] 返回已受影响的相对路径，前端显示该范围，不把部分恢复描述为未修改或全部成功。

## 界面与验证

状态栏增加版本摘要与改动数，点击打开按需加载的版本面板；当前改动、历史、diff、说明和恢复预览在同一任务区完成。恢复确认明确文件范围；忙碌期间禁止重复操作，错误保留当前选择，不丢弃文件编辑缓冲。

实现并审查后只补核心测试：临时真实 Git 仓库、初始化幂等、无空提交、大小/过滤、已有暂存与父仓库范围、并发/陈旧 revision、历史与 diff、单文件/整次快照恢复、未跟踪文件与链接边界。浏览器验证版本操作和恢复后同步成功/待确认/失败分离，真实服务器 A5 与 A13 在可用环境中复验，不拿受控替身冒充真实 SSH。
