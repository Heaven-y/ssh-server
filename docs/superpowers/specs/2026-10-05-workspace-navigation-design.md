# 工作区布局、导航与资源概览设计

日期：2026-10-05。补齐界面第1/2/3节的可折叠侧栏、可调分栏、亮色主题、网页命令面板及F9持续资源概览。用户已授权自主完成并记录，Native实施、一次新的阶段核心Review后补最少核心回归，不调用astra，不续接历史代理。

## 设计与决策

N01：默认保持暗色，顶栏按钮切换亮色；偏好只存浏览器版本化非敏感UI配置。亮色使用完整语义变量而非组件零散覆盖；CodeMirror随主题配置官方light/dark与已有变量，不重建编辑缓冲。xterm继续独立暗色画布，保留清晰的终端边界。相比新增后端产品字段，本机浏览器偏好避免跨窗口主题突然漂移；代价是不同浏览器分别选择。

N02：复用react-resizable-panels4.14.2。侧栏默认240px，可调200–320px、折叠为0；右侧文件宽窗默认420px，可调360–520px，1280px以下沿用模态覆盖层。终端既有上下分栏不改。布局变化保持文件/终端同一子树，不能因折叠或断点丢缓冲、重连PTY或重复打开SFTP。折叠导航区域inert/aria-hidden，按钮在顶栏可恢复；已打开模态时不通过全局快捷键改变布局。

N03：主题/折叠状态和宽度保存同一版本1JSON，非法值恢复默认；布局宽度通过官方Group.onLayoutChanged的meta.isUserInteraction识别，只保存用户拖动/键盘交互的有界像素值，窗口尺寸变化与主动开关不覆盖拖动偏好。存储不可用时继续内存操作；不存服务器目标、内容、凭据或原生历史。宽度仍受运行时最小/最大值限制。

N04：网页命令面板采用固定cmdk1.1.1（MIT），包元数据已核对。原生dialog承载焦点/关闭，cmdk负责过滤、上下键与选择。搜索工作区、当前工作区两类原生会话和常用操作，两个会话来源并行、复用既有queryKey、错误独立反馈；仅面板打开时订阅额外查询，不对所有项目扫描原生记录。选择会话沿用chat-store已有取消与选择代次逻辑。

N05：Ctrl+K/Cmd+K或顶栏按钮打开；输入法组字、xterm内部和已有模态中不劫持快捷键。常用动作包含新会话、文件/终端/设置、主题/侧栏、立即同步、保存版本及资源详情。同步复用当前SyncPanel动作及忙/冲突门禁；“保存版本”打开已有说明与确认表单，不直接产生提交。通过当前组件的类型化imperative ref调用已有入口，不创建第二套调度或全局命令总线。选择时再次核对当前workspace，失败留反馈；不包含删除/覆盖/恢复等危险快捷动作。

N06：顶栏常驻CPU、内存、最多两张GPU简要数值，额外GPU数量可见；显示实际采集主机、更新时间和过期/不可用。null不得显示为0。960/1280可换到顶栏第二行，1920同排，保持按钮可用且不压缩主区。点击打开现有完整详情。概览与详情由一个useResources持有同一查询和计时器，页面可见、网页连接正常且产品参数有效才检查；隐藏/断线暂停，恢复后检查，保留后端共享缓存/退避及固定目标校验，不调用模型或检测训练完成。

N07：全局主题和布局影响面广，扩大视觉检查至960/1280/1920两种主题、侧栏/文件/终端布局、产品/原生/规则/资源/版本弹窗、CodeMirror内容及公开截图对比度；实际资源SSH增量只复验新持续入口和隐藏/恢复共享查询。长会话虚拟列表、工具分组和本轮diff属于下一子功能，本阶段不扩称全部界面或完整M6。

N08：从已通过本机工程门禁的规则分支先--no-ff合入本地feat95f5e97，树等同dcb4c8c，再创建codex/workspace-navigation。规则PR11/CI37245394105双平台通过后才推送共享分支/main；若失败先定位依赖，不改门槛或强推。

N09：不采用useDefaultLayout的百分比存储，选择官方用户交互回调与单个有界像素配置。恢复折叠前宽度更直接，坏值和极端窗口不会污染偏好；代价是不同屏幕不按百分比等比伸缩，以运行时约束适配。规则CI37245394105已成功，feat95f5e97/main c8da9ff两级合并和推送完成，合并树均等同dcb4c8c。
