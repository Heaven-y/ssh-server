# 工作区文件浏览与编辑

本阶段落实 F8、A13，沿用用户已授权的持续开发与阶段提交。AI 仍是主要编辑者；网页用于偶尔修改脚本。本阶段完成文件浏览、编辑、保存和同步反馈，版本历史按后续独立阶段实施。

## 范围与界面

- 顶栏提供“文件”入口；桌面为可收起的右侧面板，窄窗口改为覆盖层。面板绑定打开时的工作区，显示名称，切换对话工作区不会丢弃编辑缓冲或把文件保存到另一工作区。
- 逐级浏览本地副本，使用同步过滤规则，跳过 .git、符号链接和超限文件；不扫描远端，不递归计算目录体积。目录列表有数量上限并明确提示截断。
- 使用既有 CodeMirror，增加 Python、JavaScript/TypeScript、Shell、YAML、Markdown 与纯文本，保留 JSON/TOML。编辑上限为同步阈值与 2 MiB 中较小者；二进制和非法 UTF-8 拒绝编辑。
- 单文件编辑，显示相对路径和未保存状态。关闭或切换文件前提示保存或放弃；保存期间禁止关闭。浏览器离开有未保存提示。
- 文件正文只在当前编辑组件内存中保存，不进入浏览器持久存储。关闭面板清理。

## 后端与并发

- 新增 files 服务及固定工作区路由，浏览器仅传工作区 ID 与校验后的相对路径，拒绝越界、链接、设备名、非普通文件和被排除路径。
- 有界读取，返回原始 UTF-8 内容和 SHA-256 revision；保存时重新检查文件身份与摘要，原子替换并保留文件权限。不存在的文件不隐式创建，删除/新建另行设计。
- 保存复用 SyncManager.transaction，与该工作区同步及远程执行串行；不持有事务再调用 sync，避免自等待。
- PUT 只确认本地写入；网页收到成功后调用已有同步接口，并分别显示本地已保存、同步中、服务器已同步或同步待处理/失败。同步完成后再次核对文件 revision，当前内容变化时不宣称保存版本已到达服务器。
- 打开文件后每 5 秒及页面重新可见时仅检查 revision；页面隐藏暂停。检测到 Agent/同步修改时保留编辑缓冲，提示重新读取。保存冲突不能强制覆盖。
- 所有接口沿用本机认证与 no-store；错误匿名化，不回显内容或底层路径。

## 接口

- GET /api/workspaces/:id/files?path=：当前目录列表。
- GET /api/workspaces/:id/file?path=：文件内容。
- GET /api/workspaces/:id/file/revision?path=：当前文件版本。
- PUT /api/workspaces/:id/file：{ path, content, revision }，返回保存后的文件。
- 共享 WorkspaceDirectory、WorkspaceFileEntry、WorkspaceFile、WorkspaceFileInput 类型由 packages/shared 导出。

## 验证

先实现并审核核心目标，再补必要测试：范围/链接/二进制/大小限制、外部修改不覆盖、权限/行尾保留、并发写入与同步事务。浏览器验证文件浏览、保存同步的成功及失败分离、外部冲突、关闭保护和不同宽度布局。只运行改动与关联测试；不重复已通过的无关全量验收。
