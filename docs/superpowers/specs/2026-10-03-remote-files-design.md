# 服务器文件管理设计

日期：2026-10-03，状态更新：2026-10-05。依据：[F10 与 A20–A23](../../product/requirements.md)、[架构 5.12](../../engineering/architecture.md)、D21。本文细化既定需求；目录浏览、操作任务、显式下载及同步路径协调已接入。同步协调的本机证据见[验收记录](../../guides/remote-file-sync-acceptance.md)，后续实际SSH/rclone、同/跨文件系统、混合目录迁移与Firefox下载见[完整链路验收](../../guides/real-workflow-acceptance.md)，真实权限/对象变化/独立连接中断见[失败验收](../../guides/remote-file-failure-acceptance.md)。Edge系统选择器仍未验，独立连接不扩大为共享池或全网络故障。

## 1. 目标与范围

用户在现有文件面板直接查看和管理当前 SSH 目标上的文件，包括未同步的数据、权重与输出。普通浏览只读取元数据；移动和复制在服务器执行；只有显式下载才传输所选文件正文到浏览器。

沿用 Node.js、TypeScript、Fastify、ssh2、现有认证和主机指纹校验。服务器不安装新程序或常驻服务。首版只处理同一 SSH 身份的文件操作，不引入跨服务器传输、自动模型调用或自动 Git 提交。

方案选择：复用 ssh2 的 SFTP 通道，并为服务器内复制、跨文件系统移动提供固定能力适配。全部经 shell 执行会扩大路径解析和输出解析范围；全部经本地 SFTP 读写则会让服务器内复制经过本机，均不作为主路径。远端缺少所需能力时明确拒绝该项操作，保留浏览等可用功能。

2026-10-04 实施约定：固定操作处理器使用服务器已有 Python 3 标准库与 Linux `renameat2(RENAME_NOREPLACE)`；不安装依赖，不提供任意命令入口。目录描述符禁止通过链接父路径操作，服务器内部复制与内容校验不传正文到本机。缺少能力时拒绝对应写操作，目录浏览和 SFTP 下载不依赖该处理器。

## 2. 文件面板与目录浏览

- 现有文件面板提供“本地代码 / 服务器文件”切换。本地编辑器保持挂载，切换视图保留未保存缓冲；关闭仍沿用现有保存提示。涉及这些缓冲的远端变更必须先保存或由用户明确放弃。
- 面板绑定打开时的工作区和 SSH 目标，显示 Host、当前绝对路径及“工作区外”标记。切换聊天不改变面板目标；工作区配置或 Host 实际身份变化后，旧面板操作失效，提示重新连接目标。
- 打开面板时先由后端签发绑定工作区配置、实际 SSH 身份及信任记录的令牌，此步骤不连接 SSH。首次浏览和重连均沿用同一个令牌；目标改变必须关闭并重新打开面板，不能静默重新登记。取消传递到后端，30 秒总截止时间覆盖排队、配置读取、握手与 SFTP；迟到产生的资源也要释放。
- 服务器视图提供路径输入、面包屑、返回上级、返回工作区、刷新和逐批加载。允许浏览同一 SSH 账号有权限的工作区外目录；浏览路径与固定的同步根独立，切换目录不修改配置、不触发同步或自动下载。相对路径从绑定的工作区根解析；`~` 仅表示当前账号主目录，不解析其他账号或 shell 表达式。
- 使用 SFTP `opendir/readdir(handle)` 按批读取，不先收集整个目录。每页最多 200 项；游标绑定目标、目录和 SSH 认证代次，空闲 60 秒释放句柄。全局最多保留 32 个目录句柄，达到上限时释放过期项或提示重新读取。
- 重试同一个分页请求不得跳过数据。刷新、关闭、断线和过期均释放对应句柄；前端忽略旧路径请求的迟到结果。
- 展示名称、类型、普通文件大小、修改时间和同步关系。目录显示“可能包含同步文件”，不递归计算体积或武断标成仅服务器。链接单独标记，不自动进入其指向目录或读取目标内容。
- 不满足本地文件名规则的远端名称仍可显示；服务器操作按远端路径规则处理，不能直接交给现有 Windows 同步路径校验。移入同步范围时再检查本地可表示性，冲突时明确阻止。

## 3. 直接操作与确认

支持新建目录、重命名、移动、复制、删除和显式下载。按钮、右键菜单与键盘使用同一操作入口；拖动只生成移动预检，不能绕过确认或直接执行。

操作统一经过“预检 → 提交 → 查询结果”：

1. 网页提交操作种类、源路径、目标路径和绑定的面板上下文；不接收任意命令。
2. 后端核对当前身份、源对象、目标父目录、同名项、工作区根保护及同步影响，返回短期有效的预检 ID 和可读影响摘要。
3. 删除、覆盖及同步路径变更展示具体 Host、源/目标路径和目录影响。提交只接受该预检 ID 与对应确认项。
4. 提交前重读对象和受影响配置；与预检不符则要求重新预检。目录扫描超时或截断时不能把未扫描部分当作无影响。

默认拒绝同名目标，目录复制不合并。使用服务器可保证不覆盖的原语；能力不足时拒绝执行，不能用“先判断不存在，再无条件重命名”冒充不覆盖。显式覆盖也须绑定已确认对象；无法保证边界时要求用户先管理同名项。

符号链接操作针对链接本身，不递归跟随。拒绝删除、移动或覆盖任何已配置工作区根，以及包含这些根的祖先目录；检查覆盖同目标的所有工作区，而非仅当前面板。不得通过带链接的父路径绕过保护。

同文件系统移动优先使用原生不覆盖重命名。跨文件系统移动分成服务器内复制、核对、移除源三个阶段；复制失败保留源，无法确认复制完整时不删除源。复制或核对的总量未知时显示阶段及已知数量，不编造百分比。

## 4. 任务、取消与下载

- 操作具有独立 ID 和重复提交保护。提交前将目标、路径、确认摘要和阶段写入本机配置目录的任务记录；不记录密码、私钥或文件正文。
- 远端执行结果与同步结果分别保存，例如“远端移动完成 / 本地同步待恢复”。重新打开面板只查询任务，重试同步不重新执行远端操作。
- 同一 SSH 身份下路径相交的写操作排队；其他目录浏览、聊天和资源请求保持可响应。取消只终止该任务拥有的通道或进程，不断开共享 SSH 连接。
- 超时、断线或后端重启后，尚未确认的远端阶段标为“结果待核对”。核对源、目标与部分产物后再决定重试；取消不等于回滚，部分产物不得显示为完整成功。
- 下载先展示 Host、完整路径、大小和浏览器保存方式，经 SFTP → HTTP 流式传输，保持背压和有界内存。服务端不选择工作区镜像作为下载目的地，不调用同步或 Git。
- 优先使用浏览器文件保存选择能力；不可用时使用浏览器下载管理器并明确提示其保存设置。取消关闭该下载流，不影响其他任务；发送完毕只能说明数据已交给浏览器，不能声称磁盘写入已核实。

## 5. 同步协调与编辑保留

现有 `SyncManager.execute()` 固定执行前后同步，不能直接作为全部服务器操作的入口。新增按路径协调的接口，明确区分仅服务器操作和涉及同步范围的操作。

1. 按实际 SSH 身份、规范化根路径和源/目标计算所有受影响工作区；目录包含关系、混合目录、跨工作区移动都需要检查。只有明确不影响同步范围时才走仅服务器路径。
2. 相关工作区按固定 ID 顺序进入现有同步事务，避免交叉移动产生死锁；排队完成后重读配置和预检对象。
3. 检查同步冲突、待确认删除和已知编辑缓冲；存在未处理事项时保留任务预检并要求处理，不静默覆盖或丢弃修改。
4. 建立相关小文件的稳定快照与源/目标映射，完成执行前一致性检查。远端操作完成后，按映射调整受控同步镜像和基线，再核对并应用本地结果；不能先运行普通双向同步把旧路径重新上传。
5. 本地文件在执行期间又变化时保留内容并报告冲突。源移出同步范围时只处理映射内受管理文件；目标移入时按既有大小、排除和路径规则处理，混合目录不整体下载。
6. 写入同步状态失败时保留远端已完成结果，暂停相关自动同步，提供单独恢复入口。保留本地 Git 索引和历史，不自动提交。

工具自身的事务只能协调本工具发起的操作，不能锁住服务器训练进程或用户外部编辑器。重验与实际文件系统操作之间的限制必须在异常结果中如实反映。

## 6. 模块与交付顺序

| 模块 | 责任 |
|---|---|
| `packages/shared/src/remote-files.ts` | 目录条目、预检、操作请求和任务状态的共享结构 |
| `apps/server/src/ssh/sftp.ts` 与连接池扩展 | 复用已验证连接，管理任务独立 SFTP 通道与关闭 |
| `apps/server/src/remote-files/` | 路径及身份绑定、分页浏览、能力检查、预检、任务记录、服务器操作和下载 |
| `apps/server/src/sync/` 的路径协调接口 | 受影响工作区串行、稳定快照、路径映射、冲突及恢复 |
| `apps/server/src/http/remote-files.routes.ts` | 复用访问控制，严格请求校验，目录/任务查询与下载流 |
| `apps/web/src/features/remote-files/` | 服务器视图、导航、操作确认和独立任务列表 |

按三个可审阅阶段交付：① SFTP 目录浏览与双视图；② 预检、服务器操作、任务与下载；③ 同步路径协调、混合目录和恢复。阶段之间保留明确的能力状态，未完成的操作不展示为可用，不能将第一阶段标为整个 F10 完成。

每阶段先实现和审查核心行为，再补最少核心测试；测试集中在对应包的 `tests/`，使用合成目标与临时路径，不写开发机绝对路径。仅验证新增及关联模块；扩展连接池和同步公共接口时覆盖相关调用方。

浏览器核对双视图、焦点/键盘、菜单、确认与错误、960/1280/1920 宽度；后端核对分页不读正文、目标变化、重试、取消、不覆盖、链接与根保护。真实 SSH 验收还须覆盖同/跨文件系统操作、混合目录、未保存修改和流式下载，使用用户指定的 Host 与允许测试目录；本机替身不替代 A20–A23。
