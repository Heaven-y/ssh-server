# 本轮改动与行内反馈设计

日期：2026-10-05。补齐界面第4/5节的改动文件聚合、逐文件diff、放弃单个文件改动和行内反馈。用户授权自主决策、实施和记录；Native实施，一次阶段核心Review后补最少核心回归，不调用astra、不续接旧代理。

## 语义与取舍

C01：分别显示“本轮期间的本地改动”和“相对上次保存版本”。本轮采用Agent启动前及轮次后同步收尾后的两个本地文件快照，表示这一时间段的净差异；不能从工具名猜测全部编辑，也不归因于唯一Agent，因为外部编辑器或并发活动可能改文件。预先存在且本轮没有变化的未提交内容不算本轮改动；改后又恢复原样的净差异为零。失败、中断、同步失败仍显示实际可获得的本地结果及状态，不把同步成功当快照成功。

C02：复用现有Git版本模块的安全路径、同步过滤、临时索引、快照及输出上限。快照写Git树对象和专用refs/ssh-server/turns命名空间，不创建提交、不移动HEAD、不改用户暂存区；常规保存版本仍只由用户触发。尚未初始化、仓库忙、路径/规则变化或采集失败时，本轮改动明确不可用，不阻断Agent。纯上下文/压缩命令不采集文件，也不追加同步。

C03：运行时只保存轮次元数据（UUID、工作区/Agent/原生会话身份、时间、树引用、范围摘要与状态），不复制聊天。每工作区最多保留最近20轮；专用Git引用保证树不会被正常GC丢弃，淘汰时只比较并删除本功能拥有的引用，不触碰用户引用或历史。查询绑定当前工作区目录、仓库身份与过滤摘要，目标变化后旧记录不作为当前结果；重启后未完成轮次标为不完整，不重跑Agent或同步。接口校验工作区和Agent/会话所属关系，不开放任意Git对象读取。

C04：本轮快照入口通过可选TurnChanges生命周期依赖接入TurnManager：普通轮次在runner调用前begin，在已有同步收尾后finish，完成消息触发网页查询刷新。采集异常转换为本轮记录的不可用原因；取消准备时不启动新采集，已经开始的只读采集收尾后再释放本轮所属资源。保持现有单会话、同步串行和工作区删除活动租约，不另建Agent调度。

C05：差异使用固定@pierre/diffs1.5.1（Apache-2.0，包元数据和React19兼容性已核对），按需加载、单列布局，沿用网页主题；不使用组件的编辑/自动接受能力。逐文件展示新增/删除行数与二进制标记，512KiB差异上限沿用既有版本模块，过大/二进制/排除项不伪造行数或可评论内容。成熟组件负责Git patch解析、行号与行交互，解析失败保留有界原文本及明确提示。

C06：“改动”是既有文件面板的第三视图，和本地代码/服务器文件共享宽窄布局；切换视图保持原编辑器和远端通道子树。当前改动与本轮记录分别加载，初始只查当前所选工作区/Agent/会话，不扫全部会话。轮次结束后提供聚合卡片/入口，点击打开所属文件差异；切换会话或工作区后旧异步结果不能替换新选择。历史只展示本功能实际保存的最近轮次，没有记录时说明未采集，不用当前文件diff冒充历史本轮结果。

C07：行内反馈记录文件、旧/新侧、真实行号、比较来源及用户评论（每条1–3000字符，最多20条，总量不超过12000字符）。行点击与可见的行号/侧别输入提供等价入口，避免只支持鼠标。加入当前会话的“待发送行内反馈”区，可移除；不覆盖已有输入，不自动发消息。提交普通消息时合并用户正文与反馈，成功发送才清空；连接失败保持。反馈绑定workspace/Agent/conversationVersion，切换选择清空反馈；选择技能/原生命令时提示先取消该选择再发送反馈，防止被解释成命令参数。

C08：放弃单文件仅针对当前本地未记录差异，恢复到当前HEAD；尚无提交时表示删除该新增文件。新增未跟踪文件也必须在明确预览中列为删除，不能静默忽略。复用现有版本恢复的文件指纹、串行事务、原子写入/回滚、编辑缓冲保留及后续同步；预览绑定当前HEAD/内容/暂存区/过滤和目标，变化后要求重新预览。用户确认只作用该文件，不自动保存版本、不丢弃未保存编辑缓冲；本地放弃与服务器删除待确认分别报告。

C09：从本机通过最终门禁的时间线阶段本地--no-ff合入feat6e1670b后创建codex/conversation-changes。PR13双平台CI通过前不推送该共享合并；两级merge树核对及main CI按实际结果记录。复用未受影响的布局/PTY/资源证据，本阶段扩大验证至diff解析、行反馈、真实Git快照与放弃、迟到结果/取消及两主题三宽度；实际rclone和多活动M6随后串联。

C10：单文件放弃保持用户索引原样。若所选文件的暂存内容、模式或删除状态与HEAD不同，预览和执行均拒绝并提示先在本机处理暂存区；不能仅恢复磁盘却声称全部差异已放弃。其他文件的暂存改动保持不动。尚无HEAD且新增文件未暂存时，明确预览为删除；已暂存的新文件遵循同一拒绝规则。

C11：保留上限包含正在采集的轮次。创建第21条记录时优先淘汰最早的已结束记录；若20条均在采集，新增轮次不创建快照，Agent仍继续并明确报告不可用。先原子移除淘汰元数据，再比较并清理拥有的引用；目录改变或外部改写引用时保留引用，避免触碰新目标。无原生sessionId的空查询不列出其他未绑定轮次；当前网页只使用自己关联的完成事件，历史列表按Agent和原生id匹配。

## 验收

真实临时Git项目含预存脏文件、Unicode路径、新增/修改/删除/二进制、预先暂存内容；两快照净diff正确，HEAD/index不变，私有引用及20轮保留可核对。普通轮次、失败/取消、原生首次id、纯压缩和同步失败分别验证；新目标不读旧结果。实际Edge核对diff新旧行号、中文反馈保留/移除/发送、断线不丢、选择切换不串、单文件放弃预览和服务器删除待确认，两主题三宽度无溢出且原编辑缓冲保持。核心Review后补最少回归，不把受控同步/模型事件当完整真实M6。
