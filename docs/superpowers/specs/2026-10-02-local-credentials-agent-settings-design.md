# 本机凭据保存与 Agent 配置编辑

更新日期：2026-10-02。用户要求继续开发、验证并在完成阶段提交；本设计补充既有 SSH/同步工作流，不更换技术栈，不扩大为服务商管理平台。实际进度以路线图为准。

## 目标与范围

- 选择保存 SSH 密码后，主动断开、重启后端均可重新连接，避免反复输入。提供独立的忘记入口。
- 在网页设置中编辑 Claude/Codex 原生配置，减少手动寻找配置文件。后续调用读取更新后的配置，不重启本项目，不改变正在运行的轮次。
- 正式 Codex 使用 `config.toml`；验证可通过运行时参数提供替代配置，复制到隔离的本机测试环境，原配置不被改写。
- 服务器不安装软件、不保存模型配置或凭据；真实验收仅修改指定测试目录内本工具创建的文件。

## SSH 保存凭据

密码继续通过受 Host、Origin、Cookie 保护的接口传入，前端不放 React Query mutation/cache、浏览器持久存储或 Agent 输入。成功测试连接后才保存，不因输入了密码就宣称保存成功。

Windows 下使用当前用户 DPAPI 保护独立的本机凭据文件；由受限子进程经 stdin 转交内容，命令行参数不含密码。明文只在后端内存中短暂存在，加密失败明确报错，不回退为明文存储。凭据按实际 HostName、Port、User 绑定并用摘要命名；Host 别名改指其他目标时不能使用旧项。凭据文件不放同步项目内，不进入 Git。

“断开连接”关闭当前连接、取消旧认证周期并清理内存，保留保存项。主动断开后暂停自动重连，用户重新连接时才从保存项恢复。“忘记密码”删除对应保存项、清理内存并关闭连接。认证失败使当前保存项失效并要求重新输入；网络或目录访问错误不误删有效保存项。忘记、退出、目标变化与异步读取之间使用代次校验，防止迟到操作重新恢复旧密码。

使用受控本机 SSH fixture 和真实 DPAPI 验证，无须读取真实服务器密码。非 Windows 环境明确表示系统加密保存不可用，内存认证仍可使用。

## Agent 配置

设置模块只允许预定义的原生文件，不接受任意路径写入。Claude 使用用户设置 JSON；Codex 使用其正式 home 下的 `config.toml`，需要时单独处理原生认证 JSON。遵循官方目录环境变量，不把测试替代文件作为产品默认。

读取与保存均限制大小，保持 UTF-8 和原格式、未知字段。保存前用 JSON/TOML 解析器校验结构，错误信息不含原始配置片段或密钥；检查读取时的文件摘要以拒绝外部修改，写入同目录临时文件并原子替换，不生成服务器备份。对符号链接等不安全目标明确拒绝，避免误写其他文件。

含密钥的配置仅在显式打开的编辑区读取，不进入查询缓存、日志、对话或浏览器持久存储；关闭、切换 Agent、组件销毁后清理编辑内容。接口使用 `Cache-Control: no-store`。保存操作与对话适配器隔离，Agent 不获得配置编辑工具。

Claude 每轮使用新的官方 query，重新读取 user/project/local 来源。Codex 的 `config/read` 重读磁盘，`config/batchWrite` 可用 `reloadUserConfig` 刷新部分运行设置，但 model 等静态选项不会更新已加载会话。后续适配器应在空闲时重启本机 app-server，再用当前原生配置的非秘密会话选项和原 thread ID resume；单纯重启并 resume 仍可能沿用旧设置。网页项目无需重启，正在运行的轮次保持启动时配置。

## 验证与阶段提交

1. M2 基础：完成真实小文件同步、删除/冲突、执行阻断、网页与工程检查，提交可用的认证/同步基础。
2. 保存凭据：真实 DPAPI 往返及磁盘无明文，fixture 密码认证、断开重连、后端重启、忘记、失败和目标变化，网页字段清理；通过后单独提交。
3. 配置编辑：语法无效、外部修改、原子保存、无查询缓存与不泄露错误；用隔离文件验证下一调用读取更新配置。
4. Codex 验收只复制调用时提供的替代配置到隔离 home；原始配置和替代文件保持不变。临时模型配置不进入仓库或共享报告。完成必要检查后提交配置功能。

本设计不包含 cc-switch 的多服务商配置集、账户切换、使用量监控或自动更新，也不跳过后续 Codex 原生会话、skills、上下文与审批的 M4 实施。
