# 工作区界面改版

目标：落实用户对当前界面过于杂乱的反馈，参考已核对的 T3 Code、CloudCLI 与 Vibe Kanban 界面，保持对话为主要工作方式。参考依据见 [界面调研](../../product/ui-reference-review.md)。

用户已授权继续开发并合理决定实现。已询问深色/浅色偏好，尚未收到选择；本轮沿用既有深色模式，采用推荐的中性深色，不改变工作流范围。

## 布局与视觉

- 保留工作区/会话左侧导航、中央对话和按需文件面板。减少常驻区域的边框和说明文案，使用中性灰黑底色与清楚的正文层级。
- 顶栏显示应用、工作区、文件与设置入口；网页连接状态明确标为本机服务，不冒充 SSH 状态。
- SSH 与同步收为一行状态操作。正常状态只显示简短摘要；失败、暂停和待确认仍然显著可见。点击展开对应详情弹窗，表单与危险操作在详情中完成。
- 同步/SSH 组件及其状态 hook 始终挂载；只按需挂载详情内容，关闭详情不停止定时同步或丢失连接状态。隐藏页面的既有暂停规则保持。
- 新建工作区表单使用宽度合适的模态区域，避免挤在窄侧栏。保留取消、验证、密码清理和迟到请求处理。
- 对话正文增加可读行距、限制行宽，工具结果保持折叠。输入框使用统一容器，发送/停止是明确主操作；输入法与键盘发送行为不变。
- 蓝色用于主操作与焦点，绿色用于成功，红色用于危险/错误；可交互边界保持足够对比度。沿用现有字体依赖，明确中文回退字体。
- 文件面板与设置编辑继续共用 CodeMirror，不引入未实现的终端/版本入口，不建设完整 IDE。

## 组件边界

- 新 ui/DetailDialog：原生 dialog、命名、焦点限制与恢复、Escape、滚动内容和忙碌关闭保护。
- SshConnectionPanel：保留现有 hook，只把操作详情移进按需弹窗；关闭清理密码，操作期间禁止关闭。
- SyncPanel：保留唯一的 useWorkspaceSync 调用，改为摘要入口与详情；执行门禁/删除确认/恢复操作不变。
- App 将两种摘要置于一条状态栏。会话与文件仍保留独立滚动和未保存保护。
- 工作区导航与对话组件只改变呈现，不改变 Agent、会话 ID 或网络协议。

## 验证

全局主题影响所有页面，扩大视觉验证到空状态、工作区表单、SSH 密码、同步成功/失败/待确认、对话文本/工具/审批、文件编辑和原生设置。检查 960/1280/1920 宽度、键盘焦点、滚动与底部操作可见性。

重点回归：详情关闭仍定时同步；隐藏页面暂停；SSH 密码取消和关闭清理；同步待确认不会继续远程执行；文件草稿、设置 CRLF/冲突仍保持。按关联范围运行现有测试，只有审查发现核心缺口才补测试；不为纯样式新增镜像测试。
