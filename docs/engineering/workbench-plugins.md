# 工作台插件接口 v1

更新于 2026-11-05。本文描述当前插件契约和页面关系，交付与验收状态见[路线图](../roadmap.md)。

AgentDeck 插件与 CLI 原生插件分别管理。第一版支持本地静态页面插件，提供自己的设置存储、当前项目摘要和命令入口；SSH Console 是使用宿主服务的内置插件。外部包不执行 Node.js 后端代码，也不兼容 DSH 的包格式。

## 插件包

插件目录包含 `agentdeck.plugin.json` 与自包含 HTML 入口。脚本和样式打入 HTML，图片可使用 data URI。安装复制到产品自己的插件目录，不在来源目录执行安装脚本，也不写入用户项目。

```json
{
  "id": "project-helper",
  "name": "项目助手",
  "version": "1.0.0",
  "apiVersion": 1,
  "entry": "index.html",
  "description": "显示当前项目与插件自己的设置",
  "permissions": ["storage", "project-context"],
  "commands": [{"id": "open", "title": "打开项目助手"}]
}
```

本地目录安装后默认停用，用户查看权限后启用。v1 拒绝其他 API 主版本、重复身份、路径越界、符号链接和可执行来源文件。单包最多 10 MiB、256 个文件、8 层目录；命令最多 32 项。只有安装时登记的入口摘要一致才可显示页面。

内置插件可以停用与再启用，不能卸载。外部插件卸载只删除产品自己的安装副本和插件设置，来源目录保留。启停和卸载核对 registry revision，资源清理失败保持可诊断状态，不谎称操作完成。

## 页面与宿主 API

插件管理和已启用插件位于工作台左栏上方。打开插件后使用中央主区，暂时隐藏对话与会话信息右栏；返回对话保留当前会话、草稿及本次右栏选择。右栏不是插件固定容器，也不承担旧服务器工具。页面只有一份标题，业务动作放在相应工具栏。

宿主显式取得已启用插件的 HTML，放入只允许脚本的 sandbox iframe。页面没有同源权限、Node 权限、表单提交或任意网络访问；不会获得 Cookie、认证变量、会话正文和 SSH 凭据。主应用的 Host/Origin/会话检查不为插件放宽。

页面可调用宿主注入的 `window.agentdeck`：

| 接口 | 所需权限 | 结果 |
|---|---|---|
| `agentdeck.storage.get()` | storage | `{ value, revision }`，插件自己的 JSON 设置 |
| `agentdeck.storage.set({ value, revision })` | storage | 核对版本后保存并返回新 revision，最多 64 KiB |
| `agentdeck.project.get()` | project-context | 当前 `{ id, name, dir }` 或 null；不返回服务器绑定和会话 |
| `agentdeck.onCommand(callback)` | 无 | 菜单命令打开插件页面并通知命令 id；返回取消订阅函数 |

宿主检查消息来自对应 iframe，按声明权限处理固定方法；单页面最多 16 个并发请求和每秒 60 次调用。设置是普通业务数据存储，不作为凭据保险库。外部页面异常不应影响对话与其他插件。

关闭外部插件页面会卸载 iframe，插件自己的持久设置保留；重新打开会重新读取。停用会撤销页面和接口访问。CLI 的配置、Skills、MCP 以及原生插件仍走[原生配置入口](native-configuration.md)。

## SSH Console 与兼容工具

SSH Console 通过同一插件目录展示和启停，主页面包含独立服务器标签、概览、进程、只读文件与终端。服务器 alias 是目标身份，项目仅提供初始默认目录；不创建隐藏项目来连接服务器。

控制台首次进入时挂载，离开页面后以隐藏且不可聚焦的状态保留组件；资源与进程采样同时停用。切换对话、打开会话右栏或切换项目不重建既有控制台页面，不覆盖已选服务器。应用启动和普通对话导航不会为了旧服务器栏偏好而加载 SSH 页面或采样服务器。

底层复用现有 SSH 连接池、主机信任和系统加密凭据。控制台的 PTY 由后端按服务器持有，关闭页面与关闭终端不同；每服务器最多 6 个，全局最多 32 个。输出保留最近 512 KiB，以字节游标读取，过期游标明确重置。断开服务器、身份代次变化、停用插件或应用退出会回收相应通道。

文件页只使用 SFTP 的目录读取与常规文件预览，预览最多 256 KiB。资源与进程只对当前可见服务器采样，缺失与过期分别呈现。停用会结束控制台与「项目服务器工具」中的终端，确认提示须包括旧项目终端；服务器档案、密码密文、项目和旧任务数据保留，共享连接不因插件停用而整体断开。

旧项目绑定的服务器面板仅通过 SSH Console 内的「项目服务器工具」打开，继续承载现有 Slurm、服务器文件写任务和旧终端。它不是对话右栏，也不是第二套独立服务器控制台。已有配置与任务记录保留，不因为页面迁移而删除；目标身份仍由原项目绑定决定。

兼容工具按首次访问挂载。返回控制台时隐藏并停止本视图采样，保留已打开视图和终端；键盘焦点回到「项目服务器工具」按钮。打开时焦点进入工具页返回按钮，隐藏整个插件时不抢走左侧导航焦点。面板收起、页面隐藏、终端结束和插件停用必须分别处理。

宿主确认停用成功后，前端取消旧终端的待绑定请求并清除标签；重新启用不能用遗留绑定重建旧标签对应的 shell。停用取消或失败时保留当前标签和连接。真正结束的终端由用户显式新建，不通过自动重连伪装为原终端恢复。
