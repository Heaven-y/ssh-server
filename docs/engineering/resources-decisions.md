# 资源面板决策记录

日期：2026-10-05。对应 F9、A18；用户授权自主完成和整合，具体参数以本阶段实际验证为依据。

| 编号 | 决策 | 原因与边界 |
|---|---|---|
| R01 | 请求驱动的 HTTP 结构化采样，详情可见时每 5 秒检查 | 复用 React Query；没有请求就不启动采样定时器，不维护第二套流式心跳 |
| R02 | 按实际地址、端口、账号、认证方式、凭据及可信记录摘要共享宿主缓存 | 不同 Host 别名可以指向同一节点；pool 的别名 cacheKey 仍用于目标复验，采样摘要不返回网页 |
| R03 | 磁盘按相同身份与工作区远端目录独立缓存 | 同一节点的不同目录可能位于不同文件系统，不能混用容量 |
| R04 | 成功缓存 5 秒，失败退避 5/10/20/30 秒，60 秒空闲淘汰，最多 64 宿主/128 目录 | 有界 singleflight，手动刷新也遵守缓存和退避；单 HTTP 断开不取消其他读取者的共享采样 |
| R05 | 每组 SSH 采样总时限 8 秒，每流 128 KiB；GPU 查询每项 3 秒；进程 50/GPU记录 100 条 | 只使用服务器现有工具和独立 exec 通道；不安装采集器，不关闭共享池或 PTY |
| R06 | CPU 连续差分且首帧 null，内存不猜 MemAvailable；非法与 N/A 字段为 null | 不把失败当作零资源占用；guest 不重复计入 CPU 累计量 |
| R07 | 使用 csv-parse，保留物理 GPU index/UUID；进程只采集 comm | 型号可含逗号；不能把数组位置当物理编号，避免完整参数泄露凭据；共享账号进程不标工作区归属 |
| R08 | 打开详情保存工作区快照，解析连接前后及采样后复验身份与认证代次 | 独立审查发现解析等待中的修改/删除竞态；两条回归先失败、修复后通过，失效输出不写共享缓存 |
| R09 | 可见性事件、关闭和失败恢复分别验收，记录浏览器实际能力 | 内置浏览器隐藏及 headless 标签切换仍报告 visible；暂停证据使用合成 visibilitychange，不能称为真实 OS 隐藏验收 |

本阶段采用 Native 实施与一次新上下文核心审查，随后补核心回归。审查模型为 gpt-6.1-sol/high，未调用 gpt-6-astra。资源采样不进入 Agent 适配器，不推断训练完成，不以 Slurm 轮询替代节点指标。资源与聊天、PTY、同步及文件任务的完整组合验收继续在 M6 执行。
