## 实际并发与长会话

实际 Codex MCP 执行服务器 15 秒 Python 任务期间，同时保持两个独立 PTY（服务器已有 htop / nvitop）、资源采样与 32 MiB 仅远端复制任务。

- 两个全屏程序实际绘制、调整尺寸、退出后仍能执行随机回显命令。
- 两帧资源时间递增，远端复制完成，均发生在 Agent 轮次结束前。
- 同工作区同步等待执行事务；重复轮次被拒绝。
- 关闭一个 PTY 后另一个继续响应，排队同步随后完成，小 JSON 返回本地。

上述补齐 V16 的实际多活动组合，以及 A10/A18 的相关真实链路。输入、输出限制和超时收尾的受控核心回归仍见[终端验收](web-terminal-acceptance.md)及[资源验收](resources-acceptance.md)。验收等待全屏程序进入、实际刷新及尺寸重绘后再发送退出键，避免 curses 初始化 / 重绘吞掉过早按键；产品终端代码未因此修改。

长会话使用真实 MCP 返回长文本，隔离配置把自动压缩阈值设为 14000 tokens 以缩短验收，产品和用户源配置不改。观察到原生 `compaction` 的 `trigger:auto`、`status:completed`，随后原 ID 续接准确保留随机记忆标记，能力目录提供的官方手动 compact 也完成。没有注入合成 JSONL；结合既有时间线负载与上下文证据，补齐本轮 A14–A16 的真实压缩 / 续接范围。
