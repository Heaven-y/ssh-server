# 可用性优化与独立面板验收

日期：2026-10-09。覆盖D39原生交互优化、D40可用性修正，以及D41独立面板与资料精简。现行规则见[设计决策](../engineering/decisions.md)，页面见[4张精选截图](../assets/ui-usability-optimization/inspection.html)。

## 1. 交付结果

| 范围 | 已实现内容 |
|---|---|
| 独立面板 | 资源与文件分别打开、收起，可同时存在；非模态，不挤成四栏或锁住聊天。标题拖动、右下角缩放、方向键微调、Shift加速、复位及视口约束均已接入 |
| 状态保留 | 收起、移动、缩放、切主题或聊天工作区不卸载CodeMirror、未保存缓冲、编辑登记/WS或PTY；文件固定原工作区，真正关闭才确认释放 |
| 强度与模型 | 初始及新会话默认high；无需先选模型即可选择low、medium、high、xhigh、max，Codex保留目录扩展档位。**自动表示不发送强度覆盖，跟随原生配置/运行时，不是网页自动判断任务难度** |
| Slurm | 当前SSH账号的单一固定格式squeue文本查询，无JSON兼容分支；首次/手动刷新，与资源采样独立。8秒、stdout/stderr合计512 KiB、200行、身份复验、缓存及独立取消保护保留 |
| 简洁交互 | 工具齐全不显示常驻成功条；归档空状态为“暂无归档会话”（归档后端仍仅Codex）；点文件默认可见；设置、规则和能力帮助按需展开，必要错误、危险确认及409保护保留 |
| 原生工作流 | 一体输入、模型/强度菜单、会话单动作管理、服务器列表、原生配置模板和60秒自动文件同步默认值已整合；不改变3秒同步状态查询或手动、执行前后同步 |
| 资料精简 | 删除被现行规范覆盖的旧设计、计划、重复验收和旧图；保留当前说明、必要决策及本验收，不新增一套过程文档 |

文件宽度沿用`fileWidth`偏好，范围360–960px；资源默认420px。其他位置与大小仅在当前页面分别记忆。最小支持宽度960px；≥1280px有工作区时初始打开资源，较窄首屏不强开面板。

文件开关不会暂停仍可见的资源或Slurm查询。收起资源只取消它自己的在途查询，不断开共享SSH、文件通道或PTY。Slurm成功警告不丢失，带警告空输出不宣称确定无作业；超字节拒绝整份，超行准确提示“仅显示前200行”，不推断精确作业数。
