# 工作区文件编辑验收

日期：2026-10-03。范围为 F8 文件浏览、编辑、保存后同步；本阶段不包含版本历史、新建或删除文件。

## 已实现

- 顶栏按需加载文件面板，绑定打开时的工作区；逐级浏览和相对路径打开，不递归扫描远端。目录最多返回 500 项、扫描 5000 项，截断时明确提示。
- 只编辑工作区内的普通 UTF-8 文本，大小不超过同步阈值与 2 MiB 中较小值；拒绝越界、链接、设备名、二进制与被排除路径。不存在的文件不自动创建。
- CodeMirror 支持 Python、JS/TS、Shell、JSON、TOML、YAML、Markdown 高亮与搜索，其他文本按纯文本处理。原始 BOM、行尾和权限保留。
- 保存使用内容摘要与文件身份检查、同目录原子替换，并进入同工作区同步事务。外部修改返回冲突，保留原文件及编辑缓冲。
- 网页收到本地保存成功后调用现有同步入口，再核对当前文件 revision；本地成功、同步失败/待确认和服务器已同步分别显示。保存文件不调用 git。
- 每 5 秒及重新可见时检查打开文件的 revision，隐藏暂停；未保存关闭/切换/重新读取需确认。正文不进入 React Query 或浏览器持久存储，关闭销毁编辑器。

## 验证结果

- 13 项新服务/路由核心测试通过：范围、链接、过滤、目录截断、大小/文本限制、BOM/行尾/权限、外部修改、并发保存与同步事务。
- 35 项关联测试通过：同步管理器、同步 HTTP 路由及前端 API。未为未受影响内容重复全量测试；此前 345 项全仓基准、设置阶段增量记录分别保留。
- 使用真实文件服务和 Fastify 路由的浏览器流程通过：按需读取、CRLF 保存、同步成功与失败分离、外部冲突保留、同步期间再次修改检测、关闭确认、工作区绑定和正文不缓存。此浏览器验证的同步传输为受控替身；没有把它记为实际 SSH 验收。
- 960/1280/1920 宽度截图已实际查看。修复编辑器未填满剩余高度；底部保存按钮可见，宽屏与覆盖层互换时草稿保留。键盘打开聚焦面板，跨断点后关闭可回到“文件”按钮。
- 共用 CodeMirror 改动后，原生设置浏览器流程复验通过，包括 JSON/TOML、CRLF、语法失败、外部冲突和关闭清理。
- 类型、相关 ESLint、格式及前端构建通过；重复行约 0.50%。编辑模块保持按需加载；构建仍报告主包和编辑器 chunk 超过 500 kB 的体积提示。
