## 脚本结果与证据边界

Codex 前两次夹具分别遇到 Agent 标签匹配和过宽工具卡定位问题；第一次尚未调用模型，第二次实际 hostname 已成功。第三次核心 A1/A11 断言全部通过，但末尾额外同步断言在同步进行中读取到 `syncing`，与瞬时期待的 `ready` 不符，整体夹具报告仍为失败。保存的原始事件与展开工具卡 DOM 经独立核对通过；原报告未改写，也不把这次脚本称为全绿。

随后仅修正 ignored 夹具：准确定位工具卡，等待真实内容，附加同步断言使用有界等待。Claude 完整运行通过，包括同步回到 `ready`。Codex 已通过的模型链路没有重复调用，附加同步断言不据此标为通过，也未发现足以证明产品同步异常的证据。

原始事件、诊断、DOM 和截图只保存于 ignored 验收材料；聚合报告按真实工具 ID、Agent、原生 ID 和清理摘要核对，不公开主机名、模型中转配置或连接信息。新增的四次夹具都清理各自随机远端根和本机配置副本，源配置摘要保持；此前被策略拒绝清理的旧副本不在本次范围。

本次不扩大为原生客户端界面、OS 输入法或 Edge 系统保存选择器验收。纯验收与文档阶段不新增产品测试、不重复产品 Review；按既有授权检查文档与源码基准后两级 `--no-ff` 整合，最终 main CI 另核对。
