# 远端文件操作真实失败验收

日期：2026-10-05。源码基准：`8041919`；实施从 `feat/ssh-workflow` 的 `d6a7b4b` 开始，产品源码与已通过双平台门禁的 `main e62f4fe` 相同。本轮仅补充验收证据与正式文档，没有修改产品或新增单元测试。

## 目标与方法

补齐 A22 的真实权限拒绝、预检后对象变化及连接中断证据。使用已授权 SSH 目标和当前账号，在其家目录建立两个随机测试根；同步根与操作数据目录为兄弟目录，每次预检的 `affectedWorkspaces` 均为空。本机镜像为专用空目录。

浏览和预检使用生产 `SshPool`、真实 SFTP、生产预检与持久任务服务；写操作使用生产执行器和原样 Python 处理器，在实际服务器运行。为取得可明确归属的连接句柄，验收执行器的 `openExec` 使用生产 `connectSshClient` 建立独立真实 SSH Client，仍沿用当前目标解析、私钥和主机密钥校验。仅在收到 `copying` 阶段后调用该 Client 的 `destroy()` 中断本次 TCP 连接。

独立 Client 的连接方式属于验收注入点，不能据此声称生产池的共享连接全部断开、全网络故障或所有网页故障都已通过。本轮重开的是真实浏览会话和从同一配置目录重建的任务服务；网页重开交互沿用[操作阶段验收](remote-file-operations-acceptance.md)，未新增网页端到端故障证据。

## 实际结果

| 场景 | 观察与核对结果 |
|---|---|
| 源文件无读取权限 | 自建 18 字节文件权限设为 `000`，先独立确认当前账号读取确实被拒绝；真实预检后复制返回 `permission_denied`。任务为 `needs_check`；恢复权限后核对源保留、目标不存在 |
| 预检后源路径变化 | 自建源文件预检后移动到同级新路径；旧操作返回 `not_found`，任务保持 `needs_check`。旧源和副本均不存在，移动后的原内容保留 |
| 预检后源内容变化 | 在原路径将 6 字节源改为 12 字节；旧操作返回 `stale_preflight`，新内容保留，目标未创建，未标完成 |
| 预检后同名目标出现 | 预检时目标不存在，提交前创建独立内容；旧操作返回 `destination_exists`。核对源和原目标大小、SHA256 均保持，没有覆盖或合并 |
| 复制期间真实连接中断 | 远端自建 128 MiB 稀疏文件，收到 `copying` 后摧毁独立 Client，并观察到连接 `close`。任务保持 `needs_check`、`remoteCompleted=false` |
| 中断后的其他活动 | 正常池上的随机回显命令和真实 SFTP 目录读取继续响应；证据限定为独立连接上的活动 |
| 重开与结果核对 | 关闭并从相同配置目录重建任务服务、重开真实浏览会话；中断任务仍为 `needs_check`。结果核对只读取实际源与目标，写操作调用数在重开前后均为 3，没有重放 |
| 正文与清理 | 文件正文及 SHA256 核对均在远端执行，本机只收少量 JSON；专用本地镜像保持空目录。确认所有登记的自有处理器自然结束后，核对随机前缀、父目录及非链接属性，两个远端随机根均已清理 |

首次三场景共调用 `plan/execute/check` 各 3 次；新增源内容与目标变化后，只定向执行这两场景，各调用 2 次，没有重复已通过的前三项。同名目标出现的任务也已持久重开，没有自动执行。

中断时远端复制未必立即结束。本次在自有处理器结束后，源与目标均为 134217728 字节且 SHA256 相同，但客户端没有收到持久保存的 `verified` 证明。生产核对入口因此仍提示“没有足够证据确认完整完成”，不把目标存在或本轮辅助哈希直接当作原任务完成证明。

## 决策与验证范围

- 派发后出现权限拒绝、旧对象失效或断线，保持保守的 `needs_check`；显示源、目标实际状态，不将执行器失败误写成已完成或完全无副作用。
- 纯远端任务使用结果核对，不调用仅针对受影响同步范围的 `recover()`；本轮没有新增同步协调故障证据。
- 不安装服务器工具、不调用模型、不复制原生配置；真实目标和运行记录只保存在本机 ignored 材料。
- 现有生产行为通过本轮验收，故只更新文档，不追加替身回归或重复核心 Review；文档核对和两级无快进整合沿用已通过的源码基准。

上述裁定同步记录为[决策 D32](../engineering/decisions.md#d32-真实文件失败验收与结果证明边界2026-10-05)。既有真实冲突、链接和取消证据见[完整链路验收](real-workflow-acceptance.md)；独立客户端刷新、原生 OS 输入法与 Edge 系统保存选择器仍保留未验范围。
