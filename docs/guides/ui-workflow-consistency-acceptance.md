## 2. 模型数据依据

- Claude SDK会话列表没有模型字段，不为列表逐条加载正文或启动额外CLI。打开历史时复用`getSessionMessages`，倒序取主会话助手的非空模型报告，排除用户消息、子代理和`<synthetic>`。
- Codex 0.160.0的`Thread.model`作为`SessionSummary.nativeModel`，表示原生当前配置/最近持久化模型，不等同逐轮执行遥测；复用`thread/list`，不追加N次`thread/read`。
- `SessionHistory.actualModel`及原生运行时报告保持独立语义；输入覆盖、产品默认和候选默认都不回填为历史实际模型。
- 网页已观察模型只存内存，按工作区/Agent/原生ID隔离，删除时清理。刷新后的列表原生模型优先于旧历史缓存，缺失时才回退；打开中的详情同步使用同身份最新摘要。

## 3. 唯一集中审查与修复

本轮进行一次集中只读审查，发现以下三项，均已定向复现、修复和复测；没有追加第二次广泛审查。

1. **自动续验缺少真实目标绑定**：旧实现仅比较网页上的路径、别名和认证模式，跨页面修改同名档案可能被接受。现`POST /api/workspace-setup/verify`只接受strict `{ input, previousBinding? }`；响应必含进程内HMAC-SHA256绑定，覆盖规范输入、真实连接cacheKey、凭据代次、认证模式、本地目录身份与远端解析路径。自动续验传原绑定，由服务端拒绝变化；绑定与过期/撤销票分离、重启失效、不暴露内部连接信息且不能用于创建。6项失败回归转绿，覆盖同别名同路径的连接/认证/目录变化、过期续验、无绑定降级禁止、HTTP畸形请求和取消。
2. **模型/推理Enter隐式发送**：移入form后，选项输入框Enter可能提交非空消息。只拦截这两个控件的Enter默认动作。真实Edge键盘RED为4通过/2误发，GREEN为6通过，正文Enter、Shift+Enter、按钮点击及按钮键盘Enter保持原行为。
3. **旧历史模型压住新列表值**：历史A、刷新列表B时仍显示A，且打开中的详情持有旧摘要。新增真实组件/store回归先后复现这两个表现，修正来源优先级和详情接线后通过；不把nativeModel转为actualModel。

另在真实浏览器中发现两端文件选中态使用不存在的`primary`变量、背景透明；已改为既有`accent`。浅/深色计算背景均不再透明，右键、拖动确认与三宽度面板复验通过。未放宽lint、类型或覆盖率门槛，未增加依赖。
