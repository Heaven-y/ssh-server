# ssh-server

只在本机运行的网页工作区：和本机 Claude Code 或 Codex 对话，修改本地代码副本，经 SSH 同步并运行服务器项目。模型配置、凭据和对话留在本机；服务器无需安装本工具或 Git，大数据留在远端。

## 功能

| 能力 | 工作方式 |
|---|---|
| 工作区与SSH | 统一服务器档案、密码/私钥认证、主机指纹确认、Windows加密保存密码；工作区只选择已保存服务器与两端目录 |
| 对话 | Claude/Codex会话固定Agent；一体输入、模型/强度菜单、流式回复、审批/中断；纯标题会话与单动作管理 |
| 原生能力 | 模型沿用本机配置；强度默认high，五档直接可选、自动不覆盖；可执行skills/命令和原生上下文 |
| 同步与执行 | rclone双向代码/小文件同步，页面自动同步默认60秒；手动及执行前后不延迟，删除确认与冲突保留 |
| 编辑与版本 | CodeMirror轻量编辑；本地Git保存版本、历史、差异、恢复、本轮净变化与行反馈 |
| 服务器文件 | 点文件默认可见；同服务器浏览、新建、重命名、移动、复制、删除、结果核对；涉及同步范围时协调两端 |
| 下载 | 明确选择位置后流式保存，仅使用File System Access API；不自动进入同步或Git |
| 终端与资源 | 多标签/分屏SSH终端；资源与文件为可同时打开的独立非模态浮动面板，可拖动、缩放和各自收起；隐藏保留编辑/PTY，当前账号Slurm首次/手动文本查询 |
| 设置与布局 | 默认浅色与主题记忆、分类设置、原生配置模板、按需帮助；工具齐全时无常驻成功条，必要确认与错误保留 |

项目运行、训练、统计和绘图默认使用服务器已有环境。用户发消息后才检查训练结果，不自动检测完成或唤起Agent。保存文件不创建Git提交，只有“保存版本”才提交用户项目。

## 环境与启动

- Windows 10/11；Node.js 22+；Git 2.43+。
- 使用对话时配置 Claude Code 和/或 Codex；Claude使用SDK随包原生程序，Codex使用本机CLI。缺少Agent不影响打开网页管理服务器，无需 VS Code 插件。
- rclone **1.75.1**：放入 PATH，或用 `SSH_SERVER_RCLONE` 指定已安装程序。服务器不需要安装rclone。
- SSH账号、可用密码/私钥和主机信任记录；服务器使用已有工具和Python环境，不自动安装依赖。
- 文件下载需要支持File System Access API的当前桌面Edge/Chrome；不提供下载管理器备用路径。

在仓库根目录运行：

```powershell
npm.cmd ci
npm.cmd start
```

启动后直接打开 **http://127.0.0.1:4317/**，无需复制令牌链接。先点顶栏“服务器”保存连接并认证，再新建工作区选择已保存服务器与两端目录。启动自动检查程序是否可执行；全部可用时主界面不显示成功条，缺失/失败可进入“产品设置 → 运行环境”查看指引并重新检测。不会自动安装或修改原生配置。开发热更新使用 `npm.cmd run dev`（网页端口5173）。环境变量及验证方法见[开发指南](docs/guides/dev-environment.md)。

## 当前状态与边界

第一版核心功能已有实现，当前交付状态见[路线图](docs/roadmap.md)。资源与文件独立浮动面板的规则见[D41](docs/engineering/decisions.md#d41-资源与文件独立浮动面板及资料精简2026-10-09)，最终验证范围与精选截图统一见[最新验收](docs/guides/ui-usability-optimization-acceptance.md)，拆分前的结果不代表新面板已通过。仅维护当前接口与数据格式；旧或损坏配置/任务不会自动清空、迁移或重放，恢复使用前须先核对原始数据，见[开发指南](docs/guides/dev-environment.md#413-windows-bisync-状态文件名过长)。

Windows rclone无法保留含反斜杠的远端根，产品会在传输前拒绝，不能直接替换路径字符重试。外部客户端界面和OS控件是检查手段，历史未观察事实不虚构通过，也不扩成额外产品功能。

Slurm使用固定格式的`squeue`文本，只查询当前SSH账号，不依赖特定JSON结构；共享账号不等于“我的任务”，当前SSH节点资源不代表作业计算节点。无Slurm明确显示不可用，不自动安装、轮询全部作业、提交或取消任务。

不包含完整IDE、多Agent编排、多用户、集群全节点监控、服务器软件安装、独立安装器或自动结果分析。

## 安全

后端只监听本机地址。首页通过严格同源握手自动取得HttpOnly、SameSite=Strict会话Cookie；API和WebSocket继续校验会话、Host和请求来源，禁止外部iframe嵌入。不要暴露到局域网或公网。密码仅在必要内存中处理，可选系统加密保存；不进入工作区配置、Agent输入或服务器。服务器变更与断开会核对共享工作区活动，不静默打断其他任务。命令黑名单用于防误操作，不是安全沙箱；本人操作的网页终端不经过黑名单。不要用root账号连接服务器。
