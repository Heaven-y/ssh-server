# AgentDeck

本机 Windows 工作台：把本机 Claude Code、Codex、Antigravity 的原生会话收进一个窗口管理，旁边附带 SSH 服务器控制台。

会话属于这些 CLI，配置也属于它们。本应用不含模型引擎、不存对话正文、不另造配置体系；M1 只负责把项目、会话与历史摆出来。当前以网页形态运行在本机，Electron 桌面壳在 M1.5 落地。

## 功能（M1 已交付）

| 能力 | 工作方式 |
|---|---|
| 项目 | 以本地绝对目录为身份，目录必须存在；可选绑定一台服务器与默认远端目录，两者同时出现或同时省略；重命名、移除只改本工具配置，不动磁盘文件与原生会话。界面当前只接入「添加项目」 |
| 会话列表 | 三个 CLI 的本机会话按 CLI 分组列出；Claude 与 Codex 按原生 `cwd` 归属，Antigravity 按 `workspace_uris`；解析不出归属的会话标为无归属，默认隐藏，可用开关查看 |
| 会话历史 | 只读查看原生历史：Claude/Codex 完整可读，Antigravity 只有元数据，正文区明确说明私有轨迹无法回放，不显示空白页；**没有输入框，发消息属于 M2** |
| CLI 探测 | 按 `--version`、`--help` 与 Codex 的 schema 生成判断实际能力，不比较版本号；结果为可用、未安装、接口变化、凭据未配置四态 |
| 服务器控制台 | 后端已有终端、资源（含 Slurm 查询）与服务器文件视图（新建、重命名、移动、复制、删除，不含下载）；面板以已绑定服务器的项目为入口，而 M1 界面还不能新建绑定，实际可用的是迁移过来的已绑定项目 |
| 界面 | 三段式：左栏项目与会话、主区会话历史、右侧服务器面板；深浅双主题，宽度可调并有界记忆 |

后续里程碑：原生配置编辑与启动环境注入（M3）、Electron 桌面壳（M1.5）、对话输入与流式回合（M2）、目录监听与安装包（M4）。

**已删除**：代码同步（rclone）、本地版本快照、本地文件镜像、改动视图与行内反馈、工作区创建向导、命令黑名单、Agent→SSH 的 MCP 桥、服务器文件下载。旧数据中的同步字段在读取时丢弃。

## 环境与启动

- Windows 10/11；Node.js 22+。
- 按需安装 `claude`、`codex`、`agy`，以本机安装的版本为准；本应用不打包、不锁定版本，探测失败只影响对应的 CLI。
- SSH 使用账号密码或已有私钥；服务器沿用已有工具与 Python 环境，不自动安装依赖。

```powershell
npm.cmd ci
npm.cmd run dev
```

开发期同时启动后端（默认 `127.0.0.1:4317`）与 Vite（5173），浏览器访问 Vite 地址。`npm.cmd start` 会先构建前端再由后端托管。桌面壳与安装包在 M1.5/M4 落地，当前阶段不提供双击入口。

环境变量、代码规范与验证方法见[开发指南](docs/guides/dev-environment.md)。

## 请求策略

本应用**绝不自动发请求**。任何会消耗额度、打到你自己配置端点的动作都必须由你点击触发：

- 第一档（随时）：`--version`、`--help`、Codex 的 `app-server generate-json-schema`、读会话与配置文件。
- 第二档（只在点「刷新能力」时）：启动 CLI 检查账号与斜杠命令/模型清单，结果缓存；M2 才接入对话界面。
- 第三档（只在点发送时）：真正发一轮 prompt；M1 没有发送入口。

自定义端点与密钥只在启动 CLI 子进程时作为环境变量传入，后端自己不发起模型请求；密钥不写日志、不回传前端明文、不进错误信息。本应用不读取 cc-switch 等工具的数据库。

## 安全

后端只监听本机回环地址，拒绝其他地址。首页通过严格同源握手取得 HttpOnly、SameSite=Strict 会话 Cookie；API 与 WebSocket 继续校验会话、Host 与请求来源，禁止外部 iframe 嵌入。不要暴露到局域网或公网。服务器密码仅按需在内存中处理，可选由 Windows 当前用户加密保存；不进入项目配置、Agent 输入或服务器。明文密码不出现在日志、配置或对话记录里。不要用 root 账号连接服务器。
