# AgentDeck

Windows 本机桌面工作台，按项目集中使用 Claude Code、Codex 和 Antigravity 的原生会话。整体交互参考 DSH；各 CLI 保留自己的会话、配置、工具与权限语义，工作台扩展采用 AgentDeck 自有插件接口。

主流程包含原生对话、配置与项目管理；工作台插件用于增加独立工具页面。插件使用自己的接口，不直接安装 DSH 插件包。

界面按 DSH 的导航与密度组织：左侧贯穿窗口的工作区列表，中央对话，右侧会话信息由用户打开。会话按时间混排，以图标区分 CLI；SSH Console 位于左上，点击后使用中央独立页面。

## 功能与进度

| 部分 | 当前能力 |
|---|---|
| 桌面与项目 | Electron 窗口、单实例和退出清理；项目可添加、改名、更换目录及移除，原生目录明确的其他会话可预填为项目 |
| 会话历史 | 三个 CLI 均可发现与读取历史，提供各自已接入的重命名、分支、删除和归档；Claude 子代理单独查看 |
| 原生对话 | 三种 CLI 新建、续接、流式事件和中断；Claude/Codex 原生审批，AGY 原生软拒；支持后台并行与短暂断线/刷新恢复 |
| 会话引用与统计 | 复制稳定会话链接、点击定位和跨 CLI 只读历史工具；执行轨迹、原生用量及可靠计时 |
| 原生配置 | 按各 CLI 的真实作用域浏览配置、规则、Skills、MCP 和原生插件入口；显式打开原文编辑，另有受控启动环境设置 |
| SSH | 左上进入 SSH Console，多服务器、全磁盘与负载、进程、文件历史导航、多终端、分屏和搜索；其中“项目服务器工具”保留 Slurm 与文件写任务 |
| 插件 | 本地安装静态页面插件，按声明权限使用自己的设置、项目摘要和命令；支持启停和卸载外部安装副本 |
| 本地分发 | 已有 Windows x64 0.1.1 安装版/便携版；后续源码尚未重新成包，未签名、不发布、不自动更新 |

完成状态和验证边界统一记录在[路线图](docs/roadmap.md)。旧同步、版本快照、本地文件镜像及 Agent→SSH 桥已经移除。

## 启动

本地安装版和便携版直接运行，使用方法见[安装指南](docs/guides/local-installation.md)。源码开发需要 Windows 10/11、Node.js 22+。按需安装对应 CLI，服务器使用已有 SSH 与运行环境。

```powershell
npm.cmd ci
npm.cmd run dev:desktop
```

桌面开发入口直接加载 Vite 页面，界面和样式保存后热更新；后端或桌面主进程变化会自动重启应用。浏览器开发可运行 `npm.cmd run dev`，生产式本机服务可运行 `npm.cmd start`。本地打包、安装与卸载说明见[本地安装指南](docs/guides/local-installation.md)，环境变量和隔离验证方式见[开发指南](docs/guides/dev-environment.md)。

## 使用边界

- 会话正文保存在各 CLI 原生存储中；本产品不维护第二份对话数据库。
- 启动与浏览只做本机探测、配置和历史读取。首次打开模型菜单会按需获取原生能力，之后复用缓存；模型回合只在显式发送后启动。
- CLI 支持什么能力、配置放在哪个作用域，以该 CLI 的实际接口为准。不同 CLI 的差异会明确展示。
- 后端仅监听回环地址，并校验会话与请求来源；SSH 凭据不进入项目配置或模型输入。
- AgentDeck 插件扩展工作台；CLI 原生 Skills、MCP 和插件仍由各 CLI 解释执行。
- 会话列表在启动及应用内操作后更新，不使用目录监听或常驻轮询；终端查找只扫描本机缓冲。真实模型、SSH 和系统交互的已验范围分别记录。
